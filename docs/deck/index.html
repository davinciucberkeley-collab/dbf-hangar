One design, one file

  • A design is designs/<id>/plane.yaml plus a schema (PDL)
  • Change it with plane design set, one value and a reason
  • Every change writes a CHANGELOG entry; a designs-only PR never touches code
  • Validate gives a scorecard: seconds for a small design, about 80 s for concept-a
Source: schema/plane.schema.json; docs/pdl/reference.md; designs/concept-a/CHANGELOG.yaml; timings 11-24 (demo-script.md)
Every set writes a CHANGELOG entry with old value, new value and a reason. Designs-only PRs never touch core/.

What the model is and is not

  • Is: recognisable geometry, and real parts placed sensibly
  • Is not: rolling wheels, or kinematic linkage checking beyond the T6 recipe
  • Control surfaces can clip at large deflection (rehearsal 3 gap 2)
  • Parts without vendor CAD are labelled envelopes (D82); licensed CAD only in a local overlay (D83), never in CI or the public viewer
  • Ratings and prices are placeholders, not invented
  • The static margin check does not model the fuselage
