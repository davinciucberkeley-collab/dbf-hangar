### 3. `core/hangar/calcs/modes.py` (SI, rad, s; `numpy`, `math` only)
Docstring first line `"""U18.4: handbook approximations of the longitudinal and lateral modes from dimensional derivatives (2-state models, Lanchester phugoid, 4-state lateral matrix)."""`. Exactly:
- `short_period(m_alpha: float, m_q: float, z_alpha: float) -> tuple[float, float]`: model `alpha_dot = q + z_alpha alpha`, `q_dot = m_alpha alpha + m_q q`; characteristic `lambda^2 - (z_alpha + m_q) lambda + (z_alpha m_q - m_alpha)`; returns `(omega_n, zeta)` with `omega_n = sqrt(c0)`, `zeta = -(z_alpha + m_q) / (2 omega_n)`; if `c0 <= 0` raises `ValueError("statically unstable pitch: no oscillatory short-period mode")`. Units: `m_alpha` 1/s^2, `m_q`, `z_alpha` 1/s.
- `dutch_roll(y_beta: float, n_r: float, n_beta: float) -> tuple[float, float]`: model `beta_dot = y_beta beta - r`, `r_dot = n_beta beta + n_r r`; characteristic `lambda^2 - (y_beta + n_r) lambda + (y_beta n_r + n_beta)`; same return and error (`"no oscillatory Dutch-roll mode"`).
- `phugoid_lanchester(speed_mps: float, lift_over_drag: float, g: float = 9.80665) -> tuple[float, float]`: `(sqrt(2) g / V, 1 / (sqrt(2) L/D))`.
- `lateral_modes(a: list[list[float]]) -> dict`: `a` is the 4x4 matrix for states `(beta, p, r, phi)`; `ev = numpy.linalg.eigvals`; if a complex-conjugate pair exists: `dutch_roll = {"omega": abs(pair), "zeta": -real/abs}` else None; of the remaining real eigenvalues the most negative is the roll subsidence `roll_tau_s = -1/lambda` (None if none is negative) and the real eigenvalue of smallest magnitude (other than the roll one) is the spiral: `spiral_lambda` (float) and `spiral_time_to_double_s = ln(2)/lambda if lambda > 0 else None`. Returns `{"dutch_roll": ..., "roll_tau_s": ..., "spiral_lambda": ..., "spiral_time_to_double_s": ...}`.
- `lateral_matrix(y_beta, l_beta, l_p, l_r, n_beta, n_p, n_r, speed_mps, g=9.80665) -> list[list[float]]`: rows `[y_beta, 0, -1, g/V]`, `[l_beta, l_p, l_r, 0]`, `[n_beta, n_p, n_r, 0]`, `[0, 1, 0, 0]` (sideforce due to p and r neglected; Ixz neglected).
