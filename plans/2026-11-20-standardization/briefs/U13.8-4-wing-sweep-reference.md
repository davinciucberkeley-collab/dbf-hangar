# Brief U13.8-4-wing-sweep-reference: document wing_panel sweep with `inboard_span` and add opt-in `sweep_reference: outboard_le`

class: hard · role: builder-plus · plan: §7 U13.8 (rehearsal 4 gap 8, c172-rc) · depends on: U13.2-6 (old U4.36-6, merged: `inboard_span`), U13.7-7 (merged: `core_fill`) · merge order: 4th · SLUG = `wing-sweep-reference`

Environment: follow `plans/2026-11-20-standardization/briefs/U13.7-env.md` with every `u13.7` read as `u13.8` and SLUG=wing-sweep-reference.

## Current semantics (read from `core/hangar/geom/wing.py::_place`, 2026-11-25)
`sweep_le_deg` offsets every section's leading edge by `|y| x tan(sweep_le_deg)` measured from the ROOT, across the whole half span, including the constant-chord `inboard_span` rectangle (the inboard leading edge is swept too). Dihedral and twist are linear in `|y|` from the root as well. The C172 reference has a straight inboard leading edge and a measured OUTBOARD leading-edge sweep of 3.3 deg; rehearsal 4 had to convert it by hand to 1.8 deg (600 mm x tan 1.8 deg = 18.85 mm = 326 mm x tan 3.3 deg = 18.80 mm).

## Decision (default taken)
Opt-in parameter `sweep_reference` (choice `root` default, `outboard_le`): with `outboard_le` the sweep starts at the end of the inboard section: leading-edge offset `0` for `|y| <= inboard_span` and `(|y| - inboard_span) x tan(sweep_le_deg)` outboard, so a measured outboard sweep is entered directly. Dihedral and twist stay root-referenced (stated in the docs). Default `root`: every existing result bit-identical.

## Exact steps
1. Param `"sweep_reference": ParamSpec("choice", default="root", choices=("root", "outboard_le"), doc="where the leading-edge sweep starts: root = from the root chord across the whole half span (default); outboard_le = from the end of the inboard_span rectangle, so the inboard leading edge is straight")`, placed after `sweep_le_deg`.
2. `_place`: replace the sweep line by `lead = ay if p.get("sweep_reference", "root") == "root" else max(0.0, ay - ib)`; `x2 = x2 + lead * math.tan(math.radians(p["sweep_le_deg"]))` (`ib` is already computed in `_place`). With `root` the arithmetic is identical to now.
3. `_check`: add `"sweep_reference: outboard_le needs inboard_span > 0"` when `sweep_reference == "outboard_le"` and `inboard_span` is 0 (with no inboard section the two references are the same: refuse the ambiguity).
4. Docs (the `doc=` strings): `sweep_le_deg`: `"leading-edge sweep angle, deg; measured from the root across the whole half span (the inboard_span rectangle is swept too) unless sweep_reference is outboard_le"`; `inboard_span`: keep the existing text and append ` Sweep starts at the root unless sweep_reference is outboard_le; dihedral and twist always start at the root.` (`plane generators show wing_panel` prints them; keep unit words in every numeric doc, as `tests/test_generator_docs.py` requires.)
5. Elevon pieces, `core_fill` pieces and every loft call use `_place`, so they follow the same reference; no other code change.

## Tests: `tests/test_wing_sweep_reference.py`

Base: `P = {"airfoil_file": DAT, "span": 400, "root_chord": 100, "tip_chord": 50, "inboard_span": 100, "part": "full", "side": "right"}` (half 200). The diamond airfoil's leading edge is the section point with the smallest x, so the leading-edge offset of a station is the minimum x of the vertices at that y.
Hand values for `sweep_le_deg = 10` (tan 10 deg = 0.176327): root reference: LE offset at y = 100 is 17.633, at the tip (y = 200) 35.265; outboard reference: 0 at y = 100 and (200 - 100) x 0.176327 = 17.633 at the tip.
1. `test_default_is_bit_identical`: vertices with `sweep_reference="root"` equal those without the param (`np.array_equal`), for `sweep_le_deg` 0 and 10.
2. `test_root_reference_leading_edge_offsets`: `m = build(P + sweep 10)`; `min x of vertices with |y - 100| < 1e-6` is `17.633` (abs 1e-3); at y = 200 it is `35.265` (abs 1e-3).
3. `test_outboard_reference_leading_edge_offsets`: with `sweep_reference="outboard_le"`: at y = 100 min x is `0.0` (abs 1e-6); at y = 200 it is `17.633` (abs 1e-3); at y = 0 it is `0.0`.
4. `test_c172_numbers`: `span 1200, root_chord 177, tip_chord 116, inboard_span 274, side="right"`: with `sweep_le_deg=3.3, sweep_reference="outboard_le"` the leading-edge offset is `0.0` at y = 274 (abs 1e-6) and `326 x tan(3.3 deg) = 18.80` at y = 600 (abs 1e-2); with the hand conversion of rehearsal 4, `sweep_le_deg=1.8, sweep_reference="root"`, it is `274 x tan(1.8 deg) = 8.61` at y = 274 (abs 1e-2, a swept inboard edge) and `18.85` at y = 600 (abs 1e-2): the tips agree within 0.05 mm, the inboard edges do not.
