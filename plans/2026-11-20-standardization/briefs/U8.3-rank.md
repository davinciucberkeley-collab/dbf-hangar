## Two facts the plan did not state (decide before step 3)

1. The 64 SKIP rows are not produced by the library. `core/hangar/checks.py:696-701` (`T2.joint_load`) and `core/hangar/sim.py:207` (`T2.sim_drop_loads`) SKIP whenever the JOINT's own `rating_basis` is `placeholder`, and never read `standards/connection-types.yaml`. Only `T2.joint_rf` (`core/hangar/gates/discipline.py:155`, non-blocking) falls back to the library `rated_load_n`; `T7.electrical_rating` reads `rated_current_a`. So writing library values changes `T2.joint_rf` rows only; the 64 SKIP rows and the 4 FAIL rows stay until either (a) the two gates get the same library fallback (a `core/` change, not in U8.3) or (b) each placeholder joint gets its own sourced rating in `designs/` (stress x that joint's contact area; the areas are not in plane.yaml). The 4 FAILs sit on derived joint ratings (0.7 N and 1.4 N, foam shear x small area) and no library value overrides a joint's own number.
2. The fidelity line (`core/hangar/gates/fidelity.py:37-56`) counts a blocking result as sourced when its CRITERION threshold has a source. Joint results carry criterion `design-standards.yaml#landing_load_factor`, which is `pending`. Sourcing `landing_load_factor` therefore moves the line for every `T2.joint_load` and `T2.sim_drop_loads` row (and the T2 gates keyed to it); sourcing any connection type moves it by zero.

Expected effect if every scoutable type gets a source: library path alone 0 of 64 SKIP and 0 of 4 FAIL become verdicts (26 structural placeholder joints get a `T2.joint_rf` library value only for fixed-size types, probably none because TAPE-FOAM, EPOXY, VELCRO and TAPE-HINGE are per-area). Ceiling with a gate fallback or joint-level ratings: 64 SKIP, plus up to 4 FAIL re-judged.

## Script (run from the repo root; prints the table data)

```python
import json, collections, yaml
D = "designs/concept-a/"
plane = yaml.safe_load(open(D + "plane.yaml", encoding="utf-8"))
base = json.load(open(D + "baseline.json", encoding="utf-8"))
lib = {t["id"]: t for t in yaml.safe_load(open("standards/connection-types.yaml", encoding="utf-8"))["connection_types"]}
rows = collections.defaultdict(collections.Counter)
for x in base["known"]:
    if x["check_id"] in ("T2.joint_load", "T2.sim_drop_loads"):
        rows[x["example"].split(":")[0]][(x["check_id"], x["status"])] += 1
st = collections.defaultdict(collections.Counter)
for a in plane["attachments"]:
    c = a.get("connection", "(none)"); s = st[c]; s["joints"] += 1
    s["placeholder_joints"] += a.get("rating_basis") == "placeholder"
    r = rows.get(a["id"], {})
    s["skip"] += r.get(("T2.joint_load", "SKIP"), 0) + r.get(("T2.sim_drop_loads", "SKIP"), 0)
    s["fail"] += r.get(("T2.sim_drop_loads", "FAIL"), 0)
for c, s in sorted(st.items(), key=lambda kv: (-(kv[1]["skip"] + kv[1]["fail"]), -kv[1]["joints"])):
    t = lib.get(c, {})
    print(c, dict(s), "source:", str(t.get("source"))[:30], "has rated_load_n:", "rated_load_n" in t)
```
