## Design (SPEC)
### D1. `params.py`
Add (names are fixed, tests import them):
```python
MAX_EXPR_LEN = 200
ATT_REF_PATHS = ("location", "articulation.pivot")     # under attachments[*]
class ExprError(ValueError):
    kind: str          # "syntax" | "name" | "zero" | "range"
def is_expression(s) -> bool            # isinstance(s, str) and "$" in s
def expr_names(expr: str) -> list[str]  # distinct parameter names in order of first appearance; parse only; raises ExprError("syntax")
def evaluate(expr: str, params: dict) -> int | float
def expression_errors(data: dict) -> list[tuple[str, str, str]]   # (owner, path, message) for syntax / zero / range errors only
```
Grammar (hand-written tokenizer + recursive descent, about 60 lines, NO `eval`, `exec`, `ast`, `compile`, `re.sub` callbacks that execute anything):
```
expr   := term (("+"|"-") term)*
term   := unary (("*"|"/") unary)*
unary  := "-" unary | atom
atom   := NUMBER | "$" NAME | "(" expr ")"
NUMBER := (digits ["." digits*] | "." digits) [("e"|"E") ["+"|"-"] digits]
NAME   := [a-z][a-z0-9_]*
```
Whitespace between tokens is ignored. Nothing else is valid: no bare names, no `**`, no `//`, no `%`, no calls, no attributes, no unary `+`, no quotes. Length limit: more than `MAX_EXPR_LEN` characters is `ExprError("syntax")` (exactly 200 is fine). Evaluation:
- A `$name` must be a key of `params` with a number value (`int`/`float`, NOT bool); else `ExprError(kind="name")` with a message that contains the name.
- Division by zero: `ExprError(kind="zero")`. A non-finite result: `ExprError(kind="range")`.
- Result: compute in float arithmetic; `v = round(float(result), 9)`; return `int(v)` if `v.is_integer()` else `v`. (So `450 - $span_mm/2` at 900 is the int `0`, and a stored `128.599` survives `450 - $span_mm/2 + 128.599`.)
- Leaves of arithmetic stay Python floats; integer inputs go through `float()` first.
`find_references`: unchanged output for components. For every string under REF_PATHS that is a whole-string `$name` yield as before; for every other string with `$` call `expr_names` and yield one `(owner, path, name)` per distinct name (on `ExprError` yield nothing for that string). Then for every attachment dict `a` in `data["attachments"]` and each path in `ATT_REF_PATHS` do the same with owner `f"attachments[{a.get('id')}]"` and path as `_walk` writes it (`location[1]`, `articulation.pivot[1]`). Components first, then attachments.
`_sub` / `resolve_references`: a whole-string `"$name"` keeps today's fast path (same value, same type, left as a string if the parameter is missing or not a number). Any other string containing `$`: `evaluate(s, params)`; on `ExprError` leave the string unchanged. Apply `_sub` to the same REF_PATHS of components AND to `ATT_REF_PATHS` of each dict in `out["attachments"]` (when it is a list of dicts). `data` is not mutated.
`expression_errors(data)`: walk the same strings (components, then attachments) that contain `$` but are not a whole-string `$name`; call `evaluate` with `data["parameters"]` (or `{}`); report only `kind != "name"`: `(owner, path, f"expression {s!r}: {message}")`. Owner for components is the component id.
