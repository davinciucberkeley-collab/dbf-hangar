## Why
- Gap 2: the library props are solid envelope discs (APC 9x6E = 229 mm against the 172's scale prop of 191 mm); rehearsal 4 used the `propeller` generator directly on the component with estimated chords, because no library part is prop-shaped. A library entry whose geometry is the `propeller` generator (n blades, hub, spinner) lets a BOM line and a component use the same part.
- Gap 3: no library servo fits a 1:10 wing 14 mm thick (the aileron servos hang under the wing). The ES08MA II is 11.5 x 23 x 24 mm, 12 g (`knowledge/parts/emax-es08maii-metal/part.yaml`); a 3-5 g sub-micro servo is needed. The scout finds candidates with vendor data; nothing is invented.

```
verified: {by: <your id>, date: '<today>', method: computed}

  generator: propeller
  params: {blades: 2, diameter: 191, hub_d: 14, hub_length: 10, root_chord: 14, tip_chord: 8, spinner_length: 25}
```
   `mass_g` = the volume of the built part in mm3 x 0.00127 g/mm3, rounded to 0.1 g (compute it with `hangar.geom.registry.build_component` and `abs(mesh.volume)` for all returned parts summed); `dimensions_mm` = the built mesh's extents rounded to 0.1 (x is the axis). The `url` is the reference sheet in the repo because a generated part has no shop page; `verified.method: computed` documents that.
2. `scale-prop-8b-a400m/part.yaml`: same layout for the A400M's scale propeller: read `knowledge/reference-aircraft/a400m.md` section 4 (prop diameter, blade count, spinner length) and the scale 1:25 used by the rehearsal-3 design (`C:/Users/trist/wt/rehearsal3-a400m/designs/a400m-rc/plane.yaml`, or PR #8 if the folder is gone; the rehearsal used an APC 2-blade stand-in because no 8-blade part existed): `blades` = the sheet's blade count (8 expected), `diameter` = sheet diameter / 25, spinner and hub from the sheet or marked ESTIMATE, chords ESTIMATE (state the rule you used in `cad_source`). If the sheet gives no prop diameter, write `not found` in `cad_source`, skip this part and say so in the hand-back (the other part still ships).
