Imports allowed: standard library, `numpy`, `trimesh`, `yaml`, and from hangar: `from .design import Design, load_standards`-style helpers exactly as `core/hangar/fea.py` uses them (open `core/hangar/fea.py` lines 1-45 and copy its import lines for `load_standards`, `overlay`), `from .geometry import component_parts, is_point_mass`, `from .mass import mass_properties`. Exact public interface (fixed; U18.1-4 calls it):

```python
INPUTS_FILE = "opencae-inputs.yaml"      # sidecar in the design folder
ROLE_BY_TYPE = {"motor": "motor", "propeller": "prop", "battery": "battery", "wing": "wing", "tail_surface": "fin",
                "landing_gear": "landing", "boom": "arm", "structure": "frame", "fuselage": "frame",
                "flight_controller": "electronics", "receiver": "electronics", "esc": "electronics",
                "servo": "electronics"}          # every other type -> "other"
SIDECAR_KEYS = ("propulsion.motor.kv", "propulsion.motor.r_ohm", "propulsion.motor.i0_a", "propulsion.prop.pitch_in",
                "propulsion.prop.ct", "propulsion.prop.cp", "propulsion.battery.r_int_mohm_per_cell",
                "propulsion.esc.i_cont_a", "propulsion.esc.efficiency")

def load_inputs(design: Design) -> dict:
    """Sidecar design.base_dir/INPUTS_FILE (yaml). Absent file -> {"values": {}, "materials": {}, "role_materials": {}}.
    File format: `format: opencae-inputs/1`; `values:` a mapping whose keys must all be in SIDECAR_KEYS, each value a mapping {value, unit, status, source} with status one of estimate|datasheet|measured|user and a non-empty source; `materials:` mapping name -> {density_kg_m3, youngs_modulus_gpa, poisson, yield_strength_mpa, status, source}; `role_materials:` mapping role -> material name that exists in `materials`.
    Raises ValueError (message names the key) for an unknown key, a bad status, a missing source, or a role_materials entry naming an unknown material."""

def solid_name(component: dict) -> str:
    """"battery" for type battery; else ROLE_BY_TYPE.get(type, "other") + "_" + id lowercased with every character not in a-z0-9 replaced by "_"."""

def mass_status(component: dict) -> str:
    """provenance.mass_source: measured->"measured", datasheet->"datasheet", cad->"estimate", estimate->"estimate"; absent -> "estimate"."""

def status_for(design: Design, component_id: str) -> str:
    """Evidence of a datasheet-type number of this component from the design's bom: the first bom item whose component_ids contains component_id and that has `verified`: method datasheet|browser|webfetch -> "datasheet", in-hand -> "measured". No such item -> "estimate"."""

def write_airframe_stl(design: Design, path: Path) -> dict:
    """One ASCII STL, millimetres, hangar frame unchanged (no axis flip), one `solid <name>` block per component that is not a point mass, in design order, triangles from trimesh.util.concatenate(component_parts(c, design.base_dir)) (face normals from the mesh). Returns {"solids": {component_id: solid_name}, "point_masses": [component_id, ...]}."""

def drone_spec(design: Design, inputs: dict, analyses: tuple[str, ...], solvers: dict, solids: dict[str, str]) -> dict:
    """The drone.json object, format "opencae-drone/1". Exact rules in the table below."""

def export_project(design: Design, out_dir: Path, analyses: tuple[str, ...], solvers: dict) -> dict:
    """Create out_dir, write airframe.stl and drone.json (json.dumps indent 1, sort_keys False, trailing newline). Returns {"dir": out_dir, "spec": <the drone.json object>, "solids": {...}, "point_masses": [...], "skipped": {analysis: reason}}. `solvers` is the dict returned by `hangar.opencae_cli.solver_status`: {"ccx": (bool, str), "cfd": (bool, str)}; `skipped` has "structure" when requested but solvers["ccx"][0] is False and "cfd" when requested but solvers["cfd"][0] is False (reason = the str). It never raises for a missing solver."""
```

drone_spec rules (every number is written in the long form `{"value", "unit", "status", "source"}` as in `plans/2026-11-20-standardization/u18.1/fixtures/concept-a-param.drone.json`; `source` is a short text naming the PDL path, for example `plane.yaml components[prp-001-ll].propulsion.max_current_a`):

| drone.json key | rule |
|---|---|
| `format`, `name`, `engine` | `"opencae-drone/1"`, `design.id`, `"generic"` |
| `type` | morphology lift "multirotor" -> `multirotor`; else vtol_method "tailsitter" -> `tailsitter`; vtol_method not "none" and not absent -> `vtol`; else `fixed_wing` |
| `geometry` | `{"file": "airframe.stl", "units": "mm", "forward": "-x", "up": "+z"}` |
| `roles` | for each role that occurs: `{role: [solid names of its components]}` (explicit names, no globs); `other` is omitted |
| `mass.parts` | solid name -> long-form grams from `mass_properties(design)["per_component"]` (the id and mass_g there), status `mass_status(component)`, source `plane design mass` ; point masses omitted |
| `mass.payload_g` | `{"value": 0, "unit": "g", "status": "user", "source": "none"}` |
| `propulsion.rotors` | `"auto"` |
| `propulsion.motor.i_max_a` | from the first motor with `propulsion.max_current_a`: value, status `status_for(design, motor id)`; no motor has it -> `null` |
| `propulsion.motor.mass_g` | the first motor's mass_g, status `mass_status`; no motor -> `null` |
| `propulsion.motor.kv/r_ohm/i0_a` | sidecar `values[...]` if present else `null` |
| `propulsion.prop.diameter_in` | first motor `propulsion.prop_diameter_mm` / 25.4 (round 4), status `status_for(motor)`; absent -> `null` |
| `propulsion.prop.pitch_in/ct/cp` | sidecar else `null` |
| `propulsion.battery.cells/capacity_mah/c_rating` | the first battery component's `battery.cells_s/capacity_mah/max_discharge_c`, status `status_for(battery id)`; absent -> `null` |
| `propulsion.battery.usable_fraction` | `standards/operations.yaml` key `battery_usable_fraction` value, status `user`, source `standards/operations.yaml#battery_usable_fraction`; read it with the same reader `hangar/gates/discipline.py` uses (`_entry(OPS, key)` or `_std`; look at lines 38-52 of that file and import the helper, do not re-parse yaml) |
| `propulsion.battery.r_int_mohm_per_cell`, `esc.i_cont_a`, `esc.efficiency` | sidecar else `null` |
| `aero.cruise_speed_ms` | `requirements.cruise_speed_mps` status `user`; absent -> `null` |
| `aero.alpha_deg` | `{"value": 0, "unit": "deg", "status": "estimate", "source": "default"}` |
| `mission.hover_s`, `mission.cruise_s` | operations.yaml `mission_hover_min`, `mission_cruise_min` x 60, status `user` |
| `mission.payload_g` | same as mass.payload_g |
| `environment.rho` | `flight.air_density_kgm3` else 1.225, status `user`; `environment.g` 9.80665 `user` |
| `materials`, `role_materials` | copied from the sidecar (omit the keys when empty) |
| `analyses.structure` | `{"enabled": bool, "load_factor": {value: design-standards.yaml#ultimate_factor, unit "", status "user", source ...}}`; enabled = "structure" in analyses and solvers["ccx"][0] |
| `analyses.cfd` | `{"enabled": bool, "solver": "auto", "preset": "coarse", "iterations": 300}`; enabled = "cfd" in analyses and solvers["cfd"][0] |
| `analyses.flight` | `{"enabled": bool, "disturbance_deg": {"value": 15, "unit": "deg", "status": "user", "source": "default"}}`; enabled = "flight" in analyses and type != fixed_wing |
| `requirements` | not written |
