# Brief U13.7-1-overlay-baselines: baselines and FEA hashes never depend on the local CAD overlay (T136)

class: hard · role: builder-plus · plan: §7 U13.7 (T136; W31-R note on U12.5) · depends on: U12.5 (old U12.5, merged: `core/hangar/geom/overlay.py`) · merge order: 1st · SLUG = `overlay-baselines`

Environment: follow `plans/2026-11-20-standardization/briefs/U13.7-env.md` with SLUG=overlay-baselines.

## Why (red on main, 2026-11-25)
Shared numbers must not depend on one teammate's licensed CAD files. With a synthetic overlay for `test-servo` (a 20 x 10 x 22 box) and the `esc` component of `tests/fixtures/gates-base.yaml` replaced by `library_part: test-servo` (the helper of `tests/test_cad_overlay_guard.py`), `hangar.fea.part_hash(design, "esc")` is `38966f1b300e...` with `PLANE_CAD_OVERLAY=off` and `22ad12d79565...` with the overlay on: the hash covers the overlay file's bytes (`component_files` lists them for the part cache) and FEA would run on the overlay mesh. `plane baseline update` and `check` call `validate(design)`, whose geometry rows (interference, attachment contact, CG, drop loads) use the overlay mesh, so `baseline.json` written on an overlay machine differs from CI's (rehearsal 2: the 54 mm motor model broke a nacelle embed check only on the overlay PC).

## Decision (taken here, stated so the reviewer can check it)
Force the overlay OFF inside the commands whose output is shared (baseline update and check, FEA run, FEA hashes) instead of refusing. A refusal would block the teammate who is working with real parts; ignoring the overlay produces exactly CI's numbers. Each such command prints one line to stderr when an overlay was configured: `note: CAD overlay ignored here (baselines and FEA results never use licensed files)`.

## Exact steps
1. `overlay.py`: add module state `_FORCED = 0`; split the body of `overlay_root()` into `_configured_root() -> Path | None` (unchanged logic) and `def overlay_root(): return None if _FORCED else _configured_root()`; add `def overlay_configured() -> bool: return _configured_root() is not None`; add
```python
@contextlib.contextmanager
def forced_off():
    """Ignore the overlay inside the block (nesting allowed; restored on exceptions)."""
    global _FORCED
    _FORCED += 1
    try:
        yield
    finally:
        _FORCED -= 1
```
   (`import contextlib`). `status`, `mesh` and `cache_files` already go through `overlay_root()`, so inside the block every part is `absent` and the part-cache key has no overlay files.
2. `fea.py`: `from .geom import overlay` (module level); wrap the whole body of `part_hash`, `run` and `tier2_fea` in `with overlay.forced_off():` (rename the existing bodies to private `_part_hash`, `_run`, `_tier2_fea` and make the public names one-line wrappers, to keep the diff small and the signatures unchanged).
3. `cli.py`: in `baseline_update_cmd` and `baseline_check_cmd`, at the top of the command body: `from .geom import overlay`; `if overlay.overlay_configured(): click.echo("note: CAD overlay ignored here (baselines and FEA results never use licensed files)", err=True)`; then run the existing body inside `with overlay.forced_off():`.
4. `docs/cad-overlay.md`: append a paragraph `## Baselines and FEA` stating the rule and the note text above; nothing else in the doc changes.
