## Exact steps and outputs
`core/hangar/geom/tails.py`: imports `registry` (`from hangar.geom import registry, kernel`), `Generator`, `ParamSpec`, `register`. Helper `_make(name, params, base_dir)` = `registry.build_component({"id": "tail", "geometry": {"generator": name, "params": params}}, base_dir)` returning the list of meshes. Generator `tail_surfaces`:
- params: `layout` (choice `conventional|t|v|h`, default `conventional`), `airfoil_file` (string, required), horizontal surface `stab_span` (number, required, `> 0`, tip to tip, horizontal projection for `v`), `stab_root_chord` (required), `stab_tip_chord` (required), `stab_sweep_le_deg` (default 0), `stab_x_le` (default 0: x of the stab root leading edge), `stab_z` (default 0: z of the stab chord datum for conventional, h and v), `v_dihedral_deg` (default `35`; check `5 <= x <= 80`, used only for `v`), vertical surface `fin_thickness`, `fin_height`, `fin_root_chord`, `fin_tip_chord` (all four: number, no default, needed for `conventional`, `t` and `h`), `fin_sweep_le_deg` (default 0), `fin_x_le` (default 0), `fin_z_root` (default 0).
- check: layouts `conventional`, `t`, `h` need the four fin parameters present (message names the missing ones); `v` needs none (ignored if given).
- build, `stab_params = {airfoil_file, span: stab_span, root_chord, tip_chord, sweep_le_deg, part: "full", z_offset: <z>}` and the stab mesh translated by `[stab_x_le, 0, 0]`:
  - `conventional`: stab `z_offset = stab_z`; fin `{plane_y: 0, thickness, root_chord, tip_chord, height, x_le: fin_x_le, z_root: fin_z_root, sweep_le_deg}`.
  - `t`: stab `z_offset = fin_z_root + fin_height` (`stab_z` ignored); same fin.
  - `h`: stab `z_offset = stab_z`; two fins at `plane_y = +stab_span/2` and `-stab_span/2`, each `z_root = stab_z - fin_height/2`, same other fin values.
  - `v`: one `wing_panel` with `dihedral_deg = v_dihedral_deg`, `z_offset = stab_z`, `side both`; no fin.
  - Result `[kernel.union(parts)]` (a single mesh for `v`).
