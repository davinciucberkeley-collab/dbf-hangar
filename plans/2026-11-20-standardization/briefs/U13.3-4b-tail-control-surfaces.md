## Why (A400M gap 9)
`tail_surfaces` is one fused mesh; there is no elevator or rudder, so a servo has no surface to drive and T6 cannot run. `wing_panel` already has `part: core | elevon` with `hinge_frac`. Defaults must keep every current result identical.

## Exact steps
1. `fin` (parts.py): add `"part": ParamSpec("choice", default="full", choices=("full", "front", "rear"))` and `"hinge_frac": ParamSpec("number", default=0.7, doc="hinge line as a fraction of the local chord, ratio; the front part ends and the rear part starts there")`. Outline with `xl = x_le`, `zr = z_root`, `h = height`, `dx = abs(h)*tan(sweep)` as now: `full` as now; `front`: `[(xl, zr), (xl + f*root_chord, zr), (xl + dx + f*tip_chord, zr + h), (xl + dx, zr + h)]`; `rear`: `[(xl + f*root_chord, zr), (xl + root_chord, zr), (xl + dx + tip_chord, zr + h), (xl + dx + f*tip_chord, zr + h)]` (`f = hinge_frac`). `_fin_check` adds `"hinge_frac: must be in (0, 1)"` when not `0 < f < 1` (keep the existing height check).
2. `tail_surfaces` (tails.py): add `"part": ParamSpec("choice", default="full", choices=("full", "fixed", "elevator", "rudder"))` and `"hinge_frac": ParamSpec("number", default=0.7, doc="hinge line as a fraction of the local chord, ratio")`. In `_build`: `full` is the existing code unchanged. `fixed`: stabiliser built with `wing_panel` `part: "core"`, `hinge_frac`; fins (not for layout `v`) with `fin` `part: "front"`, `hinge_frac`; union as now. `elevator`: stabiliser `wing_panel` `part: "elevon"`, `elevon_y: [0, stab_span/2]`, `hinge_frac`, `side: "both"` (the halves touch at y = 0 and are united), no fin. `rudder`: only the fin(s) with `fin` `part: "rear"`, `hinge_frac`. `_check` adds `"part: rudder needs a layout other than v"` for layout `v`, and `"hinge_frac: must be in (0, 1)"`. The registry `files` stays `[airfoil_file]`.
3. Nothing else changes; `part: full` results are bit-for-bit the old ones.
