### 1. `pdledit.py`
Add, with these exact signatures:
```python
def exists(data, key: str) -> bool:
    """True when every step of `key` resolves in `data` (uses walk; False on OpInputError)."""

def add_value(text: str, key: str, new) -> str:
    """Return the patched text: create what `key` needs and set the last step to the scalar `new`."""
```
`add_value` rules:
- Parse `text` with `yamlio.load` (ruamel round trip, keeps comments); steps from `parse_key(key)`.
- Walk the steps from the root. A `("key", name)` step on a mapping that lacks `name` creates it: an empty mapping if more steps follow and the next step is a `key`; an empty list if the next step is an `id` selector; the scalar `new` if it is the last step. A `("key", name)` step on something that is not a mapping raises `OpInputError(f"{key}: {name!r} needs a mapping")`.
- An `("id", v)` step on a list with no element whose `id` equals `v` appends `{"id": v}` (a ruamel `CommentedMap`) and continues in it. An `("index", i)` step out of range raises `OpInputError` as `_child` does (no creation by index).
- If the final key already exists, raise `OpInputError(f"{key}: already set; use --kind modify")`.
- `new` is a scalar (`parse_scalar` already rejects mappings and lists). Dump with `yamlio.dump`. If the input contained `\r\n`, return the output with `\n` replaced by `\r\n`.
- Verify 1: `yaml.safe_load(output)` equals the `yaml.safe_load(text)` with the same creation applied by plain dict code; if not, raise `OpInputError(f"{key}: cannot add this value without rewriting other text; edit the file by hand")`.
- Verify 2 (no collateral rewrite): after dumping, compare `text.splitlines()` with the output's lines using `difflib.SequenceMatcher`. Allowed opcodes: `equal`; `insert`; `replace` of exactly one old line by one new line, only when that old line holds the flow-style mapping that received the key. Anything else raises `OpInputError(f"{key}: adding would rewrite other lines; edit the file by hand")`.

### 2. `ops/edit.py::set_op`
`set_op` gains one keyword parameter: `also: list[str] = None` (CLI: repeatable `--also KEY=VALUE`; MCP/Studio: a list of strings). Pairs = `[(key, value)] + each also item split on its first '='`. No '=', or an empty key -> `OpInputError("--also needs KEY=VALUE")`; a repeated key -> `OpInputError`.
Steps:
- `before = yaml.safe_load(text)`.
- For each pair in order, on the working text:
  - if the key exists (`pdledit.exists` on the working data): `pdledit.patch_text`;

- Then call `pdledit.check_schema(before, yaml.safe_load(working), key)` once. It is unchanged, and a `required` error is NOT tolerated.
- Any error leaves both files exactly as they were (nothing is written before the check).
- CHANGELOG gets one entry per pair, in order (`old: null` for created keys).
- The single-pair "unchanged" shortcut stays.
- Write `plane.yaml`, then CHANGELOG, as today.
