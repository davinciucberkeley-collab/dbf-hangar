## Exact steps and outputs
Existing parameters keep their meaning; with every new parameter at its default the output must be identical to today (existing `test_fuselage_loft_frustum` stays green unchanged). New optional parameters (`ParamSpec` in the registration):
- `nose_length`: number, default `0`, minimum `0`; `tail_length`: same.
- `nose_shape`, `tail_shape`: choice `cone | ellipsoid | ogive`, default `cone`.
- `tail_upsweep_deg`: number, default `0`, minimum `0` (check: `< 60`).
- `tip_frac`: number, default `0.02` (check: `0 < tip_frac < 0.5`): the cap ends in a flat disc this fraction of the end station's size (a point would not loft watertight).
- `cap_rings`: int, default `8`, minimum `2`.
- `shape` gains the choice `superellipse`; `exponent`: number, default `2.5` (check: `exponent > 1`).
Algorithm. Profile `f(t)`, `t` in [0,1], `t = 0` at the tip: cone `f = t`; ellipsoid `f = sqrt(1 - (1 - t)**2)`; ogive `f = sin(pi * t / 2)`. Scale `s(t) = max(tip_frac, f(t))`, with `s` for cone computed as `tip_frac + (1 - tip_frac) * t` (so a cone chain is one exact frustum). `n = cap_rings`.
- Nose (if `nose_length > 0`): sections for `k = 0..n-1` at `x = x0 - nose_length * (1 - k/n)` with `t = k/n`, each the first station's width and height times `s(t)`; they come before the original stations. `x0` is the first station's x.
- Tail (if `tail_length > 0`): sections for `k = 1..n` at `x = x_last + tail_length * k/n`, `t = 1 - k/n`, size = last station times `s(t)`, section centre z raised by `(x - x_last) * tan(radians(tail_upsweep_deg))`; they come after the original stations.
- Section loops: `ellipse` and `rect` exactly as today (48-gon ellipse). `superellipse`: for `k = 0..47`, `a = 2*pi*k/48`, `y = cy + w/2 * sign(cos a) * abs(cos a) ** (2/exponent)`, `z = cz + h/2 * sign(sin a) * abs(sin a) ** (2/exponent)` (`cy`, `cz` as for the other shapes, with the upsweep added to `cz` on tail sections).
- One `kernel.loft("x", sections)` as today; stations stay strictly increasing (the checks already enforce it for the given stations).

## Exact tests
`tests/test_shapes_fuselage.py`, helper `build(name, params)` as in `tests/test_generators.py`. Let `A(w, h) = 0.5 * 48 * (w/2) * (h/2) * sin(2*pi/48)` (A(40,20) = 626.5258).
- `test_default_unchanged`: stations `[[0,40,20],[100,20,10]]` -> volume `36547.33` rel 1e-5 (as today).
- `test_cone_nose_and_tail_volume`: stations `[[0,40,20],[100,40,20]]`, `nose_length 30`, `tail_length 50` (shapes cone, defaults else). Expected `A*100 + A*30/3*(1 + 0.02**2 + 0.02) + A*50/3*(1 + 0.02**2 + 0.02)` = 79700.8, rel 1e-4; `is_watertight`; x bounds `-30.0` and `150.0` (abs 1e-6).
- `test_ellipsoid_nose_is_about_two_thirds`: same stations, `nose_length 30`, `nose_shape ellipsoid`, `cap_rings 16`: nose part (volume minus `A*100`) is within 2 percent of `2/3 * A * 30` (= 12530.5), and equals the frustum-chain sum `sum(L/n/3 * A*(s0**2 + s1**2 + s0*s1))` over consecutive rings, with `s` from the formula above, rel 1e-4.
- `test_upsweep_keeps_volume_and_lifts_tail`: tail cone 50 with `tail_upsweep_deg 10` has volume equal to the same without upsweep (rel 1e-6) and `bounds[1][2] ==` `50*tan(radians(10)) + 10*0.02` (abs 1e-4; 10 = half the 20 mm height).
- `test_superellipse`: stations `[[0,40,20],[100,40,20]]`: `exponent 2.0` volume equals `shape ellipse` (rel 1e-9); `exponent 4.0` volume lies strictly between the ellipse and the `rect` volumes of the same stations; bounds y `+-20`, z `+-10` (abs 1e-6).
- `test_new_param_validation`: `tip_frac 0.7`, `exponent 1.0`, `tail_upsweep_deg 75`, `nose_length -1` each give a non-empty `validate_params` list naming the parameter.
