## Exact steps and outputs
### 1. Core: `parts.json`
In `core/hangar/index.py`:
- Add `def parts_json(design) -> dict:` returning `{"design": <id>, "root": <root id>, "parts": [...], "attachments": [...]}`. Use `design.components` (resolved expressions, not `design.data["components"]`) and `design.data.get("attachments", [])`, `design.data.get("root")`.
  - Tree: breadth-first from `root` along attachments, `parent -> child` (directed); the first parent that reaches a child wins; depth = distance from root; a visited set stops loops. Root: `parent None`, `depth 0`. Components not reached: `parent None`, `depth 0`.
  - Each part, in `design.components` order: `{"id", "type", "parent", "attachment", "depth", "articulated", "position_mm", "position_expr", "has_cavities", "visual_only", "local_only"}`: `attachment` = the id (or `f"{parent}->{child}"` when the attachment has no id) of the attachment that reached it, else `None`; `articulated` = `bool(att.get("articulation"))` for that attachment; `position_mm` = `[float(v) for v in c["position"]]` (3 numbers; `[0.0, 0.0, 0.0]` when absent); `position_expr` = the RAW component (from `design.data["components"]`, matched by id) has a string in its `position` list (a `"$name"` expression; B5 warns because Apply would replace it with numbers); `has_cavities` = `bool(c.get("cavities"))` (B5 warns that cavities stay where they are); `visual_only` = `bool(c.get("visual_only", False))`; `local_only` = the component uses a library part whose overlay is present: `g = c.get("geometry") or {}`, `g.get("generator") == "library_part" and (g.get("params") or {}).get("part") in set(overlay.design_overlay_parts(design))` (import `overlay` as `design_entry` already does).
  - `attachments`: every attachment as `{"label": a.get("id") or f"{a['parent']}->{a['child']}", "parent": a["parent"], "child": a["child"]}` (this is the `joint` label the check rows carry).
- In `design_entry`, right after the `mass` file is written: `(out_dir / f"{fid}.parts.json").write_text(dumps(parts_json(design)) + "\n")` and add `"parts": f"{fid}.parts.json",` to the entry dict next to `"mass"`. In `error_entry` add `"parts": None,`.
- Nothing else in core changes. `build-index --out` (Pages) writes the same file.

### 4. Tree (`viewer/ui/tree.js`)
`export function renderTree(ctx, d, parts)`: fills `#parts-tree`. `parts` is the fetched `parts.json` (use `getJSON(d.parts)`); when `d.parts` is missing (old index) show `<p class="muted">No part list for this design.</p>`.
- Header: filter input `data-testid="tree-filter"` (matches id or type, case-insensitive), buttons `Show all` (`data-testid="tree-show-all"`).
- Body: nested `<ul>` built from `parent`. Top level: the root part's subtree first; then a group row `Unattached` (class `part-group`, expanded) containing every part with `parent === null` that is not the root and not `visual_only`; then a group row `Wiring` containing every `visual_only` part (empty group not shown).
- Row = `<li class="part-row" data-id="<id>" aria-selected="false" data-hidden="0" data-type="<type>">` with: caret button when it has children (click toggles that subtree; default expanded for depth < 2, collapsed deeper), eye button (`class="eye" data-testid="eye-<id>"`, click toggles hide of that part only), label `<id>` and a small muted `<type>`. Rows of parts not present in the GLB (point masses: `vp.state().all` lacks the id) get class `no-mesh` and a disabled eye.
- Click on a row (not on caret or eye): select it (Ctrl or Meta held: add or remove from the selection). Double-click: select and frame. Both call the single selection setter of step 6.
- Selected rows scroll into view (`scrollIntoView({block: "nearest"})`) when selection changes from the viewport.
- Rows must update from the viewport state: export `syncTree()` that sets each row's `aria-selected` and `data-hidden` from `vp.state()`; app.js calls it after every selection or visibility change.

### 6. Selection (one setter) (`app.js`, `vp/scene.js`, `vp/pick.js`)
- `Viewport.select(ids, { add = false } = {})`: sets `this.selection` (a `Set`, only ids in `this.ids`), calls the existing `highlight` machinery with it (same visual as today: emissive tint, others dimmed), `this.onSelect?.(this.selection)`. `app.js` `setHighlight(ids)` becomes a thin wrapper: `vps.main?.select(ids)`/compare viewports as today. Compare mode keeps single-id highlight behaviour.
- `pickAt` (pick.js): the hit list is filtered by `isPickable(object)`: not pickable when the component node or any ancestor has `visible === false` (three's Raycaster does not test `visible` itself). `onPick(id, vp, event)` receives the original pointer event; app.js `onPick` implements: id null and no Ctrl -> clear; Ctrl or Meta -> toggle id in the selection; plain -> select only that id (clicking the sole selected part again clears it, as today).
- `Esc` (document keydown, not inside an input) clears the selection. A `dblclick` on the canvas selects the part under the cursor and calls `fitTo(ids)`.

### 7. Hide, isolate, show all (`vp/scene.js`, `app.js` keys)
- `Viewport.setHidden(ids, hidden)` sets `node.visible = !hidden` on the component node (`model.getObjectByName(id)`) for each id; keeps `this.hidden` (Set); hidden parts are not pickable (step 6) and do not count in `fit`. `isolate(ids)` hides every drawn id not in `ids`; `showAll()` clears `hidden`. Each call sets `dirty` and `onSelect`-style notifies app.js, which calls `syncTree()` and re-renders the inspector.
- Keys (document keydown, ignored inside input, textarea, select): `h` hides the selection, `i` isolates it (nothing selected: no-op), `H` (Shift+h) shows all. The toolbar buttons are B7's; the tree header has `Show all` (step 4) and each row an eye.

### 8. Views, fit, damping (`vp/scene.js`, `#view-bar`)
- `controls.enableDamping = true; controls.dampingFactor = 0.12`; in `tick()` call `if (this.controls.update()) this.dirty = true;` before the render check (on-demand rendering stays: no update while idle).
- `fitTo(ids)`: `Box3` over the visible nodes of `ids` (empty or all: over the model), camera distance = `max(size.x,size.y,size.z) / (2 * tan(fov/2)) * 1.4`, keep the current view direction, target = box centre; animate in 250 ms with `requestAnimationFrame` setting `dirty` each frame (a second call cancels the first).
- `view(name)`: `iso` (direction `(0.9, 0.55, 1.1)`, up `(0,1,0)`), `front` (camera on scene +x: the nose; direction `(1,0,0)`), `back` (`(-1,0,0)`), `top` (direction `(0,1,0)`, `camera.up = (1,0,0)` so the nose points up the screen), `side` (direction `(0,0,1)`), then `fitTo(all)`. Scene axes: body x -> scene x, body z (up) -> scene y, body y -> scene -z.
- `#view-bar` buttons (`data-testid="view-iso"`, `view-front`, `view-top`, `view-side`, `view-fit`) call `view(...)`/`fitTo(selection or all)`.
