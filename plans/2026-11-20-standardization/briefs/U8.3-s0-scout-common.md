## Why
`standards/connection-types.yaml` lists connection types. The gates read these keys per type: `rated_load_n` (ultimate N one joint of that type carries; used by `T2.joint_rf` as the library fallback when a joint's own rating is a placeholder) and, for electrical types, `rated_current_a` (continuous A; used by `T7.electrical_rating`). Types with `source: pending` and no value make those gates SKIP. A value is only accepted with a source you opened. A guess is worse than `pending`.

## What counts as a usable number
- State quantity, unit, the exact test or condition (substrate, direction, temperature, "typical" or "minimum"), and the place (page number and table/section name, or the URL plus section heading). One short quoted phrase (a few words) at most; paraphrase the rest.
- Ratings must be ULTIMATE (breaking) values, not working loads. Prefer a stated minimum over a typical. If the source says "typical" or "not for specification", write that in the Notes cell.
- Load direction matters. Report each direction the source gives (tension, shear, peel, pull-off, torque) and mark which is the lowest. The builder writes the lowest.
- Area- or width-dependent types (tape, adhesive, hook-and-loop): report the stress (N/mm2, kPa) or line load (N/cm) exactly as printed. Do NOT multiply by an area you made up. Only a source that states a force for a stated size (for example "50 lb for this tie") gives a per-joint N.
- Convert units only with exact factors (1 lbf = 4.44822 N, 1 kgf = 9.80665 N, 1 psi = 6.89476 kPa) and show both numbers.
