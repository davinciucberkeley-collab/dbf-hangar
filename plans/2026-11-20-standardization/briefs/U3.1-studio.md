## Decisions
- decided (conductor default, 2026-11-21): mode set shipped in this brief is Designs, Compare, Physics, Stress, Updates, Ledger; Build/BOM/Proofs/Morph/Knowledge deferred (above).
- decided (conductor default, 2026-11-21): no bundler; native ES modules; `viewer/app.js` is the only entry in `index.html`.
- decided (conductor default, 2026-11-21): Playwright goes in the `dev` extra (`"playwright>=1.45"`; the pip package is small, browsers are separate). The browser tests are marked `slow`, so a local `pytest` skips them and CI (`-m ""`) runs them. CI installs chromium in `validate.yml` on both OS; `pages.yml` runs the same file before deploy.
- decided (conductor default, 2026-11-21): the tests need the three.js CDN (`index.html` import map, unchanged). If the CDN or the chromium binary is unavailable the tests skip locally with a reason and FAIL when env `CI` is set, so CI cannot skip silently.
- decided (conductor default, 2026-11-21): `scorecards` in index v2 is a map `{design_id: "<file>.scorecard.json"}` (per-design files stay; Compare and Designs keep fetching them). `mechanisms` is a map `{design_id: "<file>.mechanisms.json"}` of designs that have sweeps.
- decided (conductor default, 2026-11-21): Physics mode in this unit replays the analytic T6 sweep (D15) with the real part motion; "drag parts, frictionless MuJoCo" (R11 stretch) is out of scope and is not started.
- decided (conductor default, 2026-11-21) D-demo: when a design has no `mechanisms` block, `mechanism_sweeps` sweeps each articulated attachment over its `range_deg` as a pseudo-mechanism (id `sweep-<label>`), so concept-a's 2 elevon articulations play in Physics mode for the Dec 2 demo without U2.5d.
- decided (conductor default, 2026-11-21) D-ledger-public: the Pages repo is PUBLIC. The Pages build (`plane build-index`) publishes only these ledger fields: `id, kind, status, owner, summary, due, decided_in`; `summary` is `text` cut at the first newline or period, at most 100 characters (the ledger has no title field). No evidence text, no source, no quotes or transcript excerpts. The local Studio index carries every `Item` field.
- Open: none.
