`wing_panel` (`core/hangar/geom/wing.py`):
- Airfoil reading, adapted from DBF-Combined `redesign/fusion/k09kit.py` `read_dat` (Selig: TE upper to LE to TE lower; Lednicer: counts line, then upper LE to TE, lower LE to TE; returns Selig order, x normalised to chord 1; accepts CRLF and LF). Name it `read_airfoil(path) -> (upper, lower)` (two `(n, 2)` arrays, each LE to TE).
- Params: `airfoil_file` (string, required, design-folder relative; `files` returns it), `span` (number > 0, required, tip to tip), `root_chord` (> 0, required), `tip_chord` (> 0, required), `sweep_le_deg` (default 0), `dihedral_deg` (default 0), `twist_tip_deg` (default 0, positive = nose up at the tip, linear in |y|, about the section quarter chord: `x' = xq + (x-xq)cos(t) + z sin(t)`, `z' = z cos(t) - (x-xq) sin(t)`, `xq = 0.25 * chord`), `z_offset` (default 0: the airfoil datum shift; concept-a uses -5.0), `part` (choice `full|core|elevon`, default `full`), `hinge_frac` (number in (0, 1), default 0.75, used by `core` and `elevon`), `elevon_y` (vec2 `[y0, y1]`, default `[0, 0]`, required non-empty when `part` is `elevon`: `0 <= y0 < y1 <= span/2`, on |y|), `side` (choice `both|right|left`, default `both`; right = +y), `bore_x`, `bore_z`, `bore_d` (numbers; all three or none; `bore_d > 0`; a straight cylinder along y through the whole panel; ignored for `elevon`), `cut_files` (list of strings, default `[]`, design-folder-relative STL/OBJ paths of closed solids; `files` returns `[airfoil_file] + cut_files` so the cache key tracks them; ignored for `elevon`). Each cut mesh is subtracted from the core with `kernel.difference`, after the bore, only when its bounding box intersects the core's; the cut meshes are used exactly as stored (no growth). A cut file that is missing or not watertight is a `GeometryError` naming the file.
- Section loop at chord `c` between chord fractions `x0` and `x1`: stations = cosine-spaced `x0 + (x1-x0)(1-cos(pi*i/48))/2` for i in 0..48 merged with every airfoil x strictly between `x0` and `x1`, de-duplicated and sorted; z by linear interpolation of the airfoil, times `c`; loop = upper surface from `x1` back to `x0`, then lower surface from `x0` to `x1`, dropping a repeated point where upper equals lower (a sharp LE or TE); the closing edge at `x1` (or `x0` for the elevon) is straight. `full`: `x0 = 0, x1 = 1`; `core`: `0 .. hinge_frac`; `elevon`: `hinge_frac .. 1`.
- Placement of the section at spanwise station `y`: chord `c(y) = root_chord + (tip_chord - root_chord) * |y| / (span/2)`; then twist, then shift `x += |y| * tan(sweep_le_deg)`, `z += |y| * tan(dihedral_deg) + z_offset`.
- Solid: `full`/`core` with `side both` = one loft through sections at `y = -span/2, 0, +span/2` (a single watertight solid); `right`/`left` = loft `0 .. +/-span/2`; the bore is subtracted with `kernel.difference` (use bore_d > 8 mm in tests so the faceted radius is above the importer's 4 mm rule). `elevon` = a loft between sections at `y0` and `y1` for each requested side (`both` returns two parts: right then left).
- VERIFIED (importer loft on these loops): rectangular `c = 100`, span 400, `core`, diamond airfoil: 175000.0 mm3 exactly; taper 100 -> 50 over half-span 200: 102083.33 mm3 exactly (frustum formula), unchanged by sweep 10 and dihedral 3; with those, bounds `[[0, -200, -5], [75.0, 200, 12.98]]`; `c = 200`, span 400: 700000.0; elevon triangle `c = 100`, `y 50..150`: 6250 mm3 expected from the loop rule above (the scratch run used a loop that dropped the hinge-lower point and gave 6243.3: the loop rule in this brief includes both hinge points, so expect 6250.0); concept-a: S5010, 245 x 900, hinge 0.75, `z_offset -5`, bore `(60, 0)` d 12: volume 2 950 080 mm3, watertight, bounds `x 0..183.75, y -450..450, z -11.64..12.42` vs the STL `x 0..183.75, y -450..450, z -11.65..12.38` (the STL's bounds were measured on the imported file).
- Not ported (record in the module docstring): `te_min` TE opening of `k09kit.section_loop`, the cove, the explicit pockets and slots of `amodel/wing.py build_wing` (only what `cut_files` removes is cut). Known limit, say it in the docstring: the pockets are the neighbours' meshes as stored, they do not follow a neighbour that is moved later.

`fin` (`parts.py`): flat tapered fin on a plane y = const. Params: `plane_y` (default 0), `thickness` (> 0, required), `root_chord` (> 0), `tip_chord` (> 0), `height` (number, nonzero, required; signed distance from the root along z), `x_le` (default 0), `z_root` (default 0), `sweep_le_deg` (default 0). Outline in (x, z): root LE `(x_le, z_root)`, root TE `(x_le + root_chord, z_root)`, tip TE `(x_le + |height| * tan(sweep) + tip_chord, z_root + height)`, tip LE `(x_le + |height| * tan(sweep), z_root + height)`; extruded in y from `plane_y - thickness/2` by `thickness` (`kernel.prism(plane="xz")`). Volume = `(root_chord + tip_chord) / 2 * |height| * thickness`.

`plate`: Params: `plane` (choice `xy|xz|yz`, default `xy`), `size` (vec2, > 0, required), `thickness` (> 0), `center` (vec3, default `[0,0,0]`), `holes` (list of `[u, v, d]` triples, default `[]`, u and v from the plate centre in the plane's (u, v) axes as `kernel.prism` defines them, d > 0; `check` reports a hole that crosses the outline or another hole). Volume = `size_u * size_v * thickness - sum(ngon_area(d/2)) * thickness`.

`fuselage_loft`: Params: `stations` (list of `[x, width, height]`, at least 2, x strictly increasing, width and height > 0; `check` enforces), `shape` (choice `ellipse|rect`, default `ellipse`: 48-gon with semi-axes width/2 and height/2, or a rectangle), `center_y`, `center_z` (default 0). `kernel.loft("x", ...)` with loops in (y, z). Volume of two similar sections = frustum `L/3 * (A1 + A2 + sqrt(A1*A2))`.

`motor_mount`: Params: `plate_size` (vec2 along y and z, required), `plate_t`, `bolt_pattern` (vec2 `[dy, dz]`, 4 holes at `+/-dy/2, +/-dz/2`), `bolt_d`, `sleeve_od`, `sleeve_id`, `sleeve_len` (all > 0, required), `center` (vec3, default `[0,0,0]`: the centre of the plate's back face). Local frame: plate occupies x in `[0, plate_t]`, sleeve runs x in `[0, plate_t + sleeve_len]`; the thrust axis is then set by the component's `rotation_deg`. Build: plate prism (48-gon bolt holes) union a solid cylinder of `sleeve_od` over `[0, plate_t + sleeve_len]`, minus a bore of `sleeve_id` through everything. `check`: `sleeve_id < sleeve_od`; bolt holes outside the sleeve circle and inside the plate. Volume = `w*h*t - 4*A(bolt_d/2)*t + A(sleeve_od/2)*L - A(sleeve_id/2)*(t + L)` with `A = ngon_area` and `L = sleeve_len`.
- VERIFIED: `fuselage_loft` ellipses `(0, 40, 20)` and `(100, 20, 10)`: 36547.33 mm3 (frustum formula, watertight). `motor_mount` with plate 30 x 30 x 3, bolts 19 x 16 d 2.5, sleeve od 14, id 10, length 20: 3909.98 mm3 (formula 3909.98), watertight, bounds `x 0..23, y -15..15, z -15..15`.

### What the copy is
`plane design copy concept-a concept-a-param` (the op copies the folder without `fea/`, `CHANGELOG.yaml`, `baseline.json`, `import-report.json`), then four components switch from imported meshes to generators and get a shared `parameters` block.
