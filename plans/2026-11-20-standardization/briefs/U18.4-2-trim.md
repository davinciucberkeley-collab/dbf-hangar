### 3. `core/hangar/calcs/trim.py` (SI except where stated; x in mm, forces N, moments N*mm)
Docstring first line `"""U18.4: tail lift and elevator deflection to trim a wing-tail aircraft in level flight (stick-fixed, tail at zero incidence)."""`. Exactly:
- `helmbold_slope(aspect_ratio: float) -> float`: `2*pi*AR / (2 + sqrt(AR**2 + 4))` per rad (the same formula as `slope()` in `core/hangar/checks.py` `tier3_aero`; re-implement, do not import a nested function).
- `trim_tail_lift_n(weight_n: float, load_factor: float, x_cg_mm: float, x_wing_ac_mm: float, x_tail_ac_mm: float, m_ac_nmm: float = 0.0) -> float`: `(m_ac_nmm + load_factor * weight_n * (x_cg_mm - x_wing_ac_mm)) / (x_tail_ac_mm - x_wing_ac_mm)`. Derivation (put in the docstring): moments about the CG, nose-up positive, x aft: `M_ac + L_w (x_cg - x_w) + L_t (x_cg - x_t) = 0` with `L_w + L_t = n W`. Negative result = tail down-force. `x_tail_ac_mm == x_wing_ac_mm` raises `ValueError`.
- `tail_lift_coefficient(tail_lift_n: float, q_pa: float, tail_area_m2: float) -> float`: `tail_lift_n / (q_pa * tail_area_m2)`.
- `elevator_deflection_deg(cl_tail: float, tail_aspect_ratio: float, eta: float, tau: float) -> float`: `degrees(cl_tail / (eta * helmbold_slope(tail_aspect_ratio) * tau))`; negative = trailing edge up.
