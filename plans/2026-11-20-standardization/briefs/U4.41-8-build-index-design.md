## Why (red on main)
`plane build-index --out X --design a400m-rc` -> `Error: No such option: '--design'`. The command exports every design (about 8 minutes with 11 designs) to show one.

## Exact steps (`build_index_cmd`)
1. Add `@click.option("--design", "wanted", multiple=True, help="Design folder name to build (repeatable); default: every design.")` and the parameter `wanted` to the function.
2. Right after the imports in the function (before `out.mkdir`): `designs = list_designs()`; when `wanted` is non-empty: `names = {p.parent.name for p in designs}`; `missing = [w for w in wanted if w not in names]`; if `missing`: `_fail(f"unknown design(s): {', '.join(missing)}; have: {', '.join(sorted(names))}")` (nothing is created); else `designs = [p for p in designs if p.parent.name in wanted]`.
3. Both loops that currently iterate `list_designs()` (the overlay preflight and the build loop) iterate `designs` instead. Nothing else changes: `index.json` then lists only the built designs; the other outputs are as before. The docstring becomes `Export glb, scorecard and mass for every design (or only the --design ones), then write index.json.`
4. Regenerate `docs/cli.md` (`tests/test_cli_doc.py` compares bytes).
