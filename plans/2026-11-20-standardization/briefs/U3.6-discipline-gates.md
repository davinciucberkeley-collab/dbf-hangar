### 5. `core/hangar/gates/discipline.py`
Module docstring one line. Helpers (private):
- `_std(file: str, key: str, note: list[str]) -> value`: calls `resolve_threshold(f"{file}#{key}")` (from `.fidelity`); raises `_Missing(f"{file}#{key}")` when it returns `None` or its `value` is `None`; for a model-input key whose `source` is `pending` appends `f"{file}#{key}"` to `note`. `_crit(file, key) -> (value, pending: bool)` does the same for a criterion key but never appends to `note` and returns `pending = (source == "pending")`. `_prov(note)` returns `"; provisional: " + ", ".join(sorted(set(note))) + " pending"` or `""`. `_judge(check_id, status, numbers, crit_file_key, pending, data, criterion)` returns the PASS/FAIL row, or, when `pending`, a SKIP row with message `f"{numbers}; not judged: {crit_file_key} pending"` and `data | {"would_be": status}`. A `_Missing` caught in a check becomes a SKIP row naming the key.
- `_skip(check_id, why, crit, data)` -> `CheckResult(check_id, SKIP, why, crit, data)`. Every SKIP message names exactly what is missing (a PDL path, a component id, or `<file>#<key>`).
- `_hover(ctx)` -> a dict used by control authority, transition and endurance: `up = _hover_up(design)`; `hover_pose = flight.get("hover_pose")`; `h_ang = pose_angles(design, hover_pose)`; `mp = mass_properties(design, h_ang) if hover_pose else ctx.mp`; `tf = pose_transforms(design, h_ang)`; `posed = posed_component_parts(design, h_ang)`; `lift = _upward_lift(design, tf, up)`; per lift motor `f_i = |force_i| / max_thrust_n` (upward fraction); `W = mp["mass_g"]/1000*G`; `T = W / sum(f_i)` (equal thrust per motor, newtons along each motor's axis); `Tmax_i = max_thrust_n * (1 - pack_sag_fraction)**2`; returns `{"mp","up","posed","lift","T","Tmax": {motor_id: Tmax_i},"f": {motor_id: f_i}}`. Returns `None` when there is no lift motor or `sum(f_i) <= 1e-9` (callers then emit their own SKIP/FAIL as below). Import `_hover_up`, `_upward_lift`, `_subtree_mass`, `G`, `RHO_DEFAULT` from `..checks` inside the functions (circular import).
- `_vtol(design)` -> `design.data["morphology"].get("vtol_method","none") != "none" or design.data["morphology"]["lift"] == "multirotor"`.

Registered checks, each `@discipline_check("<id>", <tier>)` with signature `(ctx, rep)`:

**T2.joint_rf** (tier 2). `n = std["structure"]["landing_load_factor"]["value"] * std["structure"].get("ultimate_factor", {}).get("value", 1.0)` from `ctx.std` (as `tier2_physics`). Library `lib = load_connection_types()`. For each attachment `a` with `"connection" in a`: label `a.get("id") or f"{parent}->{child}"`; `t = lib.get(a["connection"])`; unknown type -> SKIP "connection <id> not in standards/connection-types.yaml"; `t.get("structural", True) is False` -> no row; no `rated_load_n` in `t` -> SKIP "<CT id> has no rated_load_n in standards/connection-types.yaml"; else `load = _subtree_mass(design, a["parent"], a["child"])/1000*G*n`, `rf = t["rated_load_n"]/load`, status PASS if `rf >= joint_rf_min` (`load-cases.yaml`, a criterion key) else FAIL via `_judge`; message `f"{label}: RF {rf:.2f} (rating {t['rated_load_n']} N / load {load:.1f} N at {n}g) vs min {min}"`; `data={"joint": label, "rf": round(rf,3)}`. If the loop produced no rows: one SKIP "no structural attachment declares a connection (attachments[].connection)" with `data={"parts": []}`. Criterion `load-cases.yaml#joint_rf_min`.

**T3.control_authority** (tier 3). Not applicable (no lift motor or `not _vtol`): one SKIP "not applicable: no lift motors or vtol_method none" (never PASS). Else `h = _hover(ctx)`; if `h is None` one FAIL "no lift motor has upward thrust at hover". If `T > Tmax` for any motor: one FAIL `data={"axis":"all"}` "hover thrust {T:.2f} N exceeds the sagged-pack maximum {Tmax:.2f} N". Else per motor: position `p_i` = mean of `part.center_mass` over `h["posed"][motor_id]` (no parts -> SKIP naming the motor); `cg = np.array(h["mp"]["cg_mm"])`; `u_i` = unit thrust axis = `tf[m][:3,:3] @ axis`, normalised; `dT_i = min(Tmax_i - T, T)`; `tau_i = np.cross((p_i - cg)/1000, u_i)`. Axes (body frame, as `T2.hover_moment`): `yaw = up`; `h0 = [0,1,0] - ([0,1,0]·up)*up` (use `[0,0,1]` if its norm < 1e-6), `pitch = h0/|h0|`, `roll = cross(up, pitch)`. `M_axis = sum(|tau_i . e_axis| * dT_i)` (N*m). Wind: `rho = flight.air_density_kgm3` default `RHO_DEFAULT`; union bounds of every non-empty posed part -> `lo, hi`; `ext = hi - lo` (mm); `ext_up = sum(|up_k| * ext_k)`; `ext_h(e) = sum(|e_k| * ext_k)`; `S = max(ext_h(pitch), ext_h(roll)) * ext_up / 1e6` (m2); `lever = max(abs(((lo+hi)/2 - cg) . up), wind_moment_min_lever_fraction * ext_up) / 1000` (m); `M_wind = 0.5*rho*hover_wind_mps**2 * wind_drag_coefficient * S * lever`. No parts at all -> SKIP "no geometry for the wind moment". One row per axis (pitch, roll, yaw), same `check_id`, `data={"axis": name}`: ratio `M_axis/M_wind`, PASS if `>= hover_ctrl_factor` else FAIL (via `_judge`); message `f"{axis}: control moment {M_axis:.3f} N*m, wind moment {M_wind:.3f} N*m, ratio {r:.2f} vs min {factor} (sagged pack, differential thrust, cant geometry only)"` + provisional note.
