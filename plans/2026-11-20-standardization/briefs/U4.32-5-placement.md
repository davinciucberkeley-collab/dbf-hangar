## Exact steps and outputs
1. `wing_panel` new optional params: `placement` (choice `none|high|mid|low`, default `none`), `fuselage_height` (number, default `0`, min 0), `fuselage_center_z` (number, default `0`).
2. Meaning: the airfoil chord-line datum at the root is moved to the fuselage's top (`high`), centre (`mid`) or bottom (`low`) plane: extra z offset `= fuselage_center_z + fuselage_height/2` (high), `fuselage_center_z` (mid), `fuselage_center_z - fuselage_height/2` (low), added to the existing `z_offset`. Implement at the start of `_build` as `p = {**p, "z_offset": p["z_offset"] + _placement_z(p)}`; `placement none` adds exactly `0.0`, so every existing design is bit-identical.

4. Schema text: the generator description names the registered generators; make it read `wing_panel, tube, fin, plate, fuselage_loft, motor_mount, mesh_file, library_part, nacelle, propeller, strut, landing_gear, tail_surfaces` (keep the rest of that sentence; if the text has no such list, stop).
