**Step 5. `core/hangar/migrate.py`.** Exact public names:
```python
KNOWN_VERSIONS = ("0.1", "0.2", "0.3", "0.4", "1.0")

Rules for `migrate` (deep-copy the input first; never mutate it):
- `schema_version` missing or not in `KNOWN_VERSIONS` → `ValueError(f"unsupported schema_version {v!r}; known: 0.1, 0.2, 0.3, 0.4, 1.0")`.
- `"1.0"` → `(copy, ["already 1.0"])`.
- `"0.1"`, `"0.2"`, `"0.3"`, `"0.4"` (same rule for all four) → set `schema_version` to `"1.0"`, change nothing else; notes are `[f"schema_version {old} -> 1.0", "no fields added, removed or renamed (all 1.0 blocks are optional)"]`.

`bump_version_text(text)` works on the raw file text (read with `read_bytes().decode("utf-8")`, so CRLF is still in it) and replaces the one top-level line with `re.compile(r'^(schema_version:[ \t]*)(["\']?)(0\.[1-4])\2([ \t]*(?:#[^\r\n]*)?)(\r?)$', re.M)` using replacement `r'\1"1.0"\4\5'`. Zero matches, more than one match, or text already at `"1.0"` → `ValueError` naming the cause. It must not use ruamel or `yamlio`: re-dumping would reflow the file and change the stored FEA hashes.

**Step 6. `core/hangar/pdlref.py`** (the reference generator; pure and deterministic, LF only):
```python
def build_reference(schema: dict | None = None) -> str: ...      # schema defaults to json.loads(SCHEMA_PATH.read_text(encoding="utf-8"))
def write_reference(out: Path) -> Path: ...                       # out.parent.mkdir(parents=True, exist_ok=True); out.write_bytes(build_reference().encode("utf-8")); return out
```
Output layout of `build_reference` (blank line = empty line; file ends with exactly one `\n`; join with `"\n"`):
1. `# {schema["title"]} reference`
2. `<!-- GENERATED by schema.docs (plane schema docs) from schema/plane.schema.json. Do not edit by hand. -->`
3. `{schema["description"]}`
4. `## Top-level fields`, then a table (`| Field | Type | Required | Description |` and `|---|---|---|---|`) from `rows(schema, "")`.
