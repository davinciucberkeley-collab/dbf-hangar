## Why (red on main, 2026-11-24)
A design whose wing is `generator: wing_panel` and which has no `planform` gives `T3.stall FAIL: no lifting surface found on a winged design` (the fixture below, tier 3: `T3.stall` FAIL, `T3.wing_loading` and `T3.cruise_stall_ratio` WARN "T3.stall not available", no `T3.static_margin` row). The A400M rehearsal copied the numbers into `components[wing].planform` by hand (same values twice; they drift) and its `tail_surfaces` part, one fused mesh of stabiliser and fin, could carry none, so `T3.static_margin` saw the wing alone (-6.7 % MAC) although the tail makes the aircraft stable.

## Rule (the only definition)
In `_tier3` of `core/hangar/checks.py` (the loop that builds `surfaces`, currently `for c in design.components:` with the `lifting_surface` and `planform` branches), add a third branch, tried only when the component has neither `lifting_surface` geometry nor a declared `planform`:
- Call `generated_planform(c)` (new, below). `None` -> `continue` as today.
- `{"measured": True}` (a `wing_panel` wing) -> exactly the existing planform branch's measurement: `p = strip_planform(_planform_parts(design, c)[1], c["id"], n=n_strip, gap_tol=..., control_frac=...)` with the same standards keys, `ls_c = c`.
- `{"lifting_surface": {...}, "offset": [dx, dy, dz]}` (a `tail_surfaces` tail) -> `pseudo = {**c, "geometry": {"lifting_surface": result["lifting_surface"]}, "position": [c["position"][0] + dx, c["position"][1] + dy, c["position"][2] + dz]}`; `p = lifting_surface_properties(pseudo, c_tf[c["id"]] if cruise_pose else None)`; `p["span_mm"] = result["lifting_surface"]["span"]`; `ls_c = c`.
Nothing else in `_tier3` changes: the later code already picks the largest-area surface as the wing, applies the aft-surface efficiency and downwash to the others, and builds the `T3.static_margin` message (`main_from_planform` stays defined by `"planform" in main_c`; for a generated wing it is False and the message has no "mesh wing" suffix; keep that).

`core/hangar/geom/planform.py` (new), one public function:
```python
def generated_planform(component: dict) -> dict | None:
    """Aero outline of a generated wing or tail, or None when the component is not one that tier 3 can read."""
```
- `g = component.get("geometry") or {}`; return None unless `g.get("generator")` is set. Fill defaults with `fill_defaults(get(name), g.get("params") or {})` (from `hangar.geom.registry`; `import hangar.geom` first so generators are registered).
- `wing_panel` and `component["type"] == "wing"`: return `{"measured": True}` when `part in ("full", "core")` and `side == "both"`; else None (an `elevon` piece or a single side is not a whole wing).
- `tail_surfaces` and `component["type"] == "tail_surface"`: return `{"lifting_surface": {"span": stab_span, "root_chord": stab_root_chord, "tip_chord": stab_tip_chord, "sweep_le_deg": stab_sweep_le_deg, "mirrored": True}, "offset": [stab_x_le, 0.0, stab_z]}` (the stabiliser only; the fin is not a lifting surface here; layout `v` uses the given span as is, its horizontal projection).
- anything else -> None. Never raise: any exception -> None.
