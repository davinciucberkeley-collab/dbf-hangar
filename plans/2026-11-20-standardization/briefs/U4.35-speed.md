## Exact steps and outputs
1. Create `core/hangar/yamlfast.py` with exactly one public function:
   ```python
   def safe_load(stream):
       """yaml.safe_load using libyaml's C loader when PyYAML has it, else the pure-Python SafeLoader. Same data either way."""
   ```
   Implementation: `import yaml`; `_LOADER = getattr(yaml, "CSafeLoader", yaml.SafeLoader)`; return `yaml.load(stream, Loader=_LOADER)`. No other names, no `__main__`.
2. In each of these files add `from hangar import yamlfast` (match the file's existing import style; use a relative import where the file already uses relative imports) and replace every call `yaml.safe_load(` with `yamlfast.safe_load(`: `core/hangar/ops/edit.py`, `core/hangar/geom/resolve.py`, `core/hangar/pdledit.py`, `core/hangar/design.py`. Keep `import yaml` where `yaml` is still used (`yaml.YAMLError`, dumps); remove it only if now unused. Do not touch `core/hangar/geom/materials.py` or any other file's `safe_load`.
3. Create `tests/test_yamlfast.py` with these tests:
   - `test_same_data_as_safeloader_on_every_design`: for each `designs/*/plane.yaml` and `standards/*.yaml` (glob from the repo root via `Path(__file__).resolve().parents[1]`), `yamlfast.safe_load(text) == yaml.load(text, Loader=yaml.SafeLoader)` and the `type` of every scalar leaf matches (compare `json.dumps(x, sort_keys=True, default=str)` of both).
   - `test_falls_back_without_libyaml`: monkeypatch `yamlfast._LOADER` to `yaml.SafeLoader`; the result for `designs/concept-a-param/plane.yaml` is equal to the default result.
   - `test_yaml_error_is_yamlerror`: `yamlfast.safe_load("a: [1, 2")` raises `yaml.YAMLError`.
   - `test_design_set_result_unchanged_concept_a_param`: copy `designs/concept-a-param` to `tmp_path`, run `call("design.set", path=str(d), key="parameters.span_mm", value="820", why="t")` (import `call` as `tests/test_concept_a_param.py` does), and assert `r.ok`, `r.data["regenerated"]` ids are `fin-001-l, fin-001-r, wng-001, wng-002` (sorted) and the file bytes `d/"plane.yaml"` equal those produced with `yamlfast._LOADER` monkeypatched to `yaml.SafeLoader` on a second fresh copy (also compare `CHANGELOG.yaml` after removing the `date:` lines, and compare the message list, rows, masses and `d/"meshes"` file bytes of both copies). Do the same at value `900` with a copy where the starting span is first set to 820 through the same call.
