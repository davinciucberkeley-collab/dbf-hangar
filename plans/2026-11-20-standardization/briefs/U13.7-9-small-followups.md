## Part C (T148)
### C1. Overlay note only when a manifest exists
Red on main: `cli.py` prints `note: CAD overlay ignored here ...` whenever `overlay.overlay_configured()` is true, i.e. whenever `~/parts-cad` (or the configured folder) exists, even when it holds no `overlay.yaml` (the default folder exists on Tristan's PC from the day the first CAD files were downloaded, and would exist empty on any teammate who creates it).
Steps: in `overlay.py` add `def manifest_count() -> int`: the number of `<root>/*/overlay.yaml` files under `_configured_root()` (0 when there is no root; unreadable folder -> 0), and `def ignored_note() -> str | None`: the text `note: CAD overlay ignored here (baselines and FEA results never use licensed files)` when `manifest_count() > 0`, else `None`. In `cli.py` replace both `if overlay.overlay_configured(): click.echo("note: ...", err=True)` blocks (baseline update and baseline check) by `note = overlay.ignored_note()` / `if note: click.echo(note, err=True)`. `overlay_configured()` and `forced_off()` stay as they are (the existing tests use them).
### C2. Replace the `_PAIR_PASS` module flag by a parameter
`core/hangar/importers/dbf_geometry.py` keeps a module global `_PAIR_PASS`, toggled by `part_mesh` around its first attempt. Thread it as an argument instead; results must stay byte-identical. Steps (exactly these signatures; every new parameter has the default `True`, so `kernel.py` and every other caller are unchanged):
1. `_separate_pinches(vertices, faces, pair_pass: bool = True)`: `if not pair_pass: return out` replaces `if not _PAIR_PASS: return out`.
2. `_from_manifold(man, pair_pass: bool = True)` passes it to `_separate_pinches`; `_boolean(op, meshes, pair_pass: bool = True)` passes it to `_from_manifold`.
3. `_part_mesh(comp, pair_pass: bool = True)` passes `pair_pass=pair_pass` to its three `_boolean(...)` calls (the union and the two difference calls).
4. `part_mesh(comp)` becomes: `try: return _part_mesh(comp, pair_pass=False)` / `except GeometryError: return _part_mesh(comp, pair_pass=True)`; delete `global _PAIR_PASS`, the `finally` block and the module line `_PAIR_PASS = True ...` (keep the explanatory sentence as a comment on `part_mesh`).
5. `tests/test_u135_reimport_identity.py`: in `test_part_mesh_tries_without_pair_pass_first` the spy becomes `def spy(comp, pair_pass=True): seen.append(pair_pass); return real(comp, pair_pass)` and the final assertion `assert seen == [False, True]` (drop `and geo._PAIR_PASS is True`); in `test_fixture_needs_and_gets_the_pair_pass` drop `and geo._PAIR_PASS is True` (keep `assert geo._closed(mesh)`).
