**`core/hangar/ops/research.py`**
- `SLUG_RE = re.compile(r"^[a-z0-9][a-z0-9-]*$")`.
- `@op(name="research.new", summary="Create knowledge/sources/<slug>.md or knowledge/diy-projects/<slug>.md from its template.", mutates=True, render=lambda r: r.data["path"])` `def new_op(kind: Literal["source", "diy"], slug: str)`. Bad slug -> `OpInputError`. Template `knowledge/TEMPLATE-source.md` (source -> `knowledge/sources/`) or `knowledge/TEMPLATE-diy-project.md` (diy -> `knowledge/diy-projects/`), read as text, first line `id: <kebab-case-slug>` replaced by `id: <slug>` (use `text.replace("id: <kebab-case-slug>", f"id: {slug}", 1)`); target exists -> `OpInputError`; template missing -> `OpInputError`. Write with `newline="\n"`. `data={"path": rel}`, `changed_files=[rel]`.
- `@op(name="research.check", summary="List the frontmatter fields and sections of a knowledge entry that are still empty or still the template placeholder.", render=...)` `def check_op(path: str)`. File missing -> `OpInputError`. Split frontmatter: text must start with `---`; the frontmatter is between the first two lines equal to `---`; `yaml.safe_load` it (error or non-mapping -> `OpInputError`). Kind: `"diy"` if the frontmatter has key `source_url`, else `"source"`.
  Required keys: source -> `id title authors year url type retrieved verified`; diy -> `id title source_url source_type creator date retrieved configuration outcome outcome_evidence verified`.
  Required sections (text after `## <heading>` up to the next line starting `## ` or end of file): source -> `Summary`, `Usable rules / numbers`, `How we could use it`; diy -> `What's novel`, `How it was built`, `Problems and fixes`, `Lessons for us`.
  A key is missing if absent, `None`, an empty string, a string starting with `<`, or a string containing ` | ` (an unchosen template alternative such as `paper | standard`); `id` is also missing if it differs from the file name without `.md`. A section is missing if the heading is absent or its stripped body is empty or starts with `<`. `missing_fields` = missing keys (as the key name) then missing sections (as `section:<heading>`), in the order above. `ok = not missing_fields`; `data={"kind": kind, "missing_fields": [...]}`; `messages=["ok"]` or `["missing: " + ", ".join(...)]`; render `"\n".join(r.messages)`. (ok False without an `error` key exits 1.)

**`core/hangar/ops/morph.py`** — chart file `knowledge/morphological-chart.yaml`.
- `@op(name="morph.add-option", summary="Add one option to a dimension of the morphological chart (source must be an entry in knowledge/sources/).", mutates=True, render=lambda r: r.data["line"])` `def add_option(dimension: str, id: str, name: str, source: str)`. Checks (each -> `OpInputError`): `id` and `source` match `^[a-z0-9][a-z0-9-]*$`; `name` non-empty; `knowledge/sources/<source>.md` exists; chart loads with `yaml.safe_load`; `dimension` is the `id` of an entry in `dimensions`; `id` is not already an option id in that dimension. Edit by text, not by re-dumping YAML: `lines = text.splitlines(keepends=True)`; `start` = index of the line whose `rstrip()` equals `f"  - id: {dimension}"`; `end` = index of the next line starting with `  - id:` after `start`, or `len(lines)`; `last` = highest index in `[start, end)` whose line starts with `      - {` (none -> `OpInputError("dimension has no flow-style options to extend")`). New line `f"      - {{id: {id}, name: {json.dumps(name)}, source: {source}}}"` plus the file's line ending (`\r\n` if `"\r\n" in text` else `\n`); if `lines[last]` does not end with a newline add one first. Insert after `last`. Write with `write_bytes(("".join(lines)).encode("utf-8"))` (read with `read_bytes().decode("utf-8")`) so no other byte changes. `data={"path": chart rel path, "line": new line stripped}`, `changed_files=[chart rel path]`.
- `@op(name="morph.coverage", summary="For every dimension and option of the chart, which designs use it.", render=...)` `def coverage_op()`. Load the chart; for each design file `root/designs/*/plane.yaml` (sorted; `yaml.safe_load`; skip files that fail to load) take `data["id"]` (fallback folder name) and `data.get("morphology") or {}`. `cells` = one `{"dimension": dim_id, "option": option_id, "designs": [design ids whose morphology.get(dim_id) == option_id (compare as str)]}` for every dimension x option, in chart order. `data={"cells": cells}`; render one line per cell `f"{dimension}/{option}: {', '.join(designs) or '-'}"`.

**`core/hangar/ops/bom.py`**
- Helper `_load(path)`: `p = pdledit.resolve_design_path(path)` (`from .. import pdledit`); not a file -> `OpInputError`; `data = yaml.safe_load(text)`; `items = ((data.get("bom") or {}).get("items")) or []`; no items -> `OpInputError("design has no bom.items")`.
- `@op(name="bom.verify", summary="Record that someone verified a BOM line (browser, datasheet or in-hand). Records only; the CLI never scrapes a shop.", mutates=True, render=lambda r: r.data["line"])` `def verify_op(path: str, item: str, method: Literal["browser", "datasheet", "in-hand"], evidence: str, by: str)`. Checks (each -> `OpInputError`): `evidence` and `by` non-empty; `item` is the `id` of a bom item; that item has no `verified` key (message `already verified by <by> on <date>; edit by hand`). Locate the item with ruamel: `from ruamel.yaml import YAML; root = YAML().load(text); start = root["bom"]["items"].lc.item(index)[0]` (0-based line of the item's first line). `lines = text.splitlines(keepends=True)`. If `lines[start].lstrip().startswith("- {")` -> `OpInputError("flow-style bom line; edit by hand")`. Block style: `dash = len(lines[start]) - len(lines[start].lstrip())`; `last = start`; for `n` from `start + 1` while `n < len(lines)`: a non-blank line with indent `<= dash` ends the block (break); a non-blank line with indent `> dash` and not starting with `#` after strip sets `last = n`. Insert after `lines[last]` (add a newline first if it lacks one) the line `" " * (dash + 2) + 'verified: {by: <json.dumps(by)>, date: "<today>", method: <method>, evidence: <json.dumps(evidence)>}'` plus the file's line ending, `today = date.today().isoformat()`. Then `after = yaml.safe_load(patched)`; the item's `verified` must equal `{"by": by, "date": today, "method": method, "evidence": evidence}` else `OpInputError`; run `pdledit.check_schema(yaml.safe_load(text), after, f"bom[{item}].verified")`. Write `write_bytes(patched.encode("utf-8"))`. `data={"path": rel-or-given path string, "item": item, "line": inserted line stripped}`, `changed_files=[the plane.yaml path as given]`.
- `@op(name="bom.cost", summary="Total cost of a design's BOM and which lines lack a cost or a verification.", render=lambda r: ...)` `def cost_op(path: str)`. `total = sum(qty * unit_cost_usd)` over items that have `unit_cost_usd`, `round(total, 2)`; `missing_cost` = ids without `unit_cost_usd`; `unverified` = ids without `verified`. `data={"total_usd", "costed": n, "missing_cost": [...], "unverified": [...]}`; render `f"total ${total_usd:.2f} ({costed} lines costed; {len(missing_cost)} without cost; {len(unverified)} unverified)"`.
