## Exact steps and outputs
1. `_png.py`: `decode(path) -> (width, height, gray)`, `gray` a list of rows of ints 0-255. Non-interlaced 8-bit colour types 0, 2, 3 (palette), 4, 6 via `zlib` and PNG filters 0-4. Alpha below 128 counts as white (255). Anything else (interlaced, 16-bit, bad signature, `width*height > 25_000_000`) raises `ValueError` naming the cause (`interlaced`, `16-bit`, `not a PNG`, `too large`). Gray = `(r*299 + g*587 + b*114)//1000`. Read-only.
2. `reference.py`, helper `_ink(gray, threshold, dark_on_light)`: a pixel is ink when `gray < threshold` (default 128) if `dark_on_light` (default true), else `gray >= threshold`.
3. `reference.views(image: str, threshold: int = 128, dark_on_light: bool = True, min_gap: int = 5)`: split ink into bands by blank row runs of at least `min_gap` rows, then each band into blocks by blank column runs of at least `min_gap` columns. Blocks with fewer than 20 ink pixels are dropped and counted. Returns `{"image_px": [w, h], "views": [{"box": [x0, y0, x1, y1], "ink_px": n}], "dropped_small": k}`; boxes are tight to the ink, inclusive pixel indices, in reading order (bands top to bottom, blocks left to right).
4. `reference.measure(image: str, known_axis: str, known_m: float, box: str = "", rotate_deg: float = 0.0, ignore_cols: str = "", ignore_rows: str = "", stations: int = 21, threshold: int = 128, dark_on_light: bool = True)`:
   - `box` is `"x0,y0,x1,y1"` inclusive pixels (empty = whole image); malformed or outside the image gives `OpInputError`.
   - `known_axis` is `"width"` or `"height"` (else `OpInputError`); `known_m > 0`; `stations >= 2`.
   - Order: select ink inside `box`; remove ink in `ignore_cols` / `ignore_rows` (strings `"a-b,c-d"`, inclusive image pixel ranges); rotate; measure. Rotation: each ink pixel `(x, y)` is rotated by `-rotate_deg` degrees about the centre of `box` (y down; positive `rotate_deg` means the drawing is tilted clockwise on screen) and rounded to integers; `rotate_deg == 0` skips it.
   - Ink bounding box `min_x, min_y, max_x, max_y`; `w_px = max_x - min_x + 1`, `h_px = max_y - min_y + 1`; `scale_m_per_px = known_m / w_px` (width) or `known_m / h_px` (height).
   - `data`: `{"scale_m_per_px", "width_m", "height_m", "bbox_px": [min_x, min_y, max_x, max_y], "ink_px", "origin": "left edge and bottom edge of the ink", "column_stations": [{"x_m", "top_m", "bottom_m"}], "row_stations": [{"y_m", "left_m", "right_m"}]}`. `width_m = w_px * scale`, `height_m = h_px * scale`. Column stations: `stations` columns evenly spaced including both edges (`col = round(min_x + i*(w_px-1)/(stations-1))`); `x_m = (col - min_x)*scale`; `top_m`, `bottom_m` = `(max_y - row)*scale` for the first and last ink row of that column; a column without ink gives `null` for both. Row stations mirror this: `y_m = (max_y - row)*scale`, `left_m`, `right_m` = `(col - min_x)*scale` of the first and last ink column. All metres rounded to 4 decimals.
   - `render`: line `width W m x height H m (scale S m/px)`, then the column stations as a table.
