### 3. `core/hangar/gates/stability.py`
Docstring first line `"""U18.4: tail volume coefficients (and, in later briefs, trim and dynamic modes) for fixed-wing designs; thresholds in standards/stability.yaml."""`. Imports: `math`, `numpy as np`, `from ..design import PASS, SKIP, WARN, CheckResult`, `from ..geometry import lifting_surface_properties, rotation_matrix`, `from . import discipline_check`, `from .applicability import skip_row`, `from .fidelity import resolve_threshold`. Constants `ST = "stability.yaml"`.
Functions (module level, public names used by later briefs):
- `declared_surfaces(design) -> list[dict]`: for every component whose `geometry` has `lifting_surface`: `p = lifting_surface_properties(c)` (no pose), then dict `{"id": c["id"], "area_mm2": p["area_mm2"], "mac_mm": p["mac_mm"], "x_ac_mm": p["x_ac_mm"], "span_mm": c["geometry"]["lifting_surface"]["span"], "aspect_ratio": p["aspect_ratio"], "lifting": p["lifting"], "vertical": bool(abs((rotation_matrix(c.get("rotation_deg")) @ np.array([0.0, 1.0, 0.0]))[2]) > abs((rotation_matrix(c.get("rotation_deg")) @ np.array([0.0, 1.0, 0.0]))[1]))}`.
- `main_and_tails(surfaces) -> tuple[dict | None, list[dict], list[dict]]`: main = the non-vertical surface with `lifting` true and the largest `area_mm2` (None if none); horizontal tails = non-vertical, `lifting` true, `id != main["id"]`, `x_ac_mm > main["x_ac_mm"]`; vertical tails = `vertical` true (any `lifting` flag) with `x_ac_mm > main["x_ac_mm"]`. Returns `(main, h_tails, v_tails)`.
- `_na(ctx, cid, what, crit) -> CheckResult | None`: if `ctx.design.data["morphology"]["lift"] == "fixed-wing"` return None, else `skip_row(cid, f"not applicable: {what} is for fixed-wing designs with a tail (morphology lift={lift}, vtol_method={vtol})", crit)` (`vtol` = `morphology.get("vtol_method", "none")`).
The check, `@discipline_check("T3.tail_volume", 3)` `tail_volume(ctx, rep) -> list[CheckResult]`, `cid = "T3.tail_volume"`, `crit = f"{ST}#tail_volume_h_min"`:
1. `_na(...)` result if not None -> `[that]`.
2. `main, h, v = main_and_tails(declared_surfaces(ctx.design))`. `main is None` -> `[CheckResult(cid, SKIP, "no main wing found among declared lifting_surface components (generated tail_surfaces and mesh planforms are not read yet)", crit)]`.
3. `S = main["area_mm2"]`, `c = main["mac_mm"]`, `b = main["span_mm"]`. Rows (list), in this order:
   - Horizontal: if `h` is empty -> SKIP row, data `{"coefficient": "Vh"}`, message "no horizontal tail found among declared lifting_surface components"; else `vh = sum(t["area_mm2"] * (t["x_ac_mm"] - main["x_ac_mm"]) for t in h) / (S * c)`.
   - Vertical: if `v` is empty -> SKIP row, data `{"coefficient": "Vv"}`, "no vertical tail found..."; else `vv = sum(t["area_mm2"] * (t["x_ac_mm"] - main["x_ac_mm"]) for t in v) / (S * b)`.
   - For each computed coefficient: read `lo`, `hi` from `stability.yaml` (`tail_volume_h_min`/`_max` or `_v_`), `pending = source == "pending"`. In band -> PASS `f"{name} {x:.3f} within {lo}-{hi}"`; outside -> WARN if pending (message `f"{name} {x:.3f} {'below' if x < lo else 'above'} {lo}-{hi}; provisional: stability.yaml#tail_volume_{h|v}_min pending"`) else FAIL. Data `{"coefficient": "Vh"|"Vv", "value": round(x, 4), "band": "within"|"below"|"above", "surfaces": [ids of the tails used]}` (the `surfaces` list is strings: it becomes part of the baseline key, as intended). Criterion for the Vv row: `stability.yaml#tail_volume_v_min`.
All rows use the same `check_id` `T3.tail_volume`; the `coefficient` string in `data` tells them apart.
