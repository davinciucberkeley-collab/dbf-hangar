## Decision (default taken)
One small helper, no behaviour change: a lazy module proxy. Every `import trimesh` above becomes `from hangar._lazy import trimesh` (relative form `from ._lazy import trimesh` or `from .._lazy import trimesh` to match the file's style). The proxy imports the real module on the first attribute access, so every existing `trimesh.X(...)`, `isinstance(m, trimesh.Trimesh)` and `trimesh.load(...)` in a function body works unchanged and costs nothing until geometry is actually built. `design get`, `plane --help`, `plane ledger`, `design set` on a design without generators, and the other non-geometry ops then never load trimesh. Ops that build geometry (`design set` on a generated part, `validate`, `export`) load it once, as before.

## Exact steps
1. `core/hangar/_lazy.py`:
```python
"""Lazy module proxy: `from hangar._lazy import trimesh` imports trimesh on first attribute access (start-up cost, T124)."""
from __future__ import annotations

import importlib


class LazyModule:
    def __init__(self, name: str):
        self.__dict__["_name"] = name
        self.__dict__["_mod"] = None

    def _load(self):
        mod = self.__dict__["_mod"]
        if mod is None:
            mod = importlib.import_module(self.__dict__["_name"])
            self.__dict__["_mod"] = mod
        return mod

    def __getattr__(self, attr):
        return getattr(self._load(), attr)

    def __dir__(self):
        return dir(self._load())


trimesh = LazyModule("trimesh")
```
