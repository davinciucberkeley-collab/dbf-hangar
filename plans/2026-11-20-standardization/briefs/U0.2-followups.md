## Changes
1. **Interpreter in printed instructions.** Every instruction a hook prints that runs `ledger.py` uses the running interpreter: `"<sys.executable>" "<root>/harness/ledger.py" …` (both quoted) instead of `python "<root>/harness/ledger.py" …`. Files: `harness/hooks/log_prompt.py`, `harness/hooks/stop_gate.py`.
2. **Deferred prompts after compaction.** `harness/hooks/reinject.py`, on `compact`/`resume`: after the `Open prompts:` block, print `Deferred prompts:` and one `format_line` per prompt with status `deferred` (all sessions), or `Deferred prompts: none`.
3. **Installer upgrade.** `harness/install.py`: when merging settings, first remove from the target every hook entry whose command contains `harness/hooks/` and ends in `.py"` (the old `python ".../x.py"` form), then add the `run.sh` entries as before. Hook entries of other tools are untouched.
4. **LF guarantee.** `harness/install.py` writes every `*.sh` it copies with `\n` line endings (read bytes, replace `\r\n` with `\n`, write bytes, keep mode 755).
