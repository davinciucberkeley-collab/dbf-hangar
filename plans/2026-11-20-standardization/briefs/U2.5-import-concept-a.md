**Step 2. `core/hangar/importers/dbf_claims.py`.**

`out_dir` is required in practice: `None` raises `ValueError("out_dir is required")` (never default to `designs/`). Behaviour, in order:
1. `qp = Path(dbf_root)/"redesign"/"qp"/concept`; `files = sorted((qp/"proofs").glob("claims.*.json"))`; none found raises `FileNotFoundError`.

3. First apply `PDL_MAP` (step 3) to every `P:` string in calculation `inputs` and in `limit.ref`. Then collect `refs`: every remaining string starting with `P:` that is a value of a calculation node's `inputs`, or the `limit.ref` of a claim, in node order, each once. For each ref `P:group.name` take `params[group][name]`; a missing one raises `ClaimGraphError(f"{ref}: not in params-{concept}.json")`. Make a node `{"id": ref, "type": "parameter", "title": f"{group}.{name}", "value": entry["value"], "unit": entry["unit"] (if present), "source": entry["source"] (only if it names a declared `SRC-` node of the graph; otherwise omit it and put `source <id>` into `note`), "status": entry["status"] (if present), "note": entry["note"] (joined with the line above if both), "file": f"redesign/qp/{concept}/params-{concept}.json"}`; keys with no value are left out. Parameter nodes go first in the file, in first-reference order; then the 243 imported nodes in file order.
4. For every claim, `parts` entries are lower-cased (`WNG-006-R` becomes `wng-006-r`) to match PDL component ids.
5. Build a `ClaimGraph(nodes, design=None)` from the combined node list to run the constructor checks, validate `{"schema": "claims/1", "nodes": nodes}` with `Draft202012Validator` against `schema/claims.schema.json`; any error raises `ClaimGraphError`.
6.
