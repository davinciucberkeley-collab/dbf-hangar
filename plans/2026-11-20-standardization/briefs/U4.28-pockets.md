## Design (SPEC; the prototype above implements exactly this)
### D1. `wing.py`
- New param after `cut_files` in the registration: `"cut_poses": ParamSpec("list", default=[], doc="derived by the resolver from the neighbours' positions; do not write")`.
- Entry shape: `{"file": "<a cut_files entry>", "matrix": [12 floats]}` = the top 3 rows of a 4x4 transform, row-major, each float `round(x, 9)`; the transform is applied to the loaded cut mesh before the bounds filter. A cut file without an entry is used as stored.
- `_build`: replace the line `cuts = [_load_cut(base_dir, f) for f in p["cut_files"]]` by
```python
    poses = {e["file"]: e["matrix"] for e in p["cut_poses"]}
    cuts = []
    for f in p["cut_files"]:
        m = _load_cut(base_dir, f)
        if f in poses:
            m.apply_transform(np.vstack([np.array(poses[f], dtype=float).reshape(3, 4), [0, 0, 0, 1]]))
        cuts.append(m)
```
- `_check`: append an error string `"cut_poses: each entry needs a 'file' listed in cut_files and a 'matrix' of 12 numbers"` once if any entry is not a dict, its `file` is not in `p["cut_files"]`, or its `matrix` is not a list of 12 numbers (bool is not a number).
- Docstring: replace the sentence `Known limit: the cut_files pockets are the neighbours' meshes as stored, they do not follow a neighbour that is moved later.` by `The cut_files pockets follow each neighbour's position and rotation_deg (cut_poses, derived by hangar.geom.resolve on load); they do not follow articulation poses.`

### D2. `resolve.py`
Add `_cut_poses(data: dict) -> None` (above `resolve_design_data`) and call it as the first statement after `errors: dict[str, str] = {}` in `resolve_design_data`: `_cut_poses(data)`. Body:
```python
def _cut_poses(data: dict) -> None:
    """Give every wing_panel the current placement of each neighbour in its cut_files (params.cut_poses, derived, never stored)."""
    import numpy as np
    from hangar.geometry import _transform
    comps = [c for c in data.get("components") or [] if isinstance(c, dict)]
    by_file = {}
    for c in comps:
        g = c.get("geometry")
        if isinstance(g, dict) and isinstance(g.get("mesh"), dict) and "file" in g["mesh"]:
            by_file.setdefault(g["mesh"]["file"], c)
    for w in comps:
        if not is_generated(w) or w["geometry"]["generator"] != "wing_panel":
            continue
        params = w["geometry"].get("params")
        if not isinstance(params, dict):
            continue
        params.pop("cut_poses", None)
        out = []
        try:
            inv = np.linalg.inv(_transform(w))
            for f in params.get("cut_files") or []:
                c = by_file.get(f)
                if c is None:
                    continue
                m = inv @ _transform(c)
                if not np.allclose(m, np.eye(4), atol=1e-9):
                    out.append({"file": f, "matrix": [round(float(x), 9) for x in m[:3].ravel()]})
        except (KeyError, TypeError, ValueError, np.linalg.LinAlgError):
            continue
        if out:
            params["cut_poses"] = out
```
Meaning: an identity placement adds nothing, so every design whose neighbours sit at `position [0,0,0]` (concept-a-param today) has NO `cut_poses` key and builds byte-for-byte as before. A component that has no usable `position` leaves the wing as before. `hangar.geometry` is imported inside the function (`hangar.geom` must not import it at module level; `resolve.py` already does this in `generated_volumes`).

### D3. `checks.py`: `T1.pocket`
Add `_pocket_checks(design, std, meshes) -> list[CheckResult]` and call it in `tier1_geometry` on the line right after `res += _contact_and_clash_checks(design, std, meshes, identity, atts, cache)`: `res += _pocket_checks(design, std, meshes, cache)` (pass the same `cache`, a `_PairCache`; add that parameter). Definition, at the neutral configuration only (no articulation poses):
- For each component W with `geometry.generator == "wing_panel"` (use `from .geom.resolve import is_generated` inside the function) whose `params.cut_files` is non-empty and which is in `meshes`:
  - "Cutter" C = every other component in `meshes` that is NOT generated and either (a) has `geometry.mesh.file` in W's `cut_files` ("listed"), or (b) is directly attached to W (an attachment with W as parent or child and C as the other end) and is not listed ("should be listed").
  - overlap `v = cache.overlap(meshes, {cid: np.eye(4) for cid in meshes}, W, C)` (check `_PairCache.overlap`'s signature at `checks.py:269` first).
  - If `v > std["geometry"]["interference_max_mm3"]["value"]`: one `CheckResult("T1.pocket", FAIL, msg, STD + "interference_max_mm3", {"part": C, "core": W, "volume_mm3": round(v, 1), "listed": bool})` with msg exactly `f"{C}: {v:.0f} mm^3 of it sits in uncut core of {W}; its pocket is not cut where the part is now"` when listed, and `f"{C}: {v:.0f} mm^3 of it sits in uncut core of {W}; it is attached to {W} but its mesh file is not in {W}'s cut_files"` when not listed. (`STD` is already defined in `checks.py`; note the cutters are iterated in sorted component-id order so the output is deterministic.)
  - If W has no FAIL row: one `CheckResult("T1.pocket", PASS, f"{W}: no part it is cut for or attached to sits in uncut core", STD + "interference_max_mm3")`.
- A design with no wing_panel (concept-a, c0-*, example-tailsitter-wing, tiltwing-cakir) gets no `T1.pocket` row at all.
- Rows duplicate the generic T1 rows by design: the new row is the one that names the cause.
