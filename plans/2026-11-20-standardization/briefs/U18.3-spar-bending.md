### 3. `core/hangar/calcs/spar.py` (units: mm, N, MPa; stations on ONE half wing)
Docstring first line: `"""U18.3: spanwise lift, root bending moment and tip deflection of a cantilever wing spar (beam theory)."""`. Exactly these functions:
- `spanwise_load(span_mm: float, root_chord_mm: float, tip_chord_mm: float, total_load_n: float, distribution: str, n: int = 400) -> tuple[list[float], float, list[float]]`. `s = span_mm/2`, `dy = s/n`, stations `y_i = (i + 0.5) * dy` for i in 0..n-1. `S = span_mm * (root_chord_mm + tip_chord_mm) / 2`. Chord `c(y) = root_chord_mm - (root_chord_mm - tip_chord_mm) * y / s`. Elliptic load per unit span `e(y) = 4 * L / (pi * span_mm) * sqrt(1 - (y/s)^2)` with `L = total_load_n`. `distribution == "elliptic"`: `w_i = e(y_i)`; `"schrenk"`: `w_i = 0.5 * (L * c(y_i) / S + e(y_i))`; any other string raises `ValueError(f"unknown distribution {distribution!r}")`. Returns `(y_list, dy, w_list)`, `w` in N/mm.
- `root_moment_nmm(y: list[float], dy: float, w: list[float]) -> float`: `sum(w_i * y_i * dy)`.
- `tip_deflection_mm(y: list[float], dy: float, w: list[float], span_mm: float, ei_nmm2: float) -> float`: `s = span_mm/2`; `sum(w_i * dy * (y_i**2 * s / 2 - y_i**3 / 6)) / ei_nmm2` (unit-load integral of a cantilever; for uniform `w` it equals `w s^4 / (8 EI)`).
- `tube_section(outer_d_mm: float, inner_d_mm: float) -> tuple[float, float]`: returns `(I_mm4, c_mm)` with `I = pi/64 * (od^4 - id^4)`, `c = od/2`.

### 4. `core/hangar/gates/spar.py`
Imports: `math`, `from ..design import FAIL, PASS, SKIP, CheckResult`, `from . import discipline_check`, `from .applicability import NEEDS, skip_row`, `from .fidelity import resolve_threshold`, `from ..calcs import spar as beam`, `from ..checks import G`, and (copy the exact import lines used at the top of `core/hangar/geom/planform.py`) `fill_defaults` and `get` for the `wing_panel` generator. Constant `SP = "spar.yaml"`. One `@discipline_check("T3.spar_bending", 3)` function `spar_bending(ctx, rep) -> list[CheckResult]`, `cid = "T3.spar_bending"`, `crit = "spar.yaml#spar_reserve_factor_min"`. It returns exactly one row, decided in this order:
1. `not NEEDS["winged"](morphology)` -> `skip_row(cid, "not applicable: spar bending is for winged designs (morphology lift=..., vtol_method=...)", crit)` (same wording pattern as `fixedwing._na`).
2. Main wing: over `ctx.design.data["components"]` collect candidates (a) `geometry.lifting_surface` with `lifting` true (default true) and `mirrored` true (default true): `(span, root_chord, tip_chord)` from it; (b) `geometry.generator == "wing_panel"` with `p = fill_defaults(get("wing_panel"), params)`, `p["side"] == "both"` and `p["part"] in ("full", "core")`: `(p["span"], p["root_chord"], p["tip_chord"])`. Main = largest `span * (root+tip)/2`. None -> `CheckResult(cid, SKIP, "no main wing found (needs a lifting_surface or a wing_panel generator)", crit)`.
3. Spar: components with `type == "structure"`, `geometry.generator == "tube"`, `params["axis"] == "y"` and `params["length"] >= 0.5 * wing span`; take the longest. None -> SKIP `"no spar tube found (needs a type structure component with generator tube, axis y, length at least half the wing span)"`.
4. Load: `weight_n = ctx.mp["mass_g"] / 1000 * G`; `n_lim = resolve_threshold(f"{SP}#spar_limit_load_factor")["value"]`; `ult = resolve_threshold("design-standards.yaml#ultimate_factor")["value"]`; `L = n_lim * weight_n`. Compute `spanwise_load` for both distributions, moments `M_ell`, `M_sch`; governing `M = max(...)`, `dist` = the name of the one with the larger moment. `I, c = tube_section(outer_d, inner_d)`; `sigma = M * c / I`; `sigma_ult = sigma * ult`.
5. Material id `mat` = `mass_model["material"]` if the spar has a `mass_model` dict with `material`, else `spar.get("material")`. `allow` = `resolve_threshold(f"{SP}#spar_material_allowable_mpa")["value"].get(mat)`; `E` = the same for `spar_material_modulus_mpa`. Data dict always `{"component": spar_id, "root_moment_nmm": round(M,1), "stress_limit_mpa": round(sigma,2), "stress_ultimate_mpa": round(sigma_ult,2), "distribution": dist, "load_factor": n_lim, "material": str(mat)}`; when `E` is not None also `"tip_deflection_mm"` and `"tip_deflection_fraction_semispan"`.
6. `allow is None` -> `CheckResult(cid, SKIP, f"spar {id}: root bending moment {M/1000:.2f} N*m (n={n_lim}, {dist}), stress {sigma:.1f} MPa at limit, {sigma_ult:.1f} MPa at ultimate; not judged: no sourced allowable for material '{mat}' in spar.yaml", crit, data)`.
7. Else `rf = allow / sigma_ult`, `rf_min = resolve_threshold(f"{SP}#spar_reserve_factor_min")["value"]`, add `"reserve_factor": round(rf,3)`, `"allowable_mpa": allow`, `"band": "within" if rf >= rf_min else "below"`. Status PASS if `rf >= rf_min` else FAIL. Message: `f"spar {id}: root bending moment {M/1000:.2f} N*m (n={n_lim}, {dist}), stress {sigma:.1f} MPa x {ult} = {sigma_ult:.1f} vs allowable {allow} MPa, reserve factor {rf:.2f} vs min {rf_min}; tip deflection {defl:.1f} mm ({frac:.1%} of semi-span)"` (when `E` is None omit the deflection clause).
Tip deflection uses `ei = E * I`. State in the module docstring: the spar alone carries the bending (skin and foam core give no stiffness); lift is `n x weight` with no inertial relief from wing mass (conservative); moment taken at the centre line (spar continuous through the fuselage); constant section.
