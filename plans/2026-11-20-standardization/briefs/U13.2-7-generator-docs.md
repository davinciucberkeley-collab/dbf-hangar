## Why
`plane generators show <name>` (U13.2-5) prints each parameter's `doc`. Today 72 of 130 parameters have an empty doc (fin 7, fuselage_loft 11, landing_gear 7, motor_mount 5, nacelle 9, plate 4, propeller 10, strut 2, tail_surfaces 7, wing_panel 10) and the unit is unknown to a reader. Units in this repo: lengths mm, angles degrees, mass g.

## Exact steps
1. For every `ParamSpec` of every generator registered in the five files above whose `doc` is empty (list them with: `$PY -c "import hangar.geom; from hangar.geom import registry as r; [print(n, k) for n in r.names() for k, v in r.get(n).params.items() if not v.doc]"`), add `doc="..."`: one short sentence fragment (under 90 characters) saying what the value is, read from that generator's `_build` and `_check` code in the same file. For `number`, `int`, `vec2` and `vec3` params the doc must contain one of these unit words as a whole word: `mm`, `deg`, `g`, `fraction` (of a length it names), `ratio`, `count`. Write e.g. `doc="spinner cone length, mm"`.
2. For the `number`/`int`/`vec` params that already have a doc without a unit word (for example `twist_tip_deg`: "positive = nose up at the tip"), append `, deg` (or the right word) to the existing text; do not reword it otherwise. Docs asserted by tests must keep their exact text: `span` of wing_panel is exactly `tip to tip, mm`.
3. Do not touch `library_part`, `mesh_file`, `tube` (already documented) except to append a missing unit word under step 2 if the test below demands it.

## Tests: `tests/test_generator_docs.py`
1. `test_every_param_has_a_doc`: `import hangar.geom`; for every `n` in `registry.names()` and every `(k, spec)` in `registry.get(n).params.items()`: `spec.doc.strip() != ""`; collect failures as `f"{n}.{k}"` and assert the list is empty.
2. `test_numeric_docs_name_a_unit`: for every param with `spec.kind in ("number", "int", "vec2", "vec3")`: `re.search(r"\b(mm|deg|g|fraction|ratio|count)\b", spec.doc)`; collect and assert empty. Exception list (documented by name in the test as a constant `NO_UNIT = {...}`) only for params whose value is a pure index or flag: add a param to it only if its code shows it is neither a length, an angle, a mass, a fraction, a ratio nor a count, and say why in a comment.
3. `test_wing_span_doc_is_unchanged`: `registry.get("wing_panel").params["span"].doc == "tip to tip, mm"`.
