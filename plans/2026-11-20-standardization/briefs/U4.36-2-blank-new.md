# Brief U4.36-2-blank-new: `plane design new <id> --blank` makes a minimal valid design with no copied template data

## Where
Branch `std/u4.36-blank-new`. Files you may change: `core/hangar/cli.py`, `core/hangar/ops/design.py`, `docs/cli.md` (regenerated), `tests/test_design_blank.py` (new). Nothing else.

## Why (red on main)
`$PY -m hangar.cli design new q --blank` -> `Error: No such option '--blank'`. `design new` only copies a template (173 components, meshes, stale baseline.json, claims, CHANGELOG when the template is `concept-a-param`), and the schema refuses `components: []` and an empty `root`, so a design cannot be blanked by removing things.

## Exact steps
1. `core/hangar/cli.py`: add next to `new_design` a function `def new_blank_design(new_id: str) -> Path:` with this behaviour: raise `ValueError(f"invalid id {new_id!r}: use lowercase letters, digits, - and _")` unless `ID_RE.fullmatch(new_id)`; raise `ValueError(f"design {new_id!r} already exists")` when `DESIGNS_DIR / new_id` exists; create the folder and write ONLY `plane.yaml` (LF line ends, via `write_bytes(text.encode("utf-8"))`) with exactly this text, `<id>` replaced by `new_id`:
```
# Blank design from `plane design new --blank`. Add parts with `plane design add`, change values with `plane design set`.
schema_version: "1.2"
id: <id>
name: "<id>"
status: concept
description: "Blank start: one placeholder root component `datum` (a 1 g point mass). Add the real root component, point `root` at it, then remove `datum`."
lineage: {derived_from: [], inspired_by: []}
morphology: {lift: fixed-wing, vtol_method: none, tail: conventional, propulsion_count: 1}
root: datum
components:
  - id: datum
    type: other
    geometry: {point_mass: {}}
    position: [0, 0, 0]
    mass_g: 1
attachments: []
```
   (`1.2` because generator geometry needs `schema_version "1.2"` (check T0.version). The schema requires a non-empty `components` and a `root` that names a component; that is why `datum` exists. Do not change the schema.) Return the plane.yaml path. Create no other file (no CHANGELOG.yaml, baseline.json, README).
2. `core/hangar/ops/design.py`: `new_op` signature becomes `def new_op(new_id: str, *, template: str = "example-tailsitter-wing", blank: bool = False) -> OpResult:`; update the summary to `"Create a design from a template, or with blank=True a minimal valid blank design (no template data)."`. When `blank` is true and `template != "example-tailsitter-wing"` raise `OpInputError("--blank and --template exclude each other")`; when blank, validate the id as now and call `new_blank_design(new_id)` instead of `new_design`, mapping `ValueError` to `OpInputError` the same way. Keep the existing ID_RE check and template behaviour unchanged.
3. Do not edit the `plane new` alias in `cli.py` (it keeps `--from`).
4. Regenerate `docs/cli.md`.
