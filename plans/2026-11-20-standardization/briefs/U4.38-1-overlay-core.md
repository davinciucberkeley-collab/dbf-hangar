## Interface (`core/hangar/geom/overlay.py`; exactly these public names)
```python
CONFIG_ENV = "PLANE_CAD_OVERLAY"            # folder path, or "off" / "" to disable
CONFIG_FILE = REPO_ROOT / "cad-overlay.local.json"   # {"path": "<folder>"}; git-ignored
def overlay_root() -> Path | None
def status(part_id: str) -> dict
def mesh(part_id: str) -> "trimesh.Trimesh | None"
def cache_files(part_id: str) -> list[str]
```
1. `overlay_root()`: if env `PLANE_CAD_OVERLAY` is set: `""` or `"off"` (case-insensitive) -> None, else `Path(value)`. Else if `CONFIG_FILE` exists: JSON `{"path": ...}` -> `Path(path)` (`"off"` -> None; unreadable JSON -> None). Else the default `Path.home() / "parts-cad"`. Return None when the resulting folder does not exist.
2. Manifest `<root>/<part_id>/overlay.yaml` (lives in the overlay folder, never in the repo):
```
file: stl/EN-sunnysky-x2814-1.STL     # required, relative to the part folder; .stl .obj .ply .off, or .step/.stp when cascadio imports
licence: "GrabCAD Terms of Use 6.2, non-commercial internal use; https://grabcad.com/library/sunnysky-x2814-1000kv-1"   # required, non-empty text
units: mm                              # mm (default) | m | in
matrix: [0,0,-1,0, 1,0,0,0, 0,-1,0,0]  # optional, 12 numbers, 3x4 row-major, applied after units, before recentre
recentre: bbox                         # bbox (default: bounding-box centre to the origin) | none
note: "shaft toward -x (nose side)"    # optional text
```
3. `status(part_id) -> dict` always returns `{"state": "absent" | "present" | "unusable", "root": str|None, "file": str|None, "licence": str|None, "note": str|None, "units": str|None, "reason": str|None, "extents_mm": [x, y, z]|None, "envelope_mm": [x, y, z]|None, "fit": [rx, ry, rz]|None}`. `absent` when there is no root, no folder `<root>/<part_id>` or no `overlay.yaml`. `unusable` (with `reason`) for: unreadable/invalid manifest (missing `file` or `licence`, bad `units`, `matrix` not 12 numbers, `recentre` not bbox/none); file missing; extension not in the list; `.step`/`.stp` without cascadio -> reason `"STEP needs cascadio (pip install cascadio) or export an STL"`; a load error; a body that cannot be made watertight; or size mismatch (below). `present` otherwise, with the numbers filled. `envelope_mm` = the committed `dimensions_mm` (`library.load_part`); `fit` = overlay extents divided by envelope per axis.
4. Loading (`mesh(part_id)` returns the mesh when `status` is `present`, else None; the work is done once per process and cached under the key `(absolute file, mtime_ns, size, manifest mtime_ns, manifest size)` in a module dict): `trimesh.load(path, force="mesh")` (for a Scene result concatenate); scale by units (`mm` 1, `m` 1000, `in` 25.4); apply `matrix` as a 4x4; `merge_vertices()`; `bodies = split(only_watertight=False)`; one body -> `kernel.require_solid`, several -> `kernel.union(bodies)` (`from hangar.geom import kernel`); recentre; return. Never write any file.
5. Size guard: after the transform, if any `fit` ratio is above 3.0 or below 1/3 the state is `unusable` with reason `"overlay size does not match the committed envelope (fit x y z = ...); check units and matrix"`. Ratios between are accepted and reported (the real motor shows x 1.5: its 54 mm includes the shaft, the envelope's 36 mm is the body).
6. `cache_files(part_id) -> list[str]`: `[]` when `absent`; otherwise the absolute strings of the manifest and (when it exists) the mesh file, so the part cache key changes with them.
