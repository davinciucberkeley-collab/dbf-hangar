## What is wrong (measured on main e487972, W34-T7)
`plane design validate designs/c172-rc --tier 3` (37 s here): `T3.tail_volume` says "no main wing found among declared lifting_surface components (generated tail_surfaces and mesh planforms are not read yet)" and `T3.trim` says "no main wing or no horizontal tail among declared lifting_surface components"; both WARN (report-only). Cause: `stability.declared_surfaces` (`core/hangar/gates/stability.py:19`) reads only `geometry.lifting_surface`. In c172-rc BOTH the main wing (`wing-core`, generator `wing_panel`, part core, side both) and the tail (`tail-fixed`, generator `tail_surfaces`, part fixed; `elevator` and `rudder` are the movable parts of the same tail) are generated. Tier 3 already reads them for the neutral point: `checks.tier3_aero` (`core/hangar/checks.py`, the loop from `counted = counted_tail_ids(...)` to `surfaces.append`) uses `geom.planform.generated_planform` and `counted_tail_ids` and, for the wing, `strip_planform(_planform_parts(design, c)[1], ...)`. It does not read the fin (not a pitch surface), so `generated_planform` has no fin; Vv needs one.

## Decisions (defaults taken; the conductor may overrule)
1. Reuse tier 3's own readers, invent no new geometry: main wing = `strip_planform` measurement exactly as tier 3 does it; horizontal tail = `generated_planform(c)["lifting_surface"]` wrapped in a pseudo component exactly as tier 3 does it, only for ids in `counted_tail_ids(design.components)` (so fixed + elevator count once).
2. Fin: new `planform.generated_fin`; Vv uses it. Surface ids: horizontal tail = the component id (`tail-fixed`), fin = `"<component id>:fin"`.
3. Stall-row CLmax (T153 part 2): LEAVE `standards/design-standards.yaml#cl_max_default` 1.1 and keep the trim stall row on the `T3.stall` speed. Reason: U18.2's 1.54 is the full-size Cessna 172 flaps-up value (POH stall table); the 1:10 model flies at about a third of that Reynolds number, and `cl_max_default` is a deliberately conservative floor sourced to Guglielmo & Selig (plain airfoils 1.17-2.2 at Re 2e5). No source gives a model value, so a new number would be invented. A design that knows its CLmax sets `flight.cl_max` (T3.stall and trim then agree). Effect for scale: at CLmax 1.54 the c172-rc stall speed would be 6.80 m/s and the stall elevator +11.6 deg instead of 8.05 m/s and +8.3 deg; both inside the default 20 deg down travel. The only code change: the stall row's message says it uses the T3.stall speed (W34-R2 suggestion 3, reviews/2026-11-25-w34b.md). Do not add `flight.cl_max` to c172-rc (`designs/` is out of scope).
4. If a design has both a declared and a generated main wing, `main_and_tails` still picks the largest area; nothing else changes for designs with declared surfaces (existing tests unchanged).

## Exact steps and outputs
1. `core/hangar/geom/planform.py`: append
```python
def generated_fin(component: dict) -> dict | None:
    """Vertical fin of a generated tail_surfaces component (layouts conventional and t; the fin_* params describe the whole fin
    whichever part this component is), as a pseudo lifting_surface plus offset and rotation; None when there is none to read."""
```
   Same try/except style as `generated_planform` (any exception -> `None`). Returns `None` unless `geometry.generator == "tail_surfaces"`, `type == "tail_surface"` and, after `p = fill_defaults(get("tail_surfaces"), params)`, `p["layout"] in ("conventional", "t")` and `p["part"] in ("full", "fixed")`. Otherwise returns exactly
   `{"lifting_surface": {"span": p["fin_height"], "root_chord": p["fin_root_chord"], "tip_chord": p["fin_tip_chord"], "sweep_le_deg": p["fin_sweep_le_deg"], "mirrored": False, "lifting": False}, "offset": [p["fin_x_le"], 0.0, p["fin_z_root"]], "rotation_deg": [90.0, 0.0, 0.0]}`.
2. `core/hangar/gates/stability.py` (new imports: `from ..checks import _planform_parts` next to the existing `from ..checks import G, RHO_DEFAULT`, `strip_planform` from `..geometry`, `generated_planform, generated_fin, counted_tail_ids` from `..geom.planform`):
   - `def generated_surfaces(design, std: dict) -> list[dict]`: same dict keys as `declared_surfaces` (`id, area_mm2, mac_mm, x_ac_mm, span_mm, aspect_ratio, lifting, vertical`).
     a. for each component `c` with `generated_planform(c) == {"measured": True}`: `p = strip_planform(_planform_parts(design, c)[1], c["id"], n=std["aero"]["planform_strip_count"]["value"], gap_tol=std["geometry"]["strip_gap_tolerance_mm"]["value"], control_frac=std["aero"]["control_surface_gap_max_fraction"]["value"])`; surface `{"id": c["id"], "area_mm2": p["area_mm2"], "mac_mm": p["mac_mm"], "x_ac_mm": p["x_ac_mm"], "span_mm": p["span_mm"], "aspect_ratio": p["aspect_ratio"], "lifting": True, "vertical": p["span_axis"] == "z"}`.
     b. for each component `c` with `c["id"] in counted_tail_ids(design.components)` and a `"lifting_surface"` key in `gp = generated_planform(c)`: pseudo component `{**c, "geometry": {"lifting_surface": gp["lifting_surface"]}, "position": [c["position"][0] + dx, c["position"][1] + dy, c["position"][2] + dz]}` with `dx, dy, dz = gp["offset"]`; take `lifting_surface_properties(pseudo)`; surface id `c["id"]`, `span_mm = gp["lifting_surface"]["span"]`, `lifting True`, `vertical False`.
     c. for the same counted components, `fin = generated_fin(c)`; when not None: pseudo component with `geometry {"lifting_surface": fin["lifting_surface"]}`, `position` = component position + `fin["offset"]`, `rotation_deg` = `fin["rotation_deg"]`; surface id `f"{c['id']}:fin"`, `span_mm = fin["lifting_surface"]["span"]`, `lifting False`, `vertical` computed with the same rotated-y test `declared_surfaces` uses (do not hard-code; it must come out True).
   - `def all_surfaces(design, std: dict) -> list[dict]`: `declared_surfaces(design) + generated_surfaces(design, std)`.
   - `tail_volume` and `trim`: replace `declared_surfaces(ctx.design)` by `all_surfaces(ctx.design, ctx.std)`. Keep `declared_surfaces` and `main_and_tails` unchanged (existing tests call them).
   - SKIP texts: main missing -> `"no main wing found among declared lifting_surface components or generated wing_panel parts (mesh planforms are not read yet)"`; no tail -> `f"no {kind} tail found among declared lifting_surface components or generated tail_surfaces"`; trim -> `"no main wing or no horizontal tail among declared lifting_surface components or generated parts"`.
   - Trim: the stall row's message starts `"stall: V {v:.1f} m/s (the T3.stall speed), tail lift ..."`; the cruise row text is unchanged. (Implementation: put the parenthesis only when `cond == "stall"`.)
