### 2. `core/hangar/calibration.py`
Docstring first line `"""U18.2: compare a computed number with a published one against a tolerance from standards/calibration.yaml."""`. Imports `from .gates.fidelity import resolve_threshold`. Constant `KEYS = ("calibration_tol_mass_fraction", "calibration_tol_geometry_fraction", "calibration_tol_stall_fraction")`. Functions exactly:
- `error_fraction(computed: float, published: float) -> float`: `(computed - published) / published`; `published == 0` raises `ValueError("published value is zero")`.
- `tolerance(key: str) -> tuple[float, bool]`: `t = resolve_threshold(f"calibration.yaml#{key}")`; returns `(t["value"], t["source"] == "pending")`; unknown key raises `KeyError(key)`.
- `within(computed: float, published: float, key: str) -> bool`: `abs(error_fraction(computed, published)) <= tolerance(key)[0]`.

### 4. `tests/test_calibration_c172.py`
Load the fixture like `tests/test_fixed_wing_gates.py::fw()` (deepcopy of `yaml.safe_load` of the fixture, `Design(d, path=FIX / "c172s" / "plane.yaml")`; `from test_discipline_gates import rows, run`; tier 3 only: `run(design, tiers={3})`; helper `one(design, check_id)` as in `test_fixed_wing_gates.py`). Hand calculations (G = 9.80665; rho 1.225; area 16.17 m^2 = 1617 dm^2):
- Mass: sum of `mass_g` = 1,157,000 g; error 0 against 1,157,000.
- Wing loading = 1,157,000 g / 1617 dm^2 = 715.52 g/dm^2 (71.55 kg/m^2). The standards limit 100 g/dm^2 is a scale-RC figure: row is WARN `above` (pending source). Finding.
- Weight = 1157 x 9.80665 = 11346.29 N; 2W = 22692.6 N.
- Stall at the default CLmax 1.1 (`cl_max_default`): V = sqrt(22692.6 / (1.225 x 16.17 x 1.1)) = sqrt(22692.6 / 21.789) = sqrt(1041.5) = 32.27 m/s. Published Vs1 = 48 kt = 24.693 m/s: error +30.7 %; published Vs0 = 40 kt = 20.578 m/s: error +56.8 %.
- Implied CLmax from Vs1 = 22692.6 / (1.225 x 16.17 x 24.693^2) = 22692.6 / 12078.4 = 1.879. With `flight.cl_max = 1.88`: V = sqrt(22692.6 / (19.80825 x 1.88)) = sqrt(609.4) = 24.69 m/s, error -0.03 % (well inside 5 %).
- Cruise/stall ratio with the default CLmax: 63.79 / 32.27 = 1.977 (published ratio against Vs1: 63.79 / 24.693 = 2.583).
- Neutral point (the T3 method: Helmbold slopes, downwash, aft_surface_efficiency 0.9): wing AR 7.483, slope 4.824 /rad, area 16.17 m^2, AC at 1940 + 0.25 x 1470 = 2307.5 mm; tail area 3.250 x (1.200 + 0.920) / 2 = 3.445 m^2, AR 3.066, slope 3.403 /rad, MAC 1.0662 m, AC at 6400 + 403.5 = 6803.5 mm (y_MAC 0.7767 m x tan 10 deg = 0.1370 m, plus 0.25 x 1.0662); downwash factor 1 - 2 x 4.824 / (pi x 7.483) = 0.5896; tail weight 3.403 x 3.445 x 0.9 x 0.5896 = 6.221; wing weight 4.824 x 16.17 = 78.01; NP = (78.01 x 2307.5 + 6.221 x 6803.5) / (78.01 + 6.221) = 2639.5 mm. The row says "fuselage effect not modelled" (a real fuselage moves the NP forward): finding.
