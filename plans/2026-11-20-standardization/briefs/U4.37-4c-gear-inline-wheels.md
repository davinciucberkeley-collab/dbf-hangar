## Why (A400M gap 10)
`landing_gear` builds one main wheel per side; the A400M has three wheels in line per side. Today `main_wheels` is `unknown parameter for generator 'landing_gear'`.

## Exact steps
1. Params: `"main_wheels": ParamSpec("int", default=1, minimum=1, doc="main wheels in line per side, count")`, `"wheel_pitch": ParamSpec("number", default=0.0, minimum=0, doc="x distance between neighbouring main wheel centres, mm")`.
2. `_gear_build`: for `main_wheels == 1` the code is unchanged (bit-identical result). Otherwise, per side `s`: the leg stays at `main_x` (top and axle as now); wheel `i` (0..n-1) has its axle at x = `main_x + (i - (n - 1) / 2) * wheel_pitch`, same y and axle z, `kernel.tube("y", axle_i, ww, wd)`; one bogie beam `kernel.tube("x", (main_x, s * track / 2, axle_z), (n - 1) * wheel_pitch, ld)` joins the wheel centres; all united with the rest as now.
3. `_gear_check`: add `"wheel_pitch: must be > wheel_d when main_wheels > 1"` when `main_wheels > 1` and `not wheel_pitch > wheel_d`.

## Tests: `tests/test_gear_inline_wheels.py`
Params `G = {"layout": "tricycle", "main_x": 500, "track": 400, "attach_z": 100, "ground_z": 0, "wheel_d": 40, "wheel_w": 15, "leg_d": 8, "front_x": 100}`; open `tests/test_shapes_airframe.py` first and reuse its `build` and base dir; `Vw = vol(build("tube", {"axis": "y", "length": 15, "outer_d": 40}))`, `Vb1 = vol(build("tube", {"axis": "x", "length": 1.0, "outer_d": 8}))`.
1. `test_one_wheel_is_bit_identical`: vertices with `main_wheels=1` and `wheel_pitch=60` equal those without the new params (`np.array_equal`).
2. `test_three_wheels_volume`: `main_wheels=3, wheel_pitch=60`: one watertight part; `vol(n=3) - vol(n=1) == pytest.approx(2 * (2 * Vw + 2 * (60 - 40) * Vb1), rel=1e-3)` (two sides; two extra wheels and two visible beam gaps of pitch minus wheel_d each).
3. `test_three_wheels_bounds`: `bounds[1][0] == pytest.approx(580, abs=1e-3)` (500 + 60 + 20); `bounds[0][0] == pytest.approx(100 - 20, abs=1e-3)` (nose wheel d 40 at x 100).
4. `test_pitch_check`: `main_wheels=3, wheel_pitch=30` -> `validate_params` message containing `wheel_pitch`; `main_wheels=3, wheel_pitch=60` none; `main_wheels=2` without a pitch -> message containing `wheel_pitch`.
5. `test_two_wheels_symmetry`: `main_wheels=2, wheel_pitch=50`: `abs(bounds[0][1] + bounds[1][1]) < 1e-6`.
