## Where

## Why (red on main)
`build_component` with `inboard_span: 100` -> `GeometryError: w: inboard_span: unknown parameter for generator 'wing_panel'; known: airfoil_file, bore_d, ...`. A Cessna-style wing (rectangular inboard, tapered outboard) cannot be modelled; the single taper loses about 9 % wing area when the measured tip chord is used.

## Exact steps (all in `core/hangar/geom/wing.py`)
1. Add to the `wing_panel` params: `"inboard_span": ParamSpec("number", default=0.0, minimum=0, doc="mm per side along |y| over which the chord stays root_chord; the taper to tip_chord runs from there to the tip; 0 = one taper from the root. Sweep, dihedral and twist stay linear in |y| from the root.")`, placed right after `tip_chord`.
2. `_place`: replace the chord line with
   `ib = p.get("inboard_span", 0.0); c = p["root_chord"] if ay <= ib else p["root_chord"] + (p["tip_chord"] - p["root_chord"]) * (ay - ib) / (half - ib)` (when `ib == 0` this is the old expression). Nothing else in `_place` changes (twist, sweep and dihedral use `ay / half` and `ay` exactly as now).
3. `_build`: the loft stations must include the break at `|y| = ib` when `ib > 0`:
   - full/core: side 0 `ys = [-half, -ib, 0.0, ib, half]` if `ib > 0` else the old `[-half, 0.0, half]`; side +-1 `ys = [0.0, side * ib, side * half]` if `ib > 0` else the old `[0.0, side * half]`.
   - elevon: for each side `s`, stations `[s*y0, s*y1]` plus `s*ib` when `y0 < ib < y1`.
4. `_check`: add `if p["inboard_span"] >= p["span"] / 2.0: errs.append("inboard_span: must be < span/2")` (the `minimum=0` is enforced by the ParamSpec).
5. No other edit. When `inboard_span` is 0 or omitted every existing result must be bit-for-bit the old one.
