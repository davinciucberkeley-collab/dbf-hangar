```python
def remove_element(text: str, key: str) -> tuple[str, object]:
    """Return (patched text, removed element): `key` is `name[id]`; exactly that element's lines are deleted.

    Deleted: the element's own lines (one line for a one-line flow entry `- {...}`; for a block entry its dash line
    through its last more-indented line) and the directly preceding comment lines that belong to it. Nothing is re-emitted.
    """
    crlf = "\r\n" in text
    t = text.replace("\r\n", "\n")
    hand = f"{key}: cannot remove this element without rewriting other text; edit the file by hand"
    steps = parse_key(key)
    if steps[-1][0] == "index":
        raise OpInputError(f"{key}: remove by index is not supported; address the element by id, like name[id]")
    if len(steps) > 2:
        raise OpInputError(f"{key}: remove takes a top-level list element name[id]; a nested path (one field, or a list below an element) is not supported")
    if len(steps) != 2 or steps[1][0] != "id":
        raise OpInputError(f"{key}: remove needs a list element like name[id]; this is not one")
    data = yaml.safe_load(t)
    element = walk(data, key)[0]                 # raises the "no key", "needs a list" and "no element with id" errors
    expected = copy.deepcopy(data)
    _, exp_list, _, exp_i = walk(expected, key)
    del exp_list[exp_i]                          # the reference result for Verify 1
    _, seq, _, i = walk(yamlio.load(t), key)
    if seq.fa.flow_style():
        raise OpInputError(hand)
    lines = t.split("\n")
    start, col = seq.lc.item(i)
    body = lines[start].lstrip()
    if not body.startswith("- "):
        raise OpInputError(hand)
    if seq[i].fa.flow_style():
        close = _close_brace(lines[start], col) if lines[start][col:col + 1] == "{" else -1
        rest = lines[start][close + 1:].strip() if close >= 0 else "?"
        if rest and not rest.startswith("#"):
            raise OpInputError(hand)             # a multi-line flow entry, or text after the closing brace
        last = start
    else:
        last = _block_end(lines, start, len(lines[start]) - len(body), False)
    first = start
    mine = re.compile(r"#\s*" + re.escape(str(steps[1][1])) + r"(?![A-Za-z0-9_-])")
    j = start - 1
    while j >= 0 and lines[j].lstrip().startswith("#"):
        if mine.match(lines[j].lstrip()):
            first = j                            # the topmost comment line that begins with the id
        j -= 1
    out = "\n".join(lines[:first] + lines[last + 1:])
    if yaml.safe_load(out) != expected:
        raise OpInputError(hand)
    for tag, *_ in difflib.SequenceMatcher(None, t.splitlines(), out.splitlines(), autojunk=False).get_opcodes():
        if tag not in ("equal", "delete"):
            raise OpInputError(f"{key}: removing would rewrite other lines; edit the file by hand")
    return (out.replace("\n", "\r\n") if crlf else out), element
```

Rules this code implements (do not change them; if a test fails, stop):
- Address: exactly `name[id]` (two steps: a key, then an id). Anything else is refused: last step an index -> "remove by index is not supported"; more than two steps (a field below an element, or a list below an element) -> "a nested path ... is not supported" (removing one field of an element is out of scope); fewer than two steps or last step not an id -> "remove needs a list element like name[id]".
- Unknown id, missing key, or a non-list target: the error comes from `walk`, before any edit.
- Element lines deleted: a one-line flow entry `- {...}` -> that one line (a trailing `# comment` on it goes with it). A block entry -> its `- ` line through its last more-indented content line (`_block_end`; comments or blank lines after the last content line stay). Anything else (multi-line flow entry, text after the closing brace, the list itself in flow style, a dash on its own line, a removal that would leave the list empty) -> refused with "cannot remove this element without rewriting other text; edit the file by hand".
- Comment lines deleted with it: walk up from the line above the element through the contiguous `#` lines (no blank line between). The topmost line of that run whose text after `#` and spaces begins with the id (whole id: the next character is not a letter, digit, `_` or `-`) starts the deleted range: that line, every line below it down to the element, and the element go. If no line of the run begins with the id, no comment is deleted (a comment that only mentions the id mid-sentence stays: it may be a shared header).
- Never re-emitted: the result is the original lines minus one contiguous range. Verify 1: `yaml.safe_load(result)` equals the original data with exactly that element removed. Verify 2: the line diff of old versus new has only `equal` and `delete` opcodes. CRLF is detected and restored exactly like `add_value`.

def _lines(text):
    return text.replace("\r\n", "\n").splitlines()


def _line_no(lines, needle):
    return next(n for n, line in enumerate(lines) if needle in line)


def _log(d):
    return yaml.safe_load((d / "CHANGELOG.yaml").read_text(encoding="utf-8"))


def test_remove_flow_attachment_deletes_its_line_and_id_comments(tmp_concept_a):
    text = _plane_text(tmp_concept_a)

- A new `kind` value `remove` on the existing `design.set` op (not a separate op): same registry entry, `--why`, `--also`, atomic flow, one strict schema check and CHANGELOG. `--value` is not allowed with remove, so the `value` parameter became optional (default `None`); every other kind still requires it ("value is required unless --kind remove").
- Remove works inside `--also` as `KEY=` (nothing after the `=`), only when `--kind remove`; `--also KEY` without `=` is still the existing error. One call has one kind, so removes cannot be mixed with adds or modifies.
- Only a top-level `name[id]` element is removable. Removing one field (`name[id].field`) or an element of a list below an element is out of scope and refused.
- Comment rule: only comment lines at and below the topmost contiguous comment line that begins with the id are deleted with the element (stricter than "mentions the id", so shared header comments survive).
- Removing the only element of a list is refused (it would leave `key:` with no value).
- CHANGELOG `old` is the element as a one-line flow string; `new` is `null`.
- The `design.set` op summary and `kind` Literal change (listed in Where); no generated doc contains them.
