# Brief U13.6-5-elevator-fin-gap: opt-in lateral gap between the elevator and the fin (conventional, T and H tails; T138)

class: hard · role: builder-plus · plan: §7 U13.6 item (5) · depends on: U13.3-4b merged (`part` on `tail_surfaces`) · merge order: 6th · SLUG = `elevator-fin-gap`

Environment: follow `plans/2026-11-20-standardization/briefs/U13.6-env.md` with SLUG=elevator-fin-gap.

## Why (A400M gap 7, C172 gap 14)
With `part: elevator` and `part: rudder` as separate components, the elevator spans the stabiliser from y = 0 and the rudder (the rear of the fin) sits in |y| < fin_thickness/2 at the same x and z: they overlap by construction (about 2,400 mm3 on the A400M T tail; also a small overlap on the conventional layout, and in the H layout where the fins stand on the stabiliser tips). The workaround was a shorter fin on the rudder component only. A lateral gap solves it for every hinge angle, because the elevator then never occupies the rudder's y range. Default 0 keeps every existing result bit-identical.

## Exact steps (`core/hangar/geom/tails.py`)
1. New param `"elevator_fin_gap": ParamSpec("number", default=0.0, minimum=0, doc="lateral gap between the elevator and the fin(s), mm; 0 = the elevator spans to the fin plane (default); only part elevator, layouts conventional, t and h")`.
2. In `_build`, in the `part == "elevator"` branch the stabiliser params currently set `elevon_y=[0, p["stab_span"] / 2.0]`. With `g = p["elevator_fin_gap"]` and `half = p["stab_span"] / 2.0`, `t = p["fin_thickness"]`: when `g > 0` and layout is `conventional` or `t`: `elevon_y = [t / 2.0 + g, half]`; when `g > 0` and layout is `h`: `elevon_y = [0, half - t / 2.0 - g]`; layout `v` and `g == 0` unchanged. For `g == 0` the code path and every result are exactly as now.
3. `_check`: when `elevator_fin_gap > 0` and layout is not `v`: error `"elevator_fin_gap: the gap leaves no elevator (need fin_thickness/2 + gap < stab_span/2)"` unless `t/2 + g < half` (conventional, t) or `half - t/2 - g > 0` (h); when layout is `v` and gap > 0: `"elevator_fin_gap: has no effect on layout v"`.
4. Replace the module docstring sentence `Separate elevator / rudder surfaces are not modelled.` by `part selects the whole surface, the fixed part, the elevator or the rudder; elevator_fin_gap keeps the elevator clear of the fin.`
