## Why
An overlay mesh is licensed for internal use only. Outputs built from it (GLB, STL, MJCF with mesh vertices, `build-index`, Studio data) must stay on this machine: never inside git-tracked paths, never in a directory a commit could pick up. The tracked-path rule is checked by git itself, so a new ignore pattern or a forced add cannot slip through.

## Additions to `core/hangar/geom/overlay.py`
```python
class OverlayOutputRefused(RuntimeError): ...
def design_overlay_parts(design) -> list[str]
def output_allowed(path) -> tuple[bool, str]
def guard_output(path, design) -> list[str]
```
1. `design_overlay_parts(design)`: sorted unique part ids of components whose `geometry` has `generator == "library_part"` and `params.part` where `status(part_id)["state"] == "present"`. Never raises (any error -> that part not counted... but an unknown part is not counted).
2. `output_allowed(path) -> (ok, why)`: `p = Path(path).resolve()`; if `p` is not inside `REPO_ROOT.resolve()` (module-level name, monkeypatchable) -> `(True, "outside the repository")`. Inside: run `git -C <REPO_ROOT> ls-files --error-unmatch -- <p>`; return code 0 (tracked) -> `(False, "tracked by git")`. Then `git -C <REPO_ROOT> check-ignore -q -- <p>`: code 0 -> `(True, "git-ignored")`; code 1 -> `(False, "inside the repository and not git-ignored")`; any other code or `FileNotFoundError`/`OSError` (no git) -> `(False, "cannot ask git; refusing")`. `<p>` need not exist (directories and files both work; for a directory pass the directory path).
3. `guard_output(path, design) -> list[str]`: `ids = design_overlay_parts(design)`; if no ids return `[]` (nothing checked, nothing written). Else `ok, why = output_allowed(path)`; not ok -> `raise OverlayOutputRefused(f"{path}: this design uses licensed CAD overlay parts ({', '.join(ids)}); outputs built from them stay local-only and may not be written to a tracked or unignored path in the repository ({why}). Use a folder outside the repository, or an ignored one such as viewer/data/ or .studio/.")`. Else write (create the directory) a marker file `LOCAL-ONLY-cad-overlay.txt` in the output directory (`path` itself when it is an existing or suffix-less directory path, else `path.parent`) with the text `Built from licensed CAD overlay parts: <ids>. Local use only (non-commercial, internal). Do not commit, upload or publish this folder.\n`, and return `ids`.
