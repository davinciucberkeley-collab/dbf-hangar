## Exact steps and outputs
### 1. One appearance function (`vp/materials.js`)
Replace `highlight(vp, ids)` with `applyAppearance(vp)` called by `Viewport.select`, `setGhost`, `xray`, `setHidden` (B2) and after load. For each mesh (component id `cid`) compute, in this precedence:
- ghosted (`vp.ghost` set contains `cid`, or `vp.xrayOn` and the component type is in `SKIN_TYPES = ['fuselage', 'wing', 'tail_surface']`): `transparent = true`, `opacity = 0.15`, `depthWrite = false`, `renderOrder = 5`, `castShadow = false`; its edge lines `opacity = 0.12`.
- else if the selection is non-empty and `cid` is not in it: `transparent = true`, `opacity = min(base, 0.28)`, `depthWrite = true`, `renderOrder = 0`; edges 0.15 (B1 behaviour).
- else: base opacity (`userData.baseOpacity`), `transparent = (compType === 'propeller')`, `depthWrite = true`, `renderOrder = 0`, `castShadow = true` (propellers false), edges 0.6.
- selected parts keep the emissive tint exactly as today (`0xffb020`, intensity 0.55); a selected ghosted part is tinted and stays at ghost opacity.
Set `material.needsUpdate = true` only when `transparent` or `depthWrite` changed. Sets `dirty`.

### 2. Ghost and x-ray (`vp/scene.js`)
- `this.ghost = new Set()`, `this.xrayOn = false`. `setGhost(ids, on)` adds or removes; `xray(on)` sets `xrayOn` (boolean) and recomputes; both call `applyAppearance(this)` and notify app.js (which calls `syncTree()`). `state()` gains `xray: boolean`, `ghosted: [...]` = every id currently ghosted (explicit set plus skin-type parts while `xrayOn`), `section: null | { axis, value, flip }`.
- Toolbar button `[data-testid="btn-xray"]` (toggle, `aria-pressed`) and key `x`? NO new key besides `g` (ghost selection on/off, toggling): keep `x` unused. Button label `X-ray`.
- Tree: a ghost button in each row (`class="ghost" data-testid="ghost-<id>"`, toggles that part) and `data-ghost="1|0"` on rows (reflects `state().ghosted`).

### 3. Section plane (`vp/scene.js`)
- `renderer.localClippingEnabled = true` in the constructor. One shared `this.clipPlane = new THREE.Plane()`.
- `section(axis, value = 0.5, flip = false)` with `axis` in `'x' | 'y' | 'z'` or `null` (clears). `value` is a fraction 0..1 across the model's bounding box along that BODY axis. Body to scene: body x -> scene x, body z -> scene y, body y -> scene -z. Normal: x `(1,0,0)`, y `(0,0,-1)`, z `(0,1,0)`; flip negates it. Plane point: the box min along the axis plus `value * (max - min)` (box from `Box3().setFromObject(model)` taken once at load, before any explode or move: store it as `this.box0`). `clipPlane.setFromNormalAndCoplanarPoint(normal, point)`. The kept side is where `plane.distanceToPoint(p) >= 0` (normal side). Unflipped x at 0.5 therefore keeps the aft half and removes the nose half.
- Apply: for every mesh material and every edge-line material set `clippingPlanes = [this.clipPlane]` and `needsUpdate = true`; when cleared set `clippingPlanes = null`, `needsUpdate = true`. New models (after `show()`) re-apply the current section. Materials are already `DoubleSide`, so the cut is uncapped (back faces show); no cap geometry.
- `state().section` mirrors `{axis, value, flip}` or `null`.
- UI group in `.vp-wrap`, element `<div id="see-inside" class="view-bar see-inside">` placed next to `#view-bar` (B2) containing: X-ray button; `<select data-testid="section-axis">` options `off, x, y, z`; `<input type="range" data-testid="section-slider" min="0" max="1000" value="500">` (disabled when axis is off); `<label><input type="checkbox" data-testid="section-flip"> flip</label>`. Changing any control calls `vp.section(axis || null, slider/1000, flip)`.

### 4. Picking (`vp/pick.js`, `vp/scene.js`)
- Factor the ray test into `hitsAlong(vp, raycaster) -> [{ id, point, distance }]`: all intersections with `intersectObject(model, true)` that pass `isPickable`: component node and ancestors `visible`, the component not ghosted (`state().ghosted` rule from step 2), not an edge line, and, when a section is active, `clipPlane.distanceToPoint(hit.point) >= 0`. Sorted by distance, deduplicated by component id (first hit per component kept). The first element is what a plain click selects (B2 behaviour otherwise unchanged).
- Alt-click: a `pointerup` with `event.altKey` calls `cycleSelect(hits, key)`, where `key` is the pointer position rounded to 4 px; `vp.cycle = { key, index }`; the same key again advances `index` modulo `hits.length`; a different key resets to 0; selects only that component (like a plain click). Alt + no hit: clear.
- Hooks: `pickRay(originMm, dirMm) -> string[]`: build a `Raycaster` from the origin and direction converted body mm -> scene m (`x/1000, z/1000, -y/1000` for both; normalise the direction), return the ordered ids from `hitsAlong`. `cyclePick(originMm, dirMm) -> string | null`: the Alt-click logic for that ray (key = the stringified inputs), selects and returns the id.
