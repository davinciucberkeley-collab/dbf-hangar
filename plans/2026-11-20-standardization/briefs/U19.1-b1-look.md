## Exact steps and outputs
All values below are the defaults; keep them unless a test fails. Every setting is applied per `Viewport`; Compare viewports get the same look.
1. Renderer and light in `Viewport` constructor (`scene.js`): `renderer.toneMapping = THREE.NeutralToneMapping ?? THREE.ACESFilmicToneMapping`; `renderer.toneMappingExposure = 1.0`. Environment: `const pm = new THREE.PMREMGenerator(this.renderer); this.scene.environment = pm.fromScene(new RoomEnvironment(), 0.04).texture; pm.dispose();` with `import { RoomEnvironment } from 'three/addons/environments/RoomEnvironment.js';`; `this.scene.environmentIntensity = 0.8`. Lights: HemisphereLight intensity 0.35, DirectionalLight (sun) intensity 1.8. `Viewport.dispose()` (B0) additionally disposes `scene.environment`.
2. Materials (`prepareMesh` in `materials.js`): for every non-propeller mesh set `material.metalness = 0.15`, `material.roughness = 0.55`, `material.envMapIntensity` unset (the scene intensity rules); keep `vertexColors` and `side = DoubleSide` as B0 left them; set `material.polygonOffset = true`, `polygonOffsetFactor = 1`, `polygonOffsetUnits = 1` (so edge lines do not z-fight). Propellers keep their alpha handling untouched.
3. Edge lines: in `prepareMesh`, build once per mesh `new THREE.LineSegments(new THREE.EdgesGeometry(mesh.geometry, 30), new THREE.LineBasicMaterial({ color: edgeColor, transparent: true, opacity: 0.6 }))` where `edgeColor` is `cssVar('--edge')`; set `line.userData.isEdge = true`, `line.raycast = () => {}` (never picked), `line.renderOrder = 1`; `mesh.add(line)`. Skip meshes with more than 40000 triangles (position count / 3). `highlight()` (materials.js) multiplies each edge material opacity by the same factor it applies to its mesh (dimmed parts: edges 0.15, otherwise 0.6) and `applyTheme()` recolours every edge material. `disposeModel` (B0) already frees line geometries/materials because it traverses all meshes: extend its traverse to `o.isMesh || o.isLine`. `Viewport.info()` (B0) gains `edgeSegments`: the sum of `position.count / 2` over edge lines, so the test can see edges exist.
4. Shadow: `renderer.shadowMap.enabled = true; renderer.shadowMap.type = THREE.PCFSoftShadowMap`; sun `castShadow = true`, `shadow.mapSize.set(2048, 2048)`, `shadow.bias = -0.0005`, `shadow.normalBias = 0.002`; in `show()` after the model box is known set the shadow camera `left/right/top/bottom` to `+-diag`, `near 0.01`, `far diag*6`, sun position to `center + (0.4, 1, 0.3).normalize() * diag * 2`, `updateProjectionMatrix()`. Every mesh `castShadow = true` (not propellers, not edge lines). A ground plane replaces nothing: add `new THREE.Mesh(new THREE.PlaneGeometry(diag * 2.4, diag * 2.4), new THREE.ShadowMaterial({ opacity: 0.22 }))`, rotated `-PI/2` about x, at the grid's y, `receiveShadow = true`, `renderOrder = -1`, under `root` (disposed with the model). Keep the GridHelper.
5. Theme: `viewer/style.css` has the dark palette only inside `@media (prefers-color-scheme: dark)` (lines ~10-20). Add `--edge` to the light block (`#27303f`) and to the dark block (`#c4cee0`). Add `:root[data-theme="dark"] { ...the same variables as the dark media block... }` and `:root[data-theme="light"] { ...the same variables as the light block... }` (copy the variable lists; do not restructure the file). `viewer/index.html`: in `.toolbar`, after `#mode-hint`, add `<button id="theme-toggle" class="btn" data-testid="theme-toggle" type="button" title="Switch light / dark">Theme</button>`. `app.js`: on `init()` read `localStorage.getItem('plane-theme')` (guard with try/catch); if `light` or `dark` set `document.documentElement.dataset.theme`; the button toggles between `light` and `dark` (starting from the current computed scheme when none is stored), stores it, and calls `applyTheme()` on every existing viewport on the next frame (`setTimeout(..., 0)` as the existing colour-scheme listener does). `Viewport.applyTheme()` also recolours edges and updates `scene.background`.
6. Evidence for the PR (not asserted): `window.planeViewer.vp.info()` on concept-a (`tests/fixtures/concept-a-frozen`, via the `concept_a_studio` fixture in `tests/test_viewer_static.py`) printed with `pytest -s`: `calls`, `triangles`, `edgeSegments`.
