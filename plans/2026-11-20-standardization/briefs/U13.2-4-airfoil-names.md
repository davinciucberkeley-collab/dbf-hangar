## Why (red on main)
`build_component({"id":"w","geometry":{"generator":"wing_panel","params":{"airfoil_file":"naca2412","span":1000,"root_chord":200,"tip_chord":150}}}, Path("."))` -> `FileNotFoundError: ... 'naca2412'`. No CLI command makes an airfoil file; the repo has one airfoil (s5010) inside one design.

## Rule (the one definition; implement exactly this)
A reference is "named" when it contains none of `.`, `/`, `\`. Named references resolve, in order: (1) `^naca[0-9]{4}$` (case-insensitive; normalise to lower case) -> generated by the NACA 4-digit formula below; (2) `knowledge/airfoils/<name>.dat`; (3) else `GeometryError(f"airfoil {ref!r}: not a NACA 4-digit name and no knowledge/airfoils/{ref}.dat (known: <comma-separated sorted names in knowledge/airfoils, plus 'nacaXXXX'>)")`. A reference that is not named is a design-folder-relative file, exactly as today.

## Exact steps
1. `core/hangar/geom/airfoil.py` (new), public names only these:
   - `AIRFOIL_DIR = REPO_ROOT / "knowledge" / "airfoils"` (`from hangar.design import REPO_ROOT`, as `library.py` does).
   - `def is_named(ref: str) -> bool` (the rule above: no `.`, `/`, `\`).
   - `def naca4_rows(code: str, n: int = 60) -> list[tuple[float, float]]`: `code` is 4 digits (m=code[0]/100, p=code[1]/10, t=code[2:]/100). Base stations `b_i = (1 - cos(pi*i/n))/2`, i=0..n. Half thickness `yt = 5t(0.2969*sqrt(b) - 0.1260*b - 0.3516*b^2 + 0.2843*b^3 - 0.1015*b^4)` (open trailing edge, Abbott and von Doenhoff; coefficient -0.1015). Camber `yc` and slope angle `th = atan(dyc/dx)`: for m == 0 or p == 0 both are 0; else for b < p `yc = m/p^2 (2pb - b^2)`, `dyc = 2m/p^2 (p - b)`; for b >= p `yc = m/(1-p)^2 ((1-2p) + 2pb - b^2)`, `dyc = 2m/(1-p)^2 (p - b)`. Upper `xu = b - yt sin(th)`, `yu = yc + yt cos(th)`; lower `xl = b + yt sin(th)`, `yl = yc - yt cos(th)`. Return Selig order: upper points from trailing edge to leading edge (i = n..0) followed by lower points i = 1..n (2n+1 = 121 rows). Raise `GeometryError` for a code that is not 4 digits.
   - `def resolve(ref: str)` for a named reference: returns `("rows", rows)` for a NACA name (rows from `naca4_rows`) or `("path", Path)` for a library file (the caller parses it with `read_airfoil`, so the parser is not duplicated); raises the `GeometryError` of the Rule otherwise.
2. `core/hangar/geom/wing.py`: split `read_airfoil(path)` into `read_airfoil(path)` (parses the file to `rows`, then calls) and a new `split_airfoil(rows)` holding the unchanged code from the Lednicer check to the final `return`; `read_airfoil` behaviour must not change. Add `def load_airfoil(ref, base_dir)`: `if airfoil.is_named(ref): kind, v = airfoil.resolve(ref); return split_airfoil(v) if kind == "rows" else read_airfoil(v)`; else `read_airfoil(Path(base_dir) / ref)`. In `_build` replace the `read_airfoil(Path(base_dir) / p["airfoil_file"])` call with `load_airfoil(p["airfoil_file"], base_dir)`. In the `airfoil_file` ParamSpec set `doc="design-folder-relative airfoil .dat, or a name: nacaXXXX (4-digit, generated) or a file in knowledge/airfoils/ without .dat (e.g. s5010)"`. In the registration change `files=lambda p: [p["airfoil_file"]] + list(p["cut_files"])` to `files=lambda p: ([] if airfoil.is_named(p["airfoil_file"]) else [p["airfoil_file"]]) + list(p["cut_files"])`.
3. `core/hangar/geom/tails.py`: same `files=` change for `airfoil_file` and the same `doc=` text (tails passes the reference on to `wing_panel`; no other change).
4. `knowledge/airfoils/s5010.dat`: copy with `cp` (byte-identical). `knowledge/airfoils/README.md`: five lines: what the folder is (named airfoils for `airfoil_file`), the Rule in one paragraph, the format (Selig .dat, first line a title with source URL and date checked), the table of files (`s5010` | S5010 9.82 % | UIUC https://m-selig.ae.illinois.edu/ads/coord/s5010.dat, checked 2026-11-09 (as in the file's header)), and "NACA 4-digit names are generated, not stored".
