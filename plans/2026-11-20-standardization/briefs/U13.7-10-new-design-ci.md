## Why (CI run 45582689127 on draft PR #8, which adds only `designs/a400m-rc/`; shard 1 fails on ubuntu and windows, shards 2 and 3 pass)
Three tests hard-code the set of designs that exist today. Failing list (from `gh -R davinciucberkeley-collab/dbf-hangar run view 45582689127 --log-failed`):
1. `tests/test_expressions.py::test_designs_without_expressions_resolve_unchanged` (line 259): loops over every folder of `designs/` except `concept-a-param` and asserts `load_design(folder).data == yaml.safe_load(text)`; fails for `a400m-rc` because `load_design` fills generator defaults and derived values (PDL 1.2) for a generated design, so the loaded data differs from the file text. Its intent is: PDL-1.0 designs (no expressions, no generators) load unchanged.
2. `tests/test_applicability.py::test_verdict_fixture_records_its_date` (line 108): `assert set(want) == {every folder with a plane.yaml}`; fails because the fixture `tests/fixtures/design-verdicts.json` has no `a400m-rc` entry. Its intent: the fixture records a parseable date and names only real designs (the verdict test itself iterates the fixture).
3. `tests/test_pdl12.py::test_old_designs_untouched` (line 145): takes every `designs/*/plane.yaml`, skips the names in `GENERATOR_DESIGNS = {"concept-a-param"}`, and asserts `d.raw is None and d.resolve_errors == {}` plus no `T0.parameters`/`T0.generator` rows for all the others; fails for `a400m-rc` (`raw` is set: it uses generators). Its intent: the PDL 1.2 loader leaves the OLD designs untouched.
A teammate (Dillon's concept-a-reborn, a student concept) or the demo adding any new design must pass CI without touching tests. The other design-enumerating tests (`tests/test_gates.py:364`, `tests/test_baseline.py:341`, `tests/test_pdl.py:15`) passed with `a400m-rc`; audit them in step 5 and report, change them only if they fail with a new design.

## Decision (stated so the reviewer can check it)
Compare only a frozen list of KNOWN legacy designs, never "every folder": define `LEGACY_DESIGNS = ("c0-a1", "c0-a2", "c0-a3", "c0-lift-cruise", "concept-a", "example-tailsitter-wing", "tiltwing-cakir")` (the seven PDL-1.0 designs committed before generators; `concept-a-param` is NOT in it) in `tests/testutil.py`. A design not in the list is new, so no test pins its numbers, and a separate light test checks that every design at least loads cleanly.
