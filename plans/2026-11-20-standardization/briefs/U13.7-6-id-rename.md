## Exact rules
1. Mapping: read `plans/2026-11-20-standardization.md`; take the table rows after `| old | new |` up to the first line that is not a table row; each row `| U4.<n> | U<w>.<m> |` gives `old -> new` (about 40 pairs, `U4.2 -> U14.1` ... `U4.41 -> U13.6`). `U4.1` has no row and stays unchanged. Print the parsed pairs count (expect 40) and abort if it is below 35.
2. Reference regex (case-sensitive): `(?<![A-Za-z0-9.])U4\.(\d+)(?!\d)`; the replacement is the mapped new id when the captured full number `U4.<n>` is in the mapping, else the match is left unchanged. This keeps `U4.3` distinct from `U4.30`/`U4.36`, leaves the lowercase branch and folder names (`std/u4.36-...`, `plans/.../u4.35/`) untouched, and rewrites compound names such as `U4.36-1-list-append`, `U4.37-4a`, `U4.39-2` to `U13.2-1-list-append`, `U13.3-4a`, `U13.4-2`.
3. File names: every file whose name matches `^U4\.(\d+)(?=[-.])` and whose `U4.<n>` is in the mapping (all are in `plans/2026-11-20-standardization/briefs/`; example `U4.41-1-tail-count.md` -> `U13.6-1-tail-count.md`, `U4.37-env.md` -> `U13.3-env.md`) is renamed with `git mv` to the mapped prefix plus the rest of the name. Abort (rename nothing) if any target already exists or two sources map to one target; print the full old -> new list into `.logs/renames.txt`.
4. Files whose CONTENT is rewritten (rule 2), found with `git grep -l -E "(^|[^A-Za-z0-9.])U4\.[0-9]+"` restricted to these paths: `plans/2026-11-20-standardization/briefs/` (after the renames above), `reviews/`, `docs/`, `knowledge/`, `tests/`, `core/`, `standards/`, `harness/`, `.claude/`. Text files only (skip anything git treats as binary; skip `*.stl`, `*.glb`, `*.png`). Write with the file's own line endings (read and write bytes, `utf-8`, never normalise).
5. NOT touched (leave exactly as is): `plans/2026-11-20-standardization.md` (the conductor edits the plan and keeps the mapping table), `plans/2026-11-20-standardization/archive.md`, the working-note folders `plans/2026-11-20-standardization/u4.*/`, `PROGRESS.md`, `ledger/`, `updates/`, `designs/`, `schema/`, `viewer/`, `.github/`, git history (commit messages, old branches and GitHub PR titles keep the old names).
