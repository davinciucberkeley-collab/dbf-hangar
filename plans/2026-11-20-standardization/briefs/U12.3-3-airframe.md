## Exact steps and outputs
`core/hangar/geom/airframe.py` (imports: `math`, `numpy`, `trimesh`, `kernel`, `Generator`, `ParamSpec`, `register`).
1. Helper `_segment(a, b, thickness: float, chord: float) -> trimesh.Trimesh`: unit cylinder `trimesh.creation.cylinder(radius=1.0, height=1.0, sections=48)` (axis z, centred); `L = |b - a|`, `d = (b - a) / L`; chord direction `c = e_x - (e_x . d) d` normalised (if its length is below 1e-6 use `e_y` instead); `ch = chord or thickness`. 4x4 matrix `M = T(midpoint) @ [R | 0] @ diag(ch/2, thickness/2, L)` with `R` columns `(c, d x c, d)`; `mesh.apply_transform(M)`; return `kernel.require_solid(mesh, "strut")`. Volume is exactly `0.5*48*(ch/2)*(thickness/2)*sin(2*pi/48) * L`.
2. Generator `strut`: params `start` (vec3, required), `end` (vec3, required), `diameter` (number, required, `> 0`: thickness), `chord` (number, default `0`, min 0: 0 = round). Check: `start != end`; `chord == 0 or chord >= diameter`. Build `[_segment(start, end, diameter, chord)]`.
3. Generator `landing_gear`: params `layout` (choice `tricycle|taildragger`, default `tricycle`), `main_x` (number, required), `track` (number, required, `> 0`: distance between main wheel centres), `attach_z` (number, required: z where the leg tops meet the airframe), `ground_z` (number, required), `wheel_d` (number, required, `> 0`), `wheel_w` (number, required, `> 0`), `leg_d` (number, required, `> 0`), `leg_splay_deg` (number, default `0`, min 0; check `< 45`), `front_x` (number, required: nose wheel x for tricycle, tail wheel x for taildragger), `front_wheel_d` (number, default `0`; 0 means `wheel_d`), `front_leg_d` (number, default `0`; 0 means `leg_d`).
   - Check: `tricycle` needs `front_x < main_x`; `taildragger` needs `front_x > main_x` (message names `front_x` and the layout); `attach_z - ground_z > max(wheel_d, front_wheel_d or wheel_d)` (message names `wheel_d`); `leg_d <= wheel_w` and `leg_d <= front_wheel_d or wheel_d` for the front wheel.
   - Build: for each main side `s in (-1, 1)`: axle `(main_x, s*track/2, ground_z + wheel_d/2)`; leg top `(main_x, s*(track/2 - (attach_z - axle_z)*tan(radians(leg_splay_deg))), attach_z)`; leg `_segment(top, axle, leg_d, 0)`; wheel `kernel.tube("y", axle, wheel_w, wheel_d)`. Front: wheel diameter `fw = front_wheel_d or wheel_d`, axle `(front_x, 0, ground_z + fw/2)`, vertical leg from `(front_x, 0, attach_z)` to the axle with diameter `front_leg_d or leg_d`, wheel `kernel.tube("y", axle, wheel_w, fw)`. Return `[kernel.union([...all legs and wheels...])]`.

## Exact tests

- `test_strut_round_volume`: `start [0,0,0], end [0,100,50], diameter 6` -> `A(3) * sqrt(100**2 + 50**2)` = 3152.2 (rel 1e-6); watertight; y bounds within `[-3.0, 103.0]` (abs 1e-6 on the x extent `+-3`).
