### 4. Dispose on clear (finding A2)
- `viewer/vp/loader.js` exports `loadGLB(file)` (moved unchanged from app.js, same `cache.glb`) and `disposeModel(root)`: traverse; for each mesh `geometry.dispose()`; for each material (array or single) dispose it and every texture property it holds (`map`, `normalMap`, `roughnessMap`, `metalnessMap`, `emissiveMap`, `aoMap`). Then `root.clear()`.
- `Viewport.clear()` calls `disposeModel(this.root)` first, then the existing resets. The grid and CG meshes live under `root`, so they are disposed too.
- Cached GLB scenes keep their CPU-side geometry (a later `show()` re-uploads it, which three handles after `dispose()`); do not empty `cache.glb`.

- `viewer/app.js`: remove the four eager `new Viewport(...)`. Add `const vps = {}` and `function getVp(name)` that creates `vps[name]` on first use: `main` -> `$('vp-main')` with `{ onPick }`, `a` -> `$('vp-a')` with `{ onPick }`, `b` -> `$('vp-b')` with `{ onPick }`, `phys` -> `$('vp-phys')` with `{}`. `ctx.vp` passed to modes (in `renderMode`) is an object with getters `main`, `a`, `b`, `phys` calling `getVp`, so the three mode files keep writing `vp.main`, `vp.a`, `vp.b`, `vp.phys` unchanged and a viewport exists only once its mode asks for it. `renderMode` for modes `stress`, `updates`, `ledger` touches no viewport.
