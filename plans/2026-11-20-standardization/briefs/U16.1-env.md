## Export-hash check (every core brief; this is the "existing designs stay byte-identical" proof)
Create `C:/Users/trist/wt/u16.1-SLUG/.logs/hashset.sh` with exactly this text (replace SLUG once on the `W=` line; it is a local helper, never committed):
```
#!/usr/bin/env bash
# usage: bash .logs/hashset.sh TAG DIR...   (DIR relative to the worktree, e.g. designs/c172-rc)
W=C:/Users/trist/wt/u16.1-SLUG; PY=C:/ProgramData/miniforge3/python.exe
cd "$W"; export PYTHONPATH="$W/core" PLANE_CAD_OVERLAY=off
TAG=$1; shift
for d in "$@"; do
  n=$(basename "$d"); X="$W/.logs/x-$TAG/$n"; rm -rf "$X"; mkdir -p "$X"
  for f in glb mjcf json; do
    if $PY -m hangar.cli export "$d" --format $f --out "$X/out.$f" >/dev/null 2>&1; then echo "$d $f $(sha256sum "$X/out.$f" | cut -d' ' -f1)"; else echo "$d $f ERROR"; fi
  done
  if $PY -m hangar.cli export "$d" --format stl --out "$X/stl" >/dev/null 2>&1; then echo "$d stl $(cat "$X"/stl/*.stl | sha256sum | cut -d' ' -f1)"; else echo "$d stl ERROR"; fi
  case "$d" in designs/*)
    $PY -m hangar.cli build-index --design "$n" --out "$X/idx" >/dev/null 2>&1
    for g in "$X"/idx/"$n".*; do echo "$d idx-${g##*/} $(sha256sum "$g" | cut -d' ' -f1)"; done;;
  esac
  $PY -m hangar.cli validate "$d" --tier all --format json --out "$X/val.json" >/dev/null 2>&1; echo "$d validate $(sha256sum "$X/val.json" | cut -d' ' -f1)"
done >> "$W/.logs/hash-$TAG.txt"
```
(Checked 2026-11-25 on `designs/example-tailsitter-wing`: two runs give identical output, about 1 minute per small design, longer for c172-rc.) Procedure: before your first edit run `rm -f .logs/hash-base.txt` then `bash .logs/hashset.sh base DIRS` once per group of at most 3 directories (a foreground call has a 10 minute limit), where DIRS covers every folder under `designs/` plus the fixture folders the brief names; after your last edit the same with tag `after`. `diff .logs/hash-base.txt .logs/hash-after.txt` must print nothing, except for the lines the brief says may change. A line that says ERROR in `base` must say ERROR in `after`. Paste the diff (or "empty") in your report.
