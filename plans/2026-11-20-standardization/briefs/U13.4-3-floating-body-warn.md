## Where

## Why
The A400M gave parts that look attached in the attachment list but hover in the 3D view. `T1.connectivity` checks only the attachment graph and `T1.attachment_contact` only each non-link joint's two parts; a part joined only through a `kinematic_link` attachment or a loose `location`, or a whole body whose attachments are all links, can touch nothing and still pass.

## Rule
For conventional designs only (`NEEDS["conventional"](design.data["morphology"])`, as in U13.4-2; existing designs with servos are tailsitters or lift-plus-cruise, so none changes), after the `T1.connectivity` row in `tier1_geometry`, add `res += _floating_rows(design, meshes, std)`. Variables: `meshes` is the `{component id: [meshes]}` dict `tier1_geometry` already builds; `std["geometry"]["attach_tolerance_mm"]["value"]` is `tol`.
`_floating_rows`: for each component id `c` whose mesh list is non-empty (point masses have none), the candidates are the other ids whose axis-aligned bounding box, grown by `tol` on every side, overlaps `c`'s box; `c` is touching when for some candidate `o` `_min_distance(meshes[c], meshes[o], tol) <= tol` (existing helper, stops early). Not touching -> `CheckResult(f"T1.floating.{c}", WARN, f"{c} touches no other part (nearest: {n} at {d:.1f} mm; tolerance {tol} mm)", STD + "attach_tolerance_mm", {"part": c, "nearest": n, "gap_mm": round(d, 3)})` where `n` is the id with the smallest box-to-box gap (ties by id) and `d = _min_distance(meshes[c], meshes[n])` unstopped; when there is no other component with a mesh `n` is `none` and `d` is `inf` shown as `no other part`. Rows in component order; no row when touching. The root component needs no exemption (it touches its children).
