# Brief U18.3/U18.4-0: Scout the sources behind the new thresholds (two packets)

class: easy · role: scout · plan: §7 U18.3 and U18.4 (D88: every threshold sourced or `pending` with the reason) · rules: D88 (cite only what you opened)

Each packet is one scout. Output uses `knowledge/TEMPLATE-source.md` (frontmatter: id, title, authors, year, url, type, retrieved, verified; sections Summary, Usable rules / numbers, How we could use it). You write only the new files named below and edit nothing else. Numbers appear only if you read them in the opened text, with unit, test conditions and page or table. If a document cannot be read as text, write the file with `verified: false`, `none` under the numbers heading, the URL you tried and what failed; never fill from memory.

## Packet A: tail volumes, elevator effectiveness, damping levels (feeds U18.4-1, -2, -3)
Targets, in this order, stop at the first readable source for each item:
1. Typical horizontal and vertical tail volume coefficients (Vh = Sh lh / (S MAC), Vv = Sv lv / (S b)) by aircraft class: Raymer "Aircraft Design: A Conceptual Approach" table of tail volume coefficients (general aviation single engine, homebuilt, sailplane, ...); or Gudmundsson "General Aviation Aircraft Design"; or university course notes that reproduce the table with attribution (Stanford AA241, Purdue AAE451, TU Delft, Sadraey open notes). Output `knowledge/sources/std-tail-volume-coefficients.md`; one bullet per class: Vh, Vv, and the definition used (reference chord, which span).
2. Elevator effectiveness tau versus elevator-to-tail chord ratio (the Raymer / Roskam / Etkin figure or table): output `knowledge/sources/std-elevator-effectiveness-tau.md`; bullets: chord ratio -> tau, and the formula if given.
3. MIL-F-8785C "Flying Qualities of Piloted Airplanes" (everyspec.com or ASSIST copy, or MIL-STD-1797A): short-period damping ratio limits (Level 1, by flight-phase category A/B/C), phugoid damping (Level 1), Dutch roll minimum damping ratio, damping-frequency product and frequency (by class and category), spiral minimum time to double (by level). Output `knowledge/sources/std-mil-f-8785c-damping.md`; one bullet per limit with level, class and category exactly as printed, and the paragraph or table number.
4. Cessna 172 elevator travel and pitching moment of NACA 2412: NOT in this packet (the U18.2 scout reads the FAA TCDS 3A12 control surface movements); only note the airfoil Cm_ac if the Abbott and von Doenhoff NACA report (NASA NTRS "Summary of Airfoil Data", NACA-824) is readable: output `knowledge/sources/std-naca-824-cm-ac.md` with Cm about the quarter chord for NACA 0012 and 2412 (and the Reynolds number).

## Packet B: material allowables for spar tubes (feeds U18.3)
1. Pultruded or roll-wrapped carbon fibre tube data sheet from a maker whose tubes the team uses or could use (for example Easy Composites, DragonPlate, Rock West Composites, CST/Composite Envisions) giving tensile or flexural strength, modulus and the test standard and fibre direction. Output `knowledge/sources/part-cfrp-tube-datasheet.md` (type: website); bullets with maker, product, outer and inner diameter range, strength (MPa), modulus (GPa), test method. One product is enough; say whether the strength is axial tensile, flexural or compressive.
2. 6061-T6 aluminium tube allowables: MMPDS-xx or MIL-HDBK-5J table value for 6061-T6 (tube, extruded or drawn): Fty and Ftu with basis (A, B or S) and temper; or the Aluminum Association / ASM data sheet with "typical" clearly labelled as typical. Output `knowledge/sources/std-al-6061-t6-allowables.md` (type: standard). c0-a1 uses OnlineMetals 6061-T6 tube 1.000 x 0.058 in.
3. XPS foam is not a spar; do not scout it.

## Pass check (mechanical, per file written)
1. `grep -c "^verified: " <file>` prints 1; frontmatter has all eight template fields with no `<...>` left.
2. Sections `## Summary`, `## Usable rules / numbers`, `## How we could use it` present.
3. Every bullet under numbers ends with the page, table or section.
4. Last line of How we could use it: "values still missing: ..." listing each target above not found.

## Stop rule
After two source attempts per target without readable text, write `verified: false`, `none`, and the attempted URLs; do not search further; report the gaps. Never convert units or add values from memory.
