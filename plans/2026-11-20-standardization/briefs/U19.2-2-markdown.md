## Change
1. `Scorecard.to_markdown(self, design=None)`. Import inside the method: `from .gates.describe import describe_card, fold`. Output, in this order (every `{}` is filled; no other text):
   1. `# Scorecard: {design_id}`, blank line, the verdict line exactly as today (`**Partial run ...**` or `**Accepted:** yes|no`), blank line.
   2. `**Summary:** {F} FAIL, {W} WARN, {S} not checked, {N} not applicable, {P} PASS.` where F, W, P count rows by status, N counts rows with `not_applicable`, S counts SKIP rows that are not `not_applicable`; WARN counts include report-only WARN rows. Blank line.
   3. `## Needs fixing`, `## Warnings`, `## Not checked` (status FAIL, WARN, SKIP-not-n/a), each only when it has entries, entries from `fold(...)` in its order. Entry text, each line indented as shown:
      ```
      - **{STATUS}** **{title}**{": " + labels joined ", " if the entry is a single row with parts}{" _[report-only until 2026-12-08, would be X today]_" if report_only; omit ", would be X today" when would_be is empty}
        {sentence}
        Fix: {hint}                      (line omitted when hint is empty)
        Details: {details}               (single-row entries only)
        Check: `{check_id}`               (single-row entries only)
      ```
      A folded entry (count above 1) prints the first two lines and the Fix line, then one sub-bullet per row: `  - {part labels joined ", " or details if no parts} (`{check_id}`)`.
   4. `## Not applicable ({N})` with one bullet per family: `- {title}: {details of its first row}`; only when N > 0.
   5. `## Passing ({P} checks)` with one bullet per family that has PASS rows: `- {title}: {count} ok`; only when P > 0.
   6. `## Full table`, blank line, then the old table exactly as today: the header line, the separator line, one line per row `| {tier} {name} | {status} | {check_id} | {status}: {message} | {criterion} |`.
   7. The `Fidelity:` paragraph exactly as today (after the table, same blank-line rule).
2. `design=None` is allowed (old callers, tests); labels then come from `describe_card(self, None)`.
3. `ops/design.py` line 74: `card.to_markdown(design)`. `studio.py`: `validate(design).to_markdown(design)`.
