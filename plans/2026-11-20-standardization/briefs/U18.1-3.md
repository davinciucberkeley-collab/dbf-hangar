```python
OPENCAE_ROW_IDS = ("T2.opencae_hover_tw", "T2.opencae_current_margin", "T2.opencae_endurance", "T2.opencae_structure_sf",
                   "T2.opencae_cfd_ld", "T2.opencae_flight", "T2.opencae_mass_cross", "T2.opencae")

def tier2_opencae(design: Design) -> list[CheckResult]:
    """Rows from designs/<id>/opencae/results.json. Never runs anything."""
```

Rules (in this order). Let `rec = opencae_cli.load_result(design)` and `sidecar = (design.base_dir / "opencae-inputs.yaml").is_file()`; use `with overlay.forced_off():` around everything that reads geometry.
   a. `rec is None and not sidecar` -> return `[]` (a design that has not opted in gets no rows, so no baseline changes).
   b. `rec is None and sidecar` -> one row `CheckResult("T2.opencae", SKIP, "no stored OpenCAE results; run: plane opencae run <design id> --analyses mass,propulsion", criterion "opencae_cli", {})`.
   c. `rec["design_hash"] != opencae_cli.design_fingerprint(design, tuple(rec["analyses"]))` -> one row `T2.opencae` SKIP "stored OpenCAE results are out of date (design or standards changed); run: plane opencae run <design id> --analyses <rec analyses joined with commas>".
   d. Otherwise `res = rec["result"]`, `an = res["analyses"]`. For each row below, if its analysis is not in `an` produce nothing for that row; if `an[name]["status"] == "not_evaluated"` produce one SKIP row with message `OpenCAE <name> not evaluated: missing <", ".join(an[name]["missing"])>`; if status is `error` produce one FAIL row `OpenCAE <name> failed: <an[name]["summary"]>`. Otherwise `m = an[name]["metrics"]` and use `m[key]["value"]` and `m[key]["basis"]`.
   Criterion text for every row = `standards/operations.yaml#<key>` (or `standards/design-standards.yaml#hover_thrust_to_weight_min` for the hover row). Every row's `data` dict includes `"basis"` (the metric's basis string) and `"opencae_head"` (rec["opencae_head"]). Every message ends with `; OpenCAE basis <basis>` (for example `; OpenCAE basis estimate`). A pass or fail on an estimate stays PASS or FAIL (hangar has no conditional); the basis is only reported.
   - `T2.opencae_hover_tw`: only when morphology `lift` is "multirotor" or `vtol_method` is not "none". `tw = propulsion.tw_ratio`; limit = `hover_thrust_to_weight_min` value read as `core/hangar/checks.py` line 1195 reads it (open that function; read the same standards entry with `load_standards()`); PASS if tw >= limit else FAIL; message `OpenCAE hover T/W {tw:.2f} (thrust {thrust_total_max_n:.1f} N total, static; minimum {limit})`.
   - `T2.opencae_current_margin`: three rows, one per key `motor_current_margin`, `esc_current_margin`, `battery_current_margin`; limit = `electrical_rating_min_ratio` via `_crit(OPS, ...)`; PASS if margin >= limit else FAIL, built with `_judge` so a pending limit gives SKIP with `would_be`; message `OpenCAE <motor|ESC|battery> current margin {v:.2f} (rating over full-throttle current; minimum {limit})`.
   - `T2.opencae_endurance`: only for the same designs as hover_tw. need = `mission_hover_min` x (1 + `energy_reserve_fraction`) minutes (both via `_crit(OPS, ...)`); PASS if `propulsion.hover_endurance_min` >= need else FAIL; message `OpenCAE hover time {v:.1f} min vs need {need:.1f} min (mission {t} min + {reserve:.0%} reserve)`.
   - `T2.opencae_structure_sf`: `structure.safety_factor`, limit `opencae_structure_sf_min`, via `_judge` (pending -> SKIP with would_be); message `OpenCAE structure safety factor {sf:.2f} (peak {max_stress_mpa:.1f} MPa, {max_disp_mm:.2f} mm; minimum {limit})`.
   - `T2.opencae_cfd_ld`: needs `design.data["flight"]["cruise_ld"]`; if absent -> SKIP "flight.cruise_ld missing: nothing to compare the computed L/D with". Else `err = abs(cfd.ld - declared) / declared`; limit `opencae_cfd_ld_tolerance_fraction`; via `_judge`; message `OpenCAE L/D {ld:.2f} vs declared {declared:.2f} (difference {err:.0%}; tolerance {limit:.0%}); converged {bool(cfd.converged)}; SU2 drag is indicative only`.
   - `T2.opencae_flight`: only for the hover designs. `flight.max_tilt_deg` <= `opencae_flight_max_tilt_deg_max` via `_judge`; message `OpenCAE hover recovery: peak tilt {tilt:.1f} deg, settled in {settle_time_s:.1f} s, drift {position_error_m*100:.0f} cm, throttle margin {throttle_margin:.2f}; maximum tilt {limit} deg`.
   - `T2.opencae_mass_cross`: `mass.mass_kg * 1000` vs `mass_properties(design)["mass_g"]`; limit `opencae_mass_cross_tolerance_g` via `_judge`; message `OpenCAE mass {a:.1f} g vs plane {b:.1f} g (difference {d:.1f} g; tolerance {limit} g)`.
