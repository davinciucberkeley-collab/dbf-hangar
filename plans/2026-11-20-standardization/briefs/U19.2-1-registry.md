```python
@dataclass(frozen=True)
class PartRef:
    id: str
    label: str            # "Hub (cge-001)"

@dataclass(frozen=True)
class RowText:
    check_id: str
    status: str           # PASS / FAIL / WARN / SKIP, unchanged from the row
    family: str           # first two id segments, "T7.wiring"
    title: str            # plain name, from the registry (humanised family if no entry)
    sentence: str         # one sentence; the unwrapped raw message when a template cannot be filled
    hint: str             # "" when the registry has none
    details: str          # the raw message with the report-only prefix removed
    parts: tuple[PartRef, ...]
    group: str            # "part" | "problem" | "design"
    source: str           # first 100 chars of the limit's `source:` (cut at a word), "" if none
    report_only: bool     # message started with gates.REPORT_ONLY_PREFIX
    would_be: str         # data.would_be or data.raw_status or ""
    not_applicable: bool  # CheckResult.not_applicable

def family_of(check_id: str) -> str                               # "T7.wiring.e-hrn-01" -> "T7.wiring"
def load_registry() -> dict                                       # describe.yaml, cached
def standard_limit(criterion: str) -> dict                        # {"value":..,"min":..,"max":..,"source":..} from "file#key"; {} if unknown
def part_label(design, comp_id: str) -> str                       # rule 3 of the spec
def row_parts(design, row: CheckResult) -> list[PartRef]          # rule 3 of the spec
def describe_row(row: CheckResult, design=None) -> RowText
def describe_card(card: Scorecard, design=None) -> list[list[RowText]]   # same shape as card.tiers[i].results
def fold(texts: list[RowText]) -> list[dict]                      # see "Folding"
```
`design=None` means no component data: labels are the id with hyphens as spaces and `Label (id)` still printed.

## Rules to implement (spec section 2 and 3; do not add behaviour)
1. `family_of`: first two dot-separated segments.
2. Report-only prefix: use `from hangar.gates import REPORT_ONLY_PREFIX` (import inside the function to avoid a cycle). Strip it for `details` and `{message}`.
3. `standard_limit("design-standards.yaml#static_margin")`: read `<repo>/standards/<file>` with yaml (`REPO_ROOT` from `hangar.design`); look the key up in the top-level mapping, else in the first top-level value that is a mapping and contains the key. Return `value`, `min`, `max`, `source` when present. Cache per file path. Missing file or key returns `{}`.
4. `source` field of `RowText` = `source:` text of the criterion's key, trimmed to at most 100 characters at a word boundary; `pending` becomes the text `source pending`.
5. `part_label`: component `name`; else first clause of `description` cut at the first of ` (`, `, `, `; `, ` - `, then at most 40 characters at a word boundary; else the id with `-` and `_` as spaces. Printed `Label (id)` (in `part_label` return only the label; `PartRef.label` adds ` (id)`). An id that is not a component of the design: label = id as is, no parentheses.
6. `row_parts`: collect ids in this order from `data.component` (str), `data.parts` (list of str), `data.pair` (list of 2 str, only when both are component ids), `data.link_pairs` (list of lists), and `data.joint` (a str that is an attachment `id` in `design.data["attachments"]`: add its `parent` then `child`; if `joint` is not an attachment id but is a component id, add it). Keep only ids that are components of the design; no duplicates; order of first appearance. With `design=None` return `[]`.
7. Templates: Python `str.format_map` with a dict that holds: all keys of `row.data`; `limit`/`min`/`max` from `standard_limit(row.criterion)`; `source`; `label` (first part's label), `labels` (all part labels joined with ", "); `design_id`; `message` (details); and the named groups of the family's optional `extract:` regex (`re.search` on `details`, groups that did not match are left out). Any `KeyError`, `ValueError`, `IndexError` or `TypeError` while formatting returns the fallback: sentence = `details`. A missing `what` for the row's status also gives the fallback.
8. `group` = registry `group`; default `problem`.
9. `title` = registry `title`; for a family without an entry the family tail with underscores as spaces, capitalised (`T3.foo_bar` -> `Foo bar`).
10. `hint` = registry `hint` formatted the same way, `""` if absent or on error.
11. `describe_card` never reorders or drops rows.

### Folding
`fold(texts)` takes the RowTexts of one card (any order) and returns a list of entries `{"key": str, "status": str, "title": str, "count": int, "sentence": str, "hint": str, "rows": list[RowText]}`: rows with the same `family` and `status` are folded into one entry only when the registry marks the family `fold: true` and there are 3 or more such rows; otherwise each row is its own entry with `count` 1. A folded entry's `sentence` = registry `fold_what` formatted with `{count}` and `{labels}` (the first 5 distinct `check_id` subjects, taken from `data.joint` or the first part label, joined with ", ", then ", ..." when more); `title` = registry title followed by `: {count} {fold_noun}` (registry `fold_noun`, default `rows`). Entry order: FAIL, WARN, SKIP (not applicable last), PASS; inside a status by first appearance.
