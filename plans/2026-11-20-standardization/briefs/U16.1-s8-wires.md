## What is wrong today

## Decision (default taken)
- A harness is **routed** when it has any of `waypoints`, `from_port`, `to_port` (a design with none of them keeps the old straight-segment T7 row and no GLB node). Control points = `[start] + waypoints + [end]`; `start` = the world position of `from_port` on the `from` component, else the CG of `from` (`component_cg`, as T7 does today); `end` likewise with `to_port` and `to`. Waypoints are absolute body-frame mm; `waypoints` defaults to `[]` (a straight wire port to port).
- Port world position = the component transform of the `ports.<name>.point` (`geometry._transform(component)`: `rotation_deg` then `position`), direction likewise rotated. The component must use `generator: library_part` and its part must list the port.
- Curve: uniform Catmull-Rom through the control points, end points duplicated (clamped), 8 samples per segment: for `P0..P3` and `t = k / 8`, `q(t) = 0.5 * (2 P1 + (-P0 + P2) t + (2 P0 - 5 P1 + 4 P2 - P3) t^2 + (-P0 + 3 P1 - 3 P2 + P3) t^3)`; for `n` control points there are `8 * (n - 1) + 1` curve points (the last one is the last control point). Tube: 12 sides, radius `diameter_mm / 2`, default diameter **1.5 mm** (a drawing default; `gauge_awg` is NOT used for the drawn size).
- Visual only: the tube is a GLB node named `wire-<harness id>` with metadata `{"type": "wire", "mass_g": 0, "visual_only": true}`; it is never in `components`, has no mass, no T1 row, no MJCF body and no STL; its mass stays in the existing allowances. A harness id that makes `wire-<id>` equal to a component id is a T7 FAIL (below) and is not drawn.
- T7 for a routed harness: the envelope is every part of the components in `[from, *route, to]` (point masses add nothing); the checked points are all curve points; clearance is the existing `wire_clearance_mm` (`load_gate_thresholds`); `exposed_ok` works as today. Reported length = the polyline length through the control points (a lower bound of the curve length). Bend radius is NOT computed in S8 (deferred, no row).
- Out of scope (state in the PR): bend-radius figure, wire mass, connectors as parts, wires that follow a moving part (every end must sit on a part that does not articulate; not checked), `gauge_awg` sizing, STL export of wires.
