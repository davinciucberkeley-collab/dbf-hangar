## Schema of owner and date
On any standards entry (a dict with `source`), two optional sibling keys, written right after the `source:` line, same indentation:

```yaml
  source: team constraint, <where it came from>
  owner: Tristan          # a non-empty person name; "Tristan" or "Dillon" today
  date: "2026-11-25"      # ISO date YYYY-MM-DD, written as a quoted string (an unquoted yaml date also reads, but is turned into a string)
```
Rule (the fidelity change): an entry whose `source` text, lower-cased and stripped, starts with `team constraint` counts as sourced only if `owner` is a non-empty string other than `tbd`, `unknown`, `pending` (any case) AND `date` is a valid ISO date. Without both it counts as unsourced, like `pending`. Every other source text keeps the current rule (counts unless exactly `pending` or `internal convention`, case-insensitive). `owner` and `date` on a non-team entry are allowed and ignored.

```python
_NO_OWNER = ("", "tbd", "unknown", "pending")


def is_sourced(th: dict | None) -> bool:
    """A resolved threshold counts as sourced unless its source is `pending` or `internal convention`; a source that starts
    with `team constraint` also needs a named owner and an ISO date (D91 b)."""
    if not th:
        return False
    text = str(th["source"]).strip().lower()
    if text in _UNSOURCED:
        return False
    if text.startswith("team constraint"):
        owner = th.get("owner")
        if not isinstance(owner, str) or owner.strip().lower() in _NO_OWNER:
            return False
        try:
            datetime.date.fromisoformat(str(th.get("date")))
        except ValueError:
            return False
    return True
```

def _th(source, **kw):

def test_team_constraint_needs_owner_and_date():
    assert not is_sourced(_th(TEAM))
    assert not is_sourced(_th(TEAM, owner="Tristan"))
    assert not is_sourced(_th(TEAM, date="2026-11-25"))

def _walk(node, where, out):
    if isinstance(node, dict):
        if isinstance(node.get("source"), str):
            out.append((where, node))
        for k, v in node.items():
            _walk(v, f"{where}#{k}", out)
    elif isinstance(node, list):
        for i, v in enumerate(node):
            _walk(v, f"{where}[{(v.get('id') if isinstance(v, dict) else i)}]", out)


def _team_entries():
    out = []
    for p in sorted(STANDARDS.glob("*.yaml")):
        _walk(yaml.safe_load(p.read_text(encoding="utf-8")), p.name, out)
    return [(w, e) for w, e in out if e["source"].strip().lower().startswith("team constraint")]
