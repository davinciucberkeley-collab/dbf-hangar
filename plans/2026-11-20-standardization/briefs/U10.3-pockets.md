## Design (SPEC)
Pockets follow the swept poses of every cut mesh that belongs to a moving component.
1. New `wing_panel` params in `wing.py`: `cut_sweep: ParamSpec("choice", default="swept", choices=("none", "swept"))` and `cut_poses: ParamSpec("list", default=[], doc="derived by the resolver from the design's joints when cut_sweep is swept; do not write")`. Default `swept` means NO design file changes; a wing with no articulated neighbour gets an empty `cut_poses` and builds exactly as today.
2. `cut_poses` entry shape: `{"file": "<a cut_files entry>", "matrices": [[12 floats], ...]}` = the 3 top rows of a 4x4 body-frame transform, row-major, each float `round(x, 9)`, identity and duplicates removed.
3. `_build`: after loading each cut mesh `m` also add, for every matrix of its `cut_poses` entry, `m.copy()` with `apply_transform(4x4)`. All copies join the same single `kernel.difference` call (keep the existing bounds filter on every copy). Neutral mesh always stays in. `_check` adds: an entry whose `file` is not in `cut_files` or whose matrices are not lists of 12 numbers is an error string; `cut_sweep` invalid values are already caught by `choices`.
4. New `core/hangar/geom/sweeps.py`: `def swept_cut_poses(data: dict, cut_files: list[str], base_dir: Path) -> list[dict]` (data = resolved-reference design dict, as in `resolve_design_data`):
   a. Map each cut file (normalise with `posixpath.normpath`) to the component ids whose `geometry.mesh.file` equals it; files with no such component are ignored.
   b. `design = Design(data, Path(base_dir) / "plane.yaml")` (import inside the function: `hangar.geom` must not import `hangar.design` at module level).
   c. Sample set = (i) `hangar.checks._configurations(design, step)` with `step` from `load_standards()["geometry"]["articulation_sweep_step_deg"]["value"]`, plus (ii) `hangar.gates.mechanisms.mechanism_pose_angles(design, load_gate_thresholds()["mechanism_contact_step_deg"]["value"])` (new, Design item 6). A mechanism that raises `RuntimeError`/`KeyError` while simulated is skipped (T6 reports it).
   d. For each configuration `pose_transforms(design, ang)[cid]`; collect per cut file the non-identity matrices (`np.allclose` with identity, atol 1e-9, dedupe by rounded values). A component that is not downstream of any articulated joint yields nothing. The cutting wing itself is assumed static (not downstream of a joint); if it is, return `[]` for it.
   e. Return the list of entries sorted by file name; deterministic.
5. `resolve.py` `resolve_design_data`: after `data = resolve_references(raw)`, for every generated component whose `geometry.generator == "wing_panel"`, with `geometry.params.cut_files` non-empty and `geometry.params.get("cut_sweep", "swept") == "swept"`: `c["geometry"]["params"]["cut_poses"] = swept_cut_poses(data, cut_files, base_dir)` (any exception from sweeps -> `errors[cid] = "cut_sweep: <msg>"`, component keeps neutral-only). This is the only place poses are derived, so design.data, T0, geometry, export, mass and the FEA hash all see the same params; the file as written is never changed, and `cut_poses` is never stored.
6. `mechanisms.py`: add `_pick_steps(sim, step_deg)` returning the `picks` list exactly as in `_collision` and make `_collision` call it (no other change); add public `mechanism_pose_angles(design, step_deg) -> list[dict[str, float]]` returning, for each mechanism in `design.data.get("mechanisms", [])`, `{driver: _clamp(s["input_deg"], driver range), **s["followers"]}` for each pick. T6 output must stay identical (Pass 3).
