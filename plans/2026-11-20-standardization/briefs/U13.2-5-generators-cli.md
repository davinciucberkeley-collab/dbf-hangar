## Why (red on main)

## Exact steps
1. Create `core/hangar/ops/generators.py` with module docstring `"""Read-only view of the generator registry (U13.2)."""`. Imports: `from . import op, OpResult, OpInputError`, `from ..geom import registry` and `import hangar.geom  # noqa: F401` (registers the built-in generators; see `core/hangar/geom/__init__.py`).
2. Op `generators.list`: `@op(name="generators.list", summary="List the geometry generators a component can use (geometry: {generator: <name>, params: {...}}).", render=...)` `def list_() -> OpResult`. Data `{"generators": [{"name": n, "required": [names of required params, in registry order], "param_count": int}, ...]}` for `registry.names()` (already sorted). Render: one line per generator `<name>  (<param_count> params; required: <comma list or "-">)`.
3. Op `generators.show`: `def show(name: str) -> OpResult`; unknown name -> `OpInputError(str(KeyError message))` using `registry.get(name)`'s KeyError text (it already lists the known names; strip the surrounding quotes `e.args[0]`). Data `{"name": name, "units": "lengths mm, angles degrees, mass g (component-local frame)", "params": [{"name", "kind", "required", "default", "minimum", "exclusive_minimum", "choices": list, "doc"} ...]}` taken from `gen.params` (a dict of `ParamSpec`) in registry order, `choices` as a list, `default` as stored (None when absent), and `"files_param_example"` NOT included. Render: first line `<name>`; second line `units: <units>`; then one line per param `  <name> (<kind>, required|default <default>[, min <minimum>|>0 <exclusive_minimum>][, one of a|b|c]): <doc>` (omit empty parts, no trailing colon when `doc` is empty); last line `example: geometry: {generator: <name>, params: {<required param>: <kind>, ...}}` listing only required params (`{}` when none).
4. Regenerate `docs/cli.md`.
