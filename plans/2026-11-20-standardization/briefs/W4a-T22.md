## Facts (tactician, verified on `913eac3`)
- The only place `test_studio_api_end_to_end` talks to a refusal is `tests/test_studio.py:113`: a POST with body `{}` and header `Origin: https://evil.example`, expecting HTTP 403.
- `core/hangar/studio.py:416` (`do_POST`): the cross-site check returns `self._err("cross-site request refused", 403)` before the request body is read (`_body()` is at line 367 and is first called at line 419). The handler then closes the socket with unread bytes, and on Windows the client sees `ConnectionAbortedError` (WinError 10053) or `ConnectionResetError` (10054) instead of the 403.

- `MAX_BODY` is defined at `core/hangar/studio.py:40`.

### 3. Create the repro script (not committed; `.logs/` only)
Create `C:/Users/trist/wt/w4a-t22/.logs/repro_403.py` with exactly:
```python
import collections
import threading
import urllib.error
import urllib.request
from http.server import ThreadingHTTPServer

from hangar import studio

httpd = ThreadingHTTPServer(("127.0.0.1", 0), studio.make_handler(studio.Studio()))
threading.Thread(target=httpd.serve_forever, daemon=True).start()
base = f"http://127.0.0.1:{httpd.server_port}"
count = collections.Counter()
for _ in range(3000):
    req = urllib.request.Request(base + "/api/check-all", data=b"{}", headers={"Origin": "https://evil.example"})
    try:
        urllib.request.urlopen(req, timeout=10)
    except urllib.error.HTTPError as e:
        count[e.code] += 1
    except Exception as e:  # noqa: BLE001
        count[type(e).__name__] += 1
print(dict(count))
httpd.shutdown()
httpd.server_close()
```
