## Why (checked on main)
U4.32-1's `tail_upsweep_deg` raises only the tail end cap; every station shares `center_z`. The A400M fuselage has a flat top line (x 26-38 m) and an upswept lower line: with one centre z the body comes out as a symmetric shrink, the top about 0.6 m too low aft (gap 7). A station given as `[x, width, height, dz]` is rejected today: `stations: each station must be [x, width, height]`.

## Exact steps (`core/hangar/geom/parts.py`)
1. `def _is_station(h) -> bool`: a list/tuple of length 3 or 4 whose items are all numbers (not bool); the 4th item (`dz`, mm, may be negative) is optional.
2. `_fuse_check`: use `_is_station` instead of `_is_triple`; message `"stations: each station must be [x, width, height] or [x, width, height, dz]"`; the width/height `> 0` test applies to items 1 and 2 only (`s[1]`, `s[2]`).
3. `_fuse_build`: `dz(s) = s[3] if len(s) == 4 else 0.0`. Station loops use centre z `cz + dz(s)`; the nose cap sections use `cz + dz(st[0])`; the tail cap sections use `cz + dz(st[-1]) + (x - xl) * tn`. With no 4th item anywhere every result is bit-for-bit the old one.
4. `stations` ParamSpec doc: `"[x, width, height] or [x, width, height, dz] per station, mm; dz shifts that station centre in z"`.

5. (U4.39) New param `"smooth_rings": ParamSpec("int", default=1, minimum=1, doc="1 = off (one ring per station, straight lofts); n > 1 = n rings per station interval, width, height and dz interpolated smoothly between stations, count")`. Behaviour: `1` is the existing code path (bit-identical). For `n > 1`, before the loft, replace the station list by the resampled list: for each interval between stations `i` and `i+1`, rings at `x_i + (x_{i+1} - x_i) * k / n`, `k = 0..n-1`, plus the last station, with `width`, `height` and `dz` taken from `scipy.interpolate.PchipInterpolator` curves through the stations (monotone, no overshoot; with only 2 stations Pchip is linear); stations given with 3 items have `dz = 0`. The nose and tail caps use the first and last station as before (their rings are unchanged). `_fuse_check` adds `"smooth_rings: must be >= 1"` for `smooth_rings < 1` via the ParamSpec minimum (no extra code if `validate_params` already reports it; verify with the test).

## Tests: `tests/test_fuselage_station_z.py`

2. `test_dz_shifts_a_station`: stations `[[0, 40, 20, 0], [100, 40, 20, 30]]`: volume equals the `ST3` build volume (rel 1e-9, a sheared prism has the same volume); `bounds[0][2] == -10` and `bounds[1][2] == 40` (abs 1e-6).
3. `test_nose_follows_first_station_dz`: `[[0, 40, 20, 30], [100, 40, 20]]`, `nose_length=30`: `bounds[1][2] == pytest.approx(40, abs=1e-6)` and `bounds[0][2] == pytest.approx(-10, abs=1e-6)`.
