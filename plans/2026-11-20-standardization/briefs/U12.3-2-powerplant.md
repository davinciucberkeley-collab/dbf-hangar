## Exact steps and outputs
Create `core/hangar/geom/powerplant.py`: imports as in `parts.py` (`math`, `kernel`, `Generator`, `ParamSpec`, `register`), plus `numpy` and `trimesh` for the blade rotations. Define `_s(shape, t)` for `shape in {cone, ellipsoid, ogive}` and `tip_frac`: `cone: tip_frac + (1 - tip_frac) * t`, `ellipsoid: max(tip_frac, sqrt(1 - (1 - t)**2))`, `ogive: max(tip_frac, sin(pi*t/2))`.
1. Generator `nacelle` (`kernel.revolve("x", center, profile)`; profile list of `(x_local, radius)` closed by the kernel as for `tube`: start `(x0, 0.0)`, ring points, end `(x1, 0.0)`):
   - params: `length` (number, required, `> 0`), `diameter` (number, required, `> 0`), `nose_length` (number, default `0`, min 0), `tail_length` (number, default `0`, min 0), `nose_shape` (choice cone|ellipsoid|ogive, default ellipsoid), `tail_end_frac` (number, default `0.3`; check `0 < x <= 1`: end radius as a fraction of `diameter/2`), `tip_frac` (number, default `0.02`; check `0 < x < 0.5`), `cap_rings` (int, default `8`, min 2), `inlet_d` (number, default `0`, min 0), `inlet_depth` (number, default `0`, min 0), `center` (vec3, default `[0,0,0]`: centre of the full length).
   - check: `nose_length + tail_length <= length`; `inlet_d < diameter`; `inlet_depth <= nose_length + (length - nose_length - tail_length)` and `inlet_d > 0` iff `inlet_depth > 0`.
   - build: `R = diameter/2`, `x0 = -length/2`, nose rings `k = 0..n` at `x0 + nose_length*k/n`, radius `R * _s(nose_shape, k/n)` (for `nose_length > 0`; else start with a flat disc at radius `R`: ring `(x0, R)`); body to `x1 - tail_length`; tail rings `k = 1..n` at `x_t + tail_length*k/n`, radius `R * (1 - (1 - tail_end_frac) * k/n)`; if `tail_length == 0` the end disc is flat at radius `R`. When `inlet_d > 0`, subtract `kernel.tube("x", (x0 + inlet_depth/2 - 0.5, 0, 0), inlet_depth + 1.0, inlet_d)` placed in `center` frame before the final shift (so the bore opens through the front face). Translate by `center` at the end (or pass `center` to `revolve`).
2. Generator `propeller`:
   - params: `blades` (int, required, min 2), `diameter` (number, required, `> 0`), `hub_d` (number, required, `> 0`), `hub_length` (number, required, `> 0`), `root_chord` (number, required, `> 0`), `tip_chord` (number, required, `> 0`), `thickness_frac` (number, default `0.08`; check in `(0, 0.5)`), `pitch_deg` (number, default `0.0`, check `abs < 60`), `spinner_length` (number, default `0`, min 0), `handed` (choice `cw|ccw`, default `cw`: `ccw` negates the pitch sign), `center` (vec3, default `[0,0,0]`: hub centre).
   - check: `hub_d < diameter`; `root_chord <= hub_length`.
   - build: radial inner end `r0 = hub_d/2 - 1.0` (1 mm inside the hub), outer end `R = diameter/2`. A blade is `kernel.loft("y", [(r0, loop(root_chord)), (R, loop(tip_chord))])` where `loop(c)` is the rectangle in (x, z): `x` in `+-thickness_frac*c/2`, `z` in `+-c/2`, rotated by `pitch_deg` about the y axis (use the same rotation form as `wing._place`'s twist: `x' = x*cos(t) + z*sin(t)`, `z' = z*cos(t) - x*sin(t)`, `t = radians(pitch_deg)`, negated for `ccw`). Blade `k` (`k = 0..blades-1`) is that mesh rotated about the x axis by `360*k/blades` degrees (`trimesh.transformations.rotation_matrix(angle, [1,0,0])` then `mesh.apply_transform`). Hub: `kernel.tube("x", (0,0,0), hub_length, hub_d)`. Spinner (if `spinner_length > 0`): `kernel.revolve("x", (0,0,0), profile)` of a cone on the -x side: `[(-hub_length/2 + 1.0, 0.0), (-hub_length/2 + 1.0, hub_d/2), (-hub_length/2 - spinner_length, tip_frac*hub_d/2 with tip_frac = 0.02), (-hub_length/2 - spinner_length, 0.0)]`. Result `[kernel.union([hub, spinner?, *blades])]` translated by `center`.
