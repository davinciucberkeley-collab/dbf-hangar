## Dependency decision (stated, because the task said no heavy deps without saying so)
Nothing on main can draw an image: `pyrender`, `pyglet`, `vtk`, `open3d` are not installed; `mujoco` (a core dependency) renders only through an OpenGL window context, which is not reliable headless on Windows. `matplotlib` 3.11 and `PIL` are installed in this environment but are NOT in `pyproject.toml`. This brief uses `matplotlib` (Agg backend, no display) through a flat 2D polygon projection that this brief specifies, and adds it as an optional extra `render = ["matplotlib"]` and to the `dev` extra (CI installs `.[mcp,dev]`, so the tests run in CI). Without matplotlib the op fails with a clear message. If the conductor prefers no new dependency, the alternative is a numpy z-buffer rasteriser (slower, about 100 more lines); do not build it unless told.

## Interface
`core/hangar/render.py`: `def render_png(design, out, *, view: str = "iso", size: int = 900, max_faces: int = 60000) -> Path`. Views and screen basis (body frame: +x aft, +y starboard, +z up; `right`, `up` are unit vectors in the body frame; the vector towards the viewer is `t = right x up`):
- `top`: right `(0, 1, 0)`, up `(-1, 0, 0)` (nose up, starboard right; `t = (0, 0, 1)`).
- `side`: right `(1, 0, 0)`, up `(0, 0, 1)` (port side seen, nose left; `t = (0, -1, 0)`).
- `front`: right `(0, -1, 0)`, up `(0, 0, 1)` (seen from the nose; `t = (-1, 0, 0)`).
- `iso`: `t = normalize(-1, -1, 1)` (nose, port side, above); `right = normalize(cross((0, 0, 1), t))`; `up = cross(t, right)`.
Anything else -> `ValueError("view must be one of top, side, front, iso")`.
Steps: for every component of the design that is not a point mass, `component_parts(c, design.base_dir)` (neutral pose); gather all triangles (`mesh.triangles`, mm); if the total face count exceeds `max_faces`, keep every `k`-th face of each part with `k = ceil(total / max_faces)` (deterministic); per-face colour: hue `TYPE_HUES.get(c["type"], 0.9)` (from `hangar.export`), saturation 0.45, value 0.85 -> RGB via `colorsys.hsv_to_rgb`, shaded by `shade = 0.35 + 0.65 * abs(n . l)` with `n` the unit face normal and `l = normalize(t + 0.5 * right + 0.5 * up)`; project each vertex to `(p . right, p . up)`; sort faces by depth `centroid . t` ascending (far first); draw with `matplotlib.collections.PolyCollection(..., linewidths=0, antialiaseds=False)` on a `matplotlib.figure.Figure` with `FigureCanvasAgg` (never `pyplot`), figure `size/100` inches square at 100 dpi (so the PNG is exactly `size` x `size`), white background, `ax.set_aspect("equal")`, axes off, limits = projected extents grown by 5 % of the larger extent on every side; add one text line at the lower left, `f"{design id}  {view}  mm"`, font size 9; save with `fig.savefig(out, dpi=100, metadata={"Software": None})`. Return the path. `import matplotlib` inside the function; on ImportError raise `RuntimeError("design render needs matplotlib: pip install matplotlib (or pip install -e .[render])")`.
Op (in `ops/design.py`, after `bounds_op`):
```python
@op(name="design.render", summary="Render the model to a PNG (top, side, front or iso view; headless; needs matplotlib). A design that uses licensed CAD overlay parts may only be rendered to a local, untracked path.", mutates=True, render=lambda r: "\n".join(r.data["files"]))
def render_op(path: str, *, out: Path, view: Literal["top", "side", "front", "iso", "all"] = "iso", size: int = 900) -> OpResult:
```
It loads the design as `export_op` does, rejects `size` outside 200..2000 (OpInputError), and for each requested view (`all` = the four views, files named `<stem>-<view>.png` next to `out`'s stem; a single view writes exactly `out`) calls `hangar.geom.overlay.guard_output(out_path, design)` first (so an overlay-built render is refused on tracked paths and marked local-only, as the other exports) and then `render_png`. `data = {"files": [...]}`, `changed_files` the same list; a `RuntimeError` or `ValueError` becomes `OpResult(False, {}, [f"render failed: {e}"])` as `export_op` does.
`pyproject.toml`: add `render = ["matplotlib"]` under `[project.optional-dependencies]` and add `"matplotlib"` to the `dev` list.
