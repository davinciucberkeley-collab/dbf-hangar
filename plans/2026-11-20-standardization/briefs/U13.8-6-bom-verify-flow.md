## Why (red on main, 2026-11-25)
`design add <d> bom.items --value '{id: servo, qty: 1}'` writes the new line in flow style (`    - {id: servo, qty: 1}`, or inside `bom: {items: [...]}` when the bom is one flow line). `plane bom verify` then fails with `flow-style bom line; edit by hand` (`core/hangar/ops/bom.py`, the `startswith("- {")` guard) or, for a list inside a flow mapping, falls into the block path and fails `verification stamp did not round-trip as written`. So an agent cannot verify a BOM line it just added.

## Decision (the smaller change)
Keep the block-style code path byte-for-byte as it is, and for flow lines reuse `pdledit.add_value`, which already inserts a new key into a one-line flow mapping without touching other text (it is what `design set --kind add components[x].field` uses). No change to `design add` (its flow output is the repo's layout for added elements).

## Exact steps (`verify_op`)
1. After `index` and `existing` are checked (the "already verified" refusal stays first) and after `ruamel_root = YAML().load(text)`: `items_node = ruamel_root["bom"]["items"]`; `flow = items_node.fa.flow_style() or items_node[index].fa.flow_style()` (the list is a one-line flow list, or the element itself is a flow mapping).
2. If `flow`: `want = {"by": by, "date": today, "method": method, "evidence": evidence}` (the stamp dict, same fields as now), `patched = pdledit.add_value(text, f"bom.items[{item}].verified", want)` (it raises `OpInputError` ending `edit the file by hand` for a multi-line flow element or any layout it cannot patch without rewriting other text: let that error propagate unchanged), and the returned `line` data is `pdledit.render_flow(want)`. Then the existing tail runs unchanged: round-trip check against `want`, `pdledit.check_schema`, `write_bytes`.
3. If not `flow`: the existing block code runs exactly as now (the `startswith("- {")` guard is replaced by the `flow` branch above; a block element whose first line starts with `- {` but is multi-line is a flow element and goes to the `add_value` branch, which refuses it with the hand message).
4. Move the `today = date.today().isoformat()` line above the branch so both paths use it.
