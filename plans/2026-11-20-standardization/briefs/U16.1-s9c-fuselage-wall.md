## What is wrong today
`fuselage_loft` is always a solid (`parts.py::_fuse_build` returns one `kernel.loft("x", secs)`). A servo placed inside it is buried and invisible in Studio, and `mass_model` hosts count foam where there is a cavity in the real aircraft (gap G5).

## Decision (default taken; opt-in, default byte-identical)
New param `wall` (number >= 0, default 0.0, mm). `wall == 0`: the existing code path, bit-identical. `wall > 0`: the outer loft minus an inner loft; the ends stay closed (walls at the nose and tail).
Algorithm (exact):
1. While building the sections record every ring as `(x, cz, w, h)` (`cz` = the centre z used for that ring, `w`/`h` = the width and height passed to `_fuse_loop`), in the same order as `secs`; build `secs` from the rings with the same `_fuse_loop(shape, ex, cy, cz, w, h)` call and the same arguments as today (bit-identical outer loft; nose cap rings use `w0 * s` and `h0 * s`, tail rings `wl * s`, `hl * s`).
2. `x0`, `x1` = first and last ring x. Inner candidates = rings with `x0 + wall <= x <= x1 - wall`, plus `ring_at(x0 + wall)` and `ring_at(x1 - wall)` when no ring has exactly that x (linear interpolation of `cz`, `w`, `h` between the two neighbouring rings).
3. Keep candidates with `min(w, h) >= 2 * wall + 1.0`; then keep only the contiguous run (in x order) that contains the candidate with the largest `min(w, h)`. Fewer than 2 kept -> `GeometryError("wall: too thick, no inner void")`.
4. Inner sections: `(x, _fuse_loop(shape, ex, cy, cz, w - 2 * wall, h - 2 * wall))` for the kept rings; `inner = kernel.loft("x", inner_secs)`; result `[kernel.difference(outer, [inner])]`.
5. Notes for the docs: the wall is measured along the width and height axes, so it is exactly `wall` on a rectangle section and only approximately on ellipses; the ends are solid up to the first kept ring (at least `wall` thick); cavities (`cavities`, S3 bays) are cut afterwards from the shell as before.
`_fuse_check`: `wall: needs a station at least 2 * wall + 1 mm wide and high` when `wall > 0` and no station has `min(width, height) >= 2 * wall + 1`.
