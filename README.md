# DBF Hangar

One place for the 161 Design-Build-Fly team's aircraft: one design language (PDL), one `plane` CLI that agents and people use for every task, one app to see it all, and one standard every design is checked against.

Status: **planning** (2026-11-20). v1.0 is due 2026-12-01.

- Plan and spec: [plans/2026-11-20-standardization.md](plans/2026-11-20-standardization.md)
- Agent roles: [.claude/agents/](.claude/agents/)

hangar adapts and replaces [aircraft-platform](https://github.com/davinciucberkeley-collab/aircraft-platform) and [DBF-Combined](https://github.com/davinciucberkeley-collab/DBF-Combined) (which already holds DBF-VTOL, DillonVTOL, TiltWing and OpenCAEModel). What comes from where will be listed in `PROVENANCE.md`.
