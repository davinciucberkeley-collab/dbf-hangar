## Summary
K01's airframe with six 4S lift stations instead of four, so the hover can survive one motor loss. The source calls it the only motor-out tolerant layout under the cost cap. The morph cells follow from the code string (L1, W1, C1), and C1 has no row in the table, so only the lift and vtol cells are listed.

## Key facts
- Total cost 1,732.90 USD, reserve 267.10 USD; six lift stations, one cruise motor, four control servos, three packs [AUDIT-LOG.md, Additions K21 row].
- Relative to K01 it adds two motors with their ESCs, propellers and wiring; the screen prices it about 97 USD higher [AUDIT-LOG.md, Additions K21 row; SCREENING.md row K21].
- The quadplane frame guide lists a hexa frame class; a January 2026 developer call discussed a thrust-loss change tested on a hexa [AUDIT-LOG.md, Additions K21 row].
- Motor-out survival needs power headroom, so the source says hover thrust-to-weight with one motor out must be sized in [AUDIT-LOG.md, Additions K21 row].

## Status in the study
MERGE into K01 (SCREENING.md row K21): it is K01 with two more stations, and the decision waits for K01's T/W and reserve. It stays visible because it is the only motor-out tolerant layout under the cap. Not carded, so no judging scores.
