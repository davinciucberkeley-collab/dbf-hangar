## Summary
A Y6 layout with six motors in coaxial pairs, where the front four motors tilt on one axle for cruise. It is the only tilting layout in the set that tolerates a hover motor-out, at the price of two more motors than K06. The morph cells come from the code string (L2, W2, C3), and the source's own code has no approximation.

## Key facts
- Total cost 1,663.42 USD, reserve 336.58 USD; six lift stations, one tilt servo, two elevon servos and three packs; 115 USD above K06 [AUDIT-LOG.md, Additions K25 row; SCREENING.md row K25].
- The tilt-rotor guide's supported-frame table lists a Y6 frame class [AUDIT-LOG.md, Additions K25 row].
- A commercial Y6 product from 2014 used this layout; its DIY frame is now discontinued according to the archived documentation [AUDIT-LOG.md, Additions K25 row].
- A 2025 forum thread reports that yaw authority is lost during transition, and a later change to winglet size and tilt rate is reported as the fix [AUDIT-LOG.md, Additions K25 row].
- The screen gives 8–10 weeks and six stations to wire; no purchasable kit was found [SCREENING.md row K25; AUDIT-LOG.md, Additions K25 row].

## Status in the study
DROP (SCREENING.md row K25): motor-out tolerance is bought with six stations, 115 USD over K06, and a documented transition failure; it carries too many unknowns for a single airframe in twelve weeks. Not carded, so no judging scores.
