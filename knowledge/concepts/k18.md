## Summary
A bought carbon X-frame quadcopter on 4S batteries, used as the baseline; it has no transition, so it is not a VTOL demonstrator. The study keeps it as a trainer and as a hover test bed for motors on other concepts, if budget allows. Its cost is an estimate. The morph cell is not approximate.

## Key facts
- A bought carbon X frame on 4S; the MORPH row marks it as the baseline and not a transition aircraft [MORPH.md §3.1 row K18]
- The MORPH row marks it as failing the transition mission (M-A) [MORPH.md §3.1 row K18]
- Cost is about $1,100–1,300 (ESTIMATE): frame, four 4S stations and floors [SCREENING.md row K18]
- Build time is 1–2 weeks, and ArduCopter support is mature [SCREENING.md row K18]

## Status in the study
DROP (as the aircraft). Reason: with no transition it cannot be the VTOL demonstrator; it is kept as the trainer and the hover test bed for K01 and K09 motors, if it fits the budget. No card exists, so no judging scores.
