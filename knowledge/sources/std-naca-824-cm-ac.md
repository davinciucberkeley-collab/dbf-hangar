## Summary
The NACA 824 report was opened as text and the moment-coefficient method is readable (printed pp. 14-15). The quarter-chord pitching-moment values for NACA 0012 and NACA 2412 are not in the text layer: they appear only in the supplementary plotted data sheets, which did not extract as numbers. No Cm value and no Reynolds number for either airfoil could be read, so nothing is recorded as a number.

## Usable rules / numbers
none (Cm about the quarter chord for NACA 0012 and NACA 2412 not found as printed numbers. Reynolds number for the plotted 2412 data not found in the text layer. Method only, printed p. 14: theoretical quarter-chord moment for a camber line is read from the supplementary mean-line figures and scaled linearly with design lift coefficient; the report's own examples give these values for other series, not for 2412.)

## How we could use it
- Feeds U18.4-2 only as a method reference (thin-airfoil moment estimate scaled by design CL, printed p. 14); not a value for the Cm_ac input.
- Use an experimental source for NACA 2412 Cm_ac (data sheet figures with Reynolds number) or the Abbott and von Doenhoff table of section data before the tail model is validated.
- values still missing: NACA 0012 Cm c/4 with Reynolds number; NACA 2412 Cm c/4 with Reynolds number (both only in plotted supplementary figures of this report, not extracted as text).
