## Summary
Opened on 2026-11-25 (same URL as std-ct-fasteners). The coarse-thread tables give tensile stress area, proof load and minimum ultimate tensile load per bolt for M3 to M6 in property classes 8.8 and 12.9, stated as ISO 898-1 based. No M2.5 row is in the table. The values are per bolt, not per joint.

## Usable rules / numbers
- M5 coarse: tensile stress area 14.2 mm2; proof load 8230 N (8.8) and 13800 N (12.9); minimum ultimate tensile load 11350 N (8.8) and 17300 N (12.9) (tables "Metric Bolts - Coarse Threads - Proof Loads" and "Metric Bolts - Coarse Threads - Minimum Ultimate Tensile Loads").
- M6 coarse: tensile stress area 20.1 mm2; proof load 11600 N (8.8) and 19500 N (12.9); minimum ultimate tensile load 16100 N (8.8) and 24500 N (12.9) (same two tables).
- M3 coarse: tensile stress area 5.03 mm2; proof load 2920 N (8.8) and 4880 N (12.9); minimum ultimate tensile load 4020 N (8.8) and 6140 N (12.9) (same two tables; re-confirms the M3 row in std-ct-fasteners).
- M4 coarse: tensile stress area 8.78 mm2; proof load 5100 N (8.8) and 8520 N (12.9); minimum ultimate tensile load 7020 N (8.8) and 10700 N (12.9) (same two tables; re-confirms std-ct-fasteners).
- M2.5: no row in either table (`not found`).
- Note on use: the page states these are per bolt and do not include nut, washer or thread-in-material limits.

## How we could use it
- Per-bolt proof and ultimate loads for CT-A-PROP-ADAPTER (M5 stud), CT-A-PROP-NUT (M5 stud), CT-PROP-NUT (M6), CT-A-M3-BOLT-MOUNT and CT-A-M3-CSK-MOTOR (M3). Cite as per-bolt values only.
- Does not give a joint rating for any connection type in packet 8.
