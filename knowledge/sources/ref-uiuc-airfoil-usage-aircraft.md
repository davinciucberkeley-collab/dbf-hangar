## Summary
Table of airfoils used on real aircraft, with separate wing-root and wing-tip columns. The page is dated "Last update April 4, 2026". It lists several Cessna 172 Skyhawk variants with root and tip airfoils.

## Usable rules / numbers
- Cessna 172 Skyhawk 1973-later: wing root NACA 2412, wing tip NACA 2412 mod (table row "Cessna 172 Skyhawk 1973-later"; columns "Wing Root Airfoil" / "Wing Tip Airfoil", table header line 183).
- Cessna 172 Skyhawk early models (T-41): wing root NACA 2412, wing tip NACA 0012 (same table).
- Cessna 172 Cutlass and Cessna 172 Hawk XP: root NACA 2412, tip NACA 2412 mod (same table).
- The table does not give the coordinates or thickness of the "mod" tip airfoil.
- Licence / terms on the page: none stated in the content read.

## How we could use it
- Sets the C172 wing airfoils for the c172-rc design step (1973-later Skyhawk: NACA 2412 root, NACA 2412 mod tip).
- No coordinates for the tip "mod" are given here; a coordinate source is still needed before the tip can be modelled.
