## Summary
Article on informal pull tests of printed threads in PLA+. The article body gives no numbers, only a qualitative infill comparison. A reader comment gives average pull-out loads by infill level, but for a 1/4"-20 screw, not an M3. The comment's values are not checked against the video.

## Usable rules / numbers
- PLA+, 1/4"-20 thread, 10 % infill: average pull-out 48.38 lbf (range 44.28–50.77 lbf), about 215 N by conversion (reader comment table).
- PLA+, 1/4"-20 thread, 25 % infill: average 67.54 lbf (range 48.61–80.51 lbf), about 300 N by conversion (reader comment table).
- PLA+, 1/4"-20 thread, 50 % infill: average 89.54 lbf (range 80.12–98.24 lbf), about 398 N by conversion (reader comment table).
- PLA+, 1/4"-20 thread, 100 % infill: over 110 lbf (instrument limit), about 489 N by conversion (reader comment table).
- Wall settings: not found. Layer height 0.2 mm (article text).
- M3 pull-out in PLA or birch plywood: not found.

## How we could use it
- CT-M3-SHCS-MOTOR pull-out: only a trend (pull-out rises with infill); the numbers are for a larger screw and cannot be used as an M3 value.
- Needs an M3-specific PLA test before any joint rating is set from it.
