## Summary
Index of airfoil coordinate files, each linked as a .dat file under coord/. It lists the Clark Y (clarky.dat) and SD7037 (sd7037.dat) files used in this library. The content read states no copyright or usage terms.

## Usable rules / numbers
- Clark Y: link coord/clarky.dat, entry text "CLARK Y airfoil".
- SD7037: link coord/sd7037.dat (href found by grep of the page HTML).
- The page gives "Last updated 2/23/2026" for the coord_seligFmt.zip archive, not per file.
- Licence / terms: none stated in the content read.

## How we could use it
- Source of the coordinate files knowledge/airfoils/clarky.dat and knowledge/airfoils/sd7037.dat (copied unchanged).
