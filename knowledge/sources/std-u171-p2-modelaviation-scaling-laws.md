## Summary
Model Aviation article on how model performance changes with size. It treats wing loading only as a ratio that rises with size. It gives no absolute wing-loading value or class range.

## Usable rules / numbers
- [wing_loading_max_g_dm2] Wing loading rises with size unless the designer lowers it (section "Wing Loading, Speed, and Energy"). No absolute value stated.
- [wing_loading_max_g_dm2] Table 2, "Summary of Scale Effects (doubling size)", gives a wing-loading multiplier of 2.25 for doubling size. A scaling ratio, not a limit.

## How we could use it
- Scaling context only; no usable bound for wing_loading_max_g_dm2.
