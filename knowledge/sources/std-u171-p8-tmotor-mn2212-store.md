## Summary
Opened on 2026-11-25. The T-Motor store page lists a maximum thrust and a shaft diameter for the MN2212 V2.0 motor. It gives no mounting hole pattern, no screw size, no prop-adapter thread and no readable drawing; the body text names a different model (MN4112) in places.

## Usable rules / numbers
- Max. thrust 1.8 kg, stated for the MN2212 V2.0 KV780/KV920 title, with no split by KV (product specification area, "Max. thrust").
- Shaft diameter 4 mm for both KV780 and KV920 (specification table).
- Mounting hole pattern, base screw size, prop adapter thread: `not found` on this page. The "Technical Drawing" is an image with no readable text.
- Model naming on the page is inconsistent (MN4112 in body and packing list); the thrust figure is used as printed and not confirmed for the MN2212.

## How we could use it
- Context for CT-A-PROP-ADAPTER only (motor max thrust and shaft); it does not rate the adapter or the M3 and M5 fasteners.
- A thrust statement that needs a T-Motor drawing or a confirmed model before any load case uses it.
