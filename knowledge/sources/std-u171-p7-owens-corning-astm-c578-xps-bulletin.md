## Summary
Owens Corning one-page technical bulletin (printed July 2025) that lists the ASTM C578 type, minimum compressive strength, minimum density and other minimum properties for its FOAMULAR and FOAMULAR NGX extruded polystyrene boards next to the EPS types. Opened and read on 2026-11-25 as a PDF text layer. The table header has no column labels for each product type, so the product-to-type mapping below is taken from column position and is checked against the printed compressive strength (15, 25, 40, 60 and 100 psi for the 150, 250, 400, 600 and 1000 grades).

## Usable rules / numbers
- Density, minimum, printed as lb/ft3 (kg/m3), ASTM C578 Type X (FOAMULAR NGX 150 column): 1.30 lb/ft3 (21 kg/m3). Exact conversion 1.30 x 16.01846 = 20.82 kg/m3. Kind: minimum. Place: table "ASTM C578 Classification Type ... Density, min, lb/ft3 (kg/m3)" row, column X.
- Density, minimum, Type IV (FOAMULAR NGX 250 column): 1.45 lb/ft3 (23 kg/m3). Exact 1.45 x 16.01846 = 23.23 kg/m3. Kind: minimum. Same table, column IV.
- Density, minimum, Type VI (FOAMULAR NGX 400 column): 1.80 lb/ft3 (29 kg/m3). Exact 1.80 x 16.01846 = 28.83 kg/m3. Kind: minimum. Same table, column VI. Compressive resistance minimum for this column 40.0 psi (276 kPa).
- Density, minimum, Type VII (FOAMULAR NGX 600 column): 2.20 lb/ft3 (35 kg/m3). Exact 35.24 kg/m3. Kind: minimum. Same table, column VII. Compressive 60.0 psi.
- Density, minimum, Type V (FOAMULAR NGX 1000 column): 3.00 lb/ft3 (48 kg/m3). Exact 48.06 kg/m3. Kind: minimum. Same table, column V. Compressive 100.0 psi (690 kPa).
- The bulletin cites ASTM C578-23 as the basis of the table. The bulletin does not give a density maximum or a typical value.
