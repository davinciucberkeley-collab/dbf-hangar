## Summary
Distributor summary of the ISO 898-1 mechanical property classes for steel bolts. It lists tensile strength and proof stress per class. The table is not broken down by thread size, and the fetched text had jumbled column headers, so class-to-value matching was checked against the usual class pattern. It gives no stress area, proof load or shear value.

## Usable rules / numbers
- Class 8.8: nominal and minimum tensile strength Rm 800 MPa (property table).
- Class 8.8: 0.2 % proof stress Rp0.2 640 MPa, nominal and minimum (property table).
- Class 8.8: test stress Sp 580 MPa (property table).
- Class 12.9: nominal tensile strength Rm 1200 MPa; minimum 1220 MPa (property table).
- Class 12.9: 0.2 % proof stress Rp0.2 1080 MPa nominal, 1100 MPa minimum (property table).
- Class 12.9: test stress Sp 970 MPa (property table).
- Stress area, proof load and shear strength: not found.
- Yield stress Rel for these classes: not found.

## How we could use it
- Cross-check of the material stress values behind the M2/M3 tension basis (concept-a E-MEC-02 uses 450 MPa from another file, not from this page).
- Gives the material-stress basis for any M3 shear estimate, which still needs a shear-specific source.
