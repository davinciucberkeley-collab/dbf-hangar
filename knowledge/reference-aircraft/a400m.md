# Reference aircraft fact sheet: Airbus A400M Atlas (A400M-180, production)

Rules: full-size values; lengths in metres, areas m2, masses kg, speeds m/s, angles degrees. The model scale factor is applied in section 7. Every row needs a value, a source (id or URL you opened) and a confidence (measured, drawing, photo, estimate). Write `unknown` rather than guess.

Confidence key used here: `drawing` = published manufacturer or government figure, not measured by us; `estimate` = inferred from category labels or text; `derived` = computed, formula given. No `measured` or `photo` value was taken, because no drawing or photo was read.

## 7. RC-scale adjustments (fill after sections 1 to 6)
Sources: scale-stefanv-scale-electric-design (power laws), std-mit-unified-desrules (stability ranges), scale-rcu-tail-feathers-scale-size (forum opinion). The scale factor s is a design choice, not a source value; no s is set here.
| Field | Rule | Value |
|---|---|---|
| scale factor s (model/full) | span x s must fit the transport box; check power: s = cube root of (power available / full-size power) is an upper bound | not set (design choice) |
| model span, length, area | span x s, length x s, area x s^2 | 42.4 s; 45.1 s; 225.1 s^2 (derived formulas) |
| scale-law mass (floor test) | MTOW x s^3; if real-parts mass is far higher, s is too small | 141,000 s^3 kg (derived formula) |
| target mass | real-parts mass; state the ratio to the s^3 mass | not set (needs s and BOM) |
| wing loading | full-size x s; accept higher if the stall check passes | 626 s kg/m2 (derived formula) |
| stall, cruise speed | full-size x sqrt(s) | cruise 216.9 sqrt(s) m/s (derived); stall unknown |
| power | full-size power x s^3 as a guide; thrust-to-weight not below the standards value (`standards/*.yaml`) | full size 32.8 to 33.0 MW total; model 32.8 to 33.0 MW x s^3 (derived formula) |
| horizontal tail volume Vh = Sh h / (S c) | 0.30 to 0.60 | unknown (tail geometry unknown) |
| vertical tail volume Vv = Sv v / (S b) | 0.02 to 0.05 | unknown (tail geometry unknown) |
| tail enlargement | area factor 1.0 to 1.33, only when Vh or Vv is below range (forum opinion, not tested) | unknown (needs Vh, Vv) |

## 8. Gaps
Fields left `unknown`, and what to read or measure next:
- Wing: root and tip chord, LE sweep, dihedral, twist, airfoil, wing z, root LE x, incidence, flap and aileron spans, struts. Next: a published three-view (Airbus or a Wikimedia Commons three-view) read at a known scale; the Airbus aircraft characteristics page, if it lists the A400M.
- Wing area: one source only (225.1 m2). A second source is needed; the search snippet 221.5 m2 conflicts and was not opened.
- Fuselage: 8 to 15 stations, section shapes, nose, tail-cone upsweep. Next: three-view side and top, cargo-hold cross-section photos.
- Tail: horizontal and vertical tail geometry, elevator and rudder fractions. Next: three-view.
- Propulsion: engine x, y, z positions, thrust line, nacelle size, spinner size, per-engine rotation. Next: three-view front and top; Airbus or photo read.
- Landing gear: all fields. Next: three-view and photo.
- Mass and performance: stall speed, CG range, paint scheme. Next: TCDS (readable copy) or flight manual; photos.
- Blocked or unreadable: the OCCAR A400M datasheet returned HTTP 403 (blocked: occar.int); globalmilitary.net returned HTTP 403 (blocked). The EASA data sheet PDF (ref-a400m-easa-tcds) was fetched but returned as compressed binary; no values taken from it. A search snippet quoted EASA values (span 42.357 m, length 45.091 m, height 14.675 m) that were not opened; they are consistent with the values above but are not used as sources.
- Scope note: the A400M is a military type; its TCDS is not confirmed to exist in EASA form. Verify before citing as TCDS.
