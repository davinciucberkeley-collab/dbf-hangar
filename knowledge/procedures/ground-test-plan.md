## Purpose
The ground tests run on the built aircraft and its parts before flight: part weighing and fit, proof loads, pack and motor checks, and the measurement-rig checks that must pass before the data is used. Run before the first flight and whenever a part changes.

## Steps
1. Weigh every pod part before assembly [D2#35]
2. Fit the real pack in the bay [D2#36]
3. Run the strap loop pull test [D2#37]
4. Run the handle proof load on the built wing [D2#38]
5. Weigh every fin part [D3#22]
6. Run the mount slip setting test [D3#19]
7. Run the half-fin root side pull test [D3#20]
8. Run the strap eye pull test on the bonded eye (CDR-27) [D3#21]
9. Run the cartridge crush coupon test on both types [D5#34]
10. Run the pad slide test on an incline, on the landing mat [D5#35]
11. Run the timed foot-insert swap [D5#36]
12. Run the shoe bond and flange proof load test [D5#37]
13. Run the side load test at the pad: proof of every flight shoe, and failure load of one per batch [D5#38]
14. Run the servo throw, ratio and stops test [D6#24]
15. Run the surface free play test [D6#25]
16. Run the panel twist and lag test under load [D6#26]
17. Weigh the mechanism parts [D6#27]
18. Run the crush-column coupon test [D7#25]
19. Run the loaded box drop test [D7#26]
20. Weigh the box empty and loaded, the mat, the battery can and the tote [D7#27]
21. Run the hand-hole pull test [D7#28]
22. Time the field set-up [D7#29]
23. Run the thrust stand test at one station with both candidate props [E1#50]
24. Run the incoming motor check: resistance, no-load current, mass, bolt pattern, hole and thread depth [E1#51]
25. Run the tethered hover current test [E1#52]
26. Weigh and measure every pack on arrival [E2#23]
27. Run the discharge capacity test at 1C [E2#24]
28. Run the pack resistance test by load step [E2#25]
29. Run the full-mission current log [E2#26]
30. Walk the range test distance [F5#11]
31. Run the first CF tube bend test (GT-16) [G2#44]
32. Run the stand B1 points [H1#27]
33. Run the installed-run test at the test rpm points [H1#45]
34. Repeat the session calibration at the end of every session [H1#12]
35. Read the shunt step on each bridge [H1#10]
36. Set the CG jig pins to the layout [H1#69]
37. Run the phone tap test using the phone app, only for the 12-22 Hz wing modes [H1#153]
38. Record each tap as a 4 s record, 0.25 Hz bins, 5 taps per direction [H1#154]
39. Set the tap window half-width to +/-0.2 of the forcing frequency [H1#155]
40. Tap each bell in y and z over the FFT range to 450 Hz [H1#162]

## Checks and stop conditions
- Current sensor tolerance after calibration is confirmed [F1#39]
- Airspeed error at cruise, RSS, is within the requirement limit [F3#10]
- Airspeed resolution at cruise, one count, is at most 0.1 m/s [F3#11]
- Elevon PWM error, SERVO5/6 MIN/MAX against the D6 servo angles, is at most 1.5 us [F4#42]
- Range test distance is at least 105 m (100 m plus phone-GPS U95) [F5#11]
- Sensor error the limiter value tolerates is confirmed at the first bound, both edges [E1#18]
- Thrust resolution is at most 0.5 % of hover [H1#3]
- Torque resolution is at most 2 % of hover [H1#4]
- Thrust and torque linearity: at most 0.5 % FS thrust and at most 1 % FS torque [H1#5]
- 2-sigma noise at hover: at most 0.005 (thrust) and 0.02 (torque) [H1#6]
- Start and end drift: at most 0.5 % [H1#7]
- FC raw IMU sample rate for the stand: at least 935 Hz (text) [H1#8]
- Strain-gauge zero drift over 10 min: at most 5 microstrain [H1#9]
- Shunt step read on each bridge: 1 744 microstrain within 1 % [H1#10]
- Thermocouples agree in still air within 0.3 K [H1#11]
- Thrust U95 after calibration: 0.5 % of span [H1#13]
- Scale calibration uncertainty U95: at most 5.2 g (text) [H1#62]
- Jig U95 in x: at most 0.6 mm [H1#65]
- Gauge self-heating power density: at most 78 W/m2 [H1#91]
- Gauges after unload: back to zero within 20 microstrain; zero check at most 10 microstrain before the 1.5 x load [H1#95]
- Current sensor calibration: BAT.Curr within 5 % at 5, 15, 25 and 30 A [H1#103]
- Lever calibration: within 2 %; 20 kg proof for 60 s [H1#125]
- Torque check without a driver: 0.20 N m, applied as 2.0 N on a spring scale at a 0.10 m arm [H1#137]
- Tube bending read uncertainty: 3.0 % [H1#139]
- Ring crush E_hoop uncertainty: at most 10 % [H1#145]
- Stiffness uncertainty at the pass line: at most 10 % [H1#148]
- Phone tap app: maximum 160 Hz, only for 12-22 Hz wing modes [H1#153]
