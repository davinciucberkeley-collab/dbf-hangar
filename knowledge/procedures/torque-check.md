## Purpose
Checking fastener torque with a luggage scale in place of a torque driver. Run when a torque value is set or checked without a driver.

## Steps
1. Hang the luggage scale on a 50 mm arm and read the force that gives the target torque [C6#67]

## Checks and stop conditions
- Target readings: 0.08 N m = 1.6 N; 0.20 N m = 4.0 N; 0.4 N m = 8.0 N, each at a 50 mm arm [C6#67]
